# E2-S06: IBKR Broker Profile JSON

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** P2

## Description

Write the Interactive Brokers (IBKR) broker profile JSON. IBKR uses a per-share tiered commission model, supports CFDs with overnight financing, and has tighter spreads than DEGIRO due to its market-making infrastructure.

## File Locations

- `src/phantom/profiles/ibkr.json`

## Acceptance Criteria

- [ ] File exists at `src/phantom/profiles/ibkr.json`
- [ ] `load_profile("src/phantom/profiles/ibkr.json")` returns a valid `BrokerProfile` without error
- [ ] `profile.name == "IBKR"`
- [ ] `profile.commission.model_type == "per_share"` or `"tiered"` with appropriate rates
- [ ] `profile.supported_instruments` includes `"stock"` and `"cfd"`
- [ ] `profile.overnight` has non-zero markup rates reflecting IBKR financing costs
- [ ] `profile.margin.max_leverage > 1.0` (IBKR offers leverage on CFDs)
- [ ] `profile.dividend.withholding_rates` has at least US, UK, DE rates
