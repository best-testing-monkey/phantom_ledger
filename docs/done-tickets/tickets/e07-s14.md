# E7-S14: Dividend Log Persistence

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** P2
**Depends on:** [E7-S13](e07-s13.md)

## Description

Create the `dividend_log` database table and a corresponding `DividendLogRepo` that persists each individual dividend adjustment as an immutable audit record. Each time `_apply_dividend()` fires in `PositionManager` and a non-zero adjustment is computed, call `DividendLogRepo.create()` to write a row capturing the position, account, ex-date, dividend per share, and the net adjustment amount (positive for credits, negative for debits). This log is append-only — there is no `update()` or `delete()`. The table enables downstream reporting (E12) to list all dividend events by account, ticker, or date range. The migration SQL must be added as a numbered file in `src/phantom/db/migrations/`.

## File Locations

- `src/phantom/db/repositories/dividend_log_repo.py` — `DividendLogRepo` with `create()` and `list()` methods
- `src/phantom/db/migrations/XXXX_create_dividend_log.sql` — migration creating the `dividend_log` table
- `src/phantom/models/dividend_log.py` — `DividendLog` Pydantic model

## Acceptance Criteria

- [ ] `dividend_log` table has columns: `id` (TEXT PK), `position_id` (TEXT FK → positions), `account_id` (TEXT FK → accounts), `ex_date` (TEXT ISO date), `dividend_per_share` (REAL), `adjustment_amount` (REAL), `created_at` (TEXT ISO 8601)
- [ ] `DividendLogRepo.create()` inserts a row, commits, and returns the `DividendLog` model
- [ ] `DividendLogRepo.list(position_id=...)` returns all dividend events for a position ordered by `ex_date` ascending
- [ ] `DividendLogRepo.list(account_id=...)` returns all dividend events for an account
- [ ] `DividendLog` Pydantic model has `id` (ULID default factory), all table columns with correct Python types
- [ ] Migration is numbered correctly (after overnight_log migration) and safely re-runnable

# src/phantom/models/dividend_log.py
from pydantic import BaseModel, Field
from phantom.utils.ids import new_id

class DividendLog(BaseModel):
    id: str = Field(default_factory=new_id)
    position_id: str
    account_id: str
    ex_date: str             # ISO date "YYYY-MM-DD"
    dividend_per_share: float
    adjustment_amount: float  # positive = credit, negative = debit
    created_at: str           # ISO 8601 datetime

# src/phantom/db/repositories/dividend_log_repo.py
class DividendLogRepo:
    def __init__(self, conn: sqlite3.Connection):
        self._conn = conn

    def create(self, log: DividendLog) -> DividendLog:
        self._conn.execute(
            "INSERT INTO dividend_log "
            "(id, position_id, account_id, ex_date, dividend_per_share, adjustment_amount, created_at) "
            "VALUES (?, ?, ?, ?, ?, ?, ?)",
            (log.id, log.position_id, log.account_id, log.ex_date,
             log.dividend_per_share, log.adjustment_amount, log.created_at),
        )
        self._conn.commit()
        return log
