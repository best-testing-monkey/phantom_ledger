# E15-S04: Strategy Parameter Snapshot

**Epic:** [E15: Strategy Automation Hooks](e15-strategy-automation.md)
**Phase:** P3
**Depends on:** [E5](e05-account-system.md), [E15-S01](e15-s01.md)

## Description

When an algorithm account is created with an associated strategy, serialize the strategy class name and its `__init__` parameter values (extracted via `inspect.signature`) to the `algorithm_params` JSON field on the `Account` model. This snapshot allows the system to display which strategy and configuration was active for a given account, and to reconstruct the strategy for replay purposes. The snapshot is stored at account creation time and is not updated on subsequent runs. If a strategy has no `__init__` parameters beyond `self`, the `params` dict is stored as `{}`.

## File Locations

- `src/phantom/api/accounts.py` — `create()` method extended with `strategy_path` optional parameter

## Acceptance Criteria

- [ ] `AccountAPI.create(..., strategy_path: str | None = None)` accepts an optional strategy file path
- [ ] When `strategy_path` is provided, `load_strategy(strategy_path)` is called and the class name + `__init__` params are captured
- [ ] `algorithm_params` is stored as `{"strategy_class": "MyStrategy", "strategy_path": "/abs/path.py", "params": {...}}` JSON
- [ ] If `strategy_path` is not provided, `algorithm_params` is `null` / `None`
- [ ] `ProfileError` from `load_strategy` propagates to the caller without wrapping
- [ ] Unit test: creating an account with a strategy path stores the class name in the account's `algorithm_params`

## Implementation Notes

```python
import inspect, json
from phantom.engine.strategy import load_strategy

def _snapshot_strategy(strategy_path: str) -> str:
    strategy = load_strategy(strategy_path)
    cls = type(strategy)
    sig = inspect.signature(cls.__init__)
    params = {
        k: None for k in sig.parameters
        if k != "self"
    }
    return json.dumps({
        "strategy_class": cls.__name__,
        "strategy_path": str(Path(strategy_path).resolve()),
        "params": params,
    })
```
