## Implementation Notes

```python
# Example: creating a Phantom instance
from phantom import Phantom

ph = Phantom(data_dir="./data")

# Load a broker profile
profile = ph.brokers.load("ibkr")

# Create an account
account = ph.accounts.create(
    name="my-account",
    broker_profile="ibkr",
    account_type="cash",
    initial_cash=10_000.0,
)

# Place an order
order = ph.orders.place(
    account_id=account.id,
    symbol="AAPL",
    side="buy",
    quantity=10,
    order_type="market",
)
```

```bash
# Equivalent CLI usage
phantom brokers load ibkr
phantom accounts create --name my-account --broker ibkr --cash 10000
phantom orders place --account my-account --symbol AAPL --side buy --qty 10
```
