# E12-S08: Aggregate Account Reporting

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P2
**Depends on:** [E12-S01](e12-s01.md), [E5](e05-account-system.md)

## Description

Add `phantom report --account <parent-name> --aggregate` flag that combines equity curves from all child accounts under a parent "aggregate" account type and computes portfolio-level metrics treating the combined history as a single equity curve. Child accounts are fetched via `ph.accounts.list(parent_id=parent_account.id)`. Each child account's closed positions contribute to the combined equity curve: all positions from all children are merged, sorted by `close_datetime`, and accumulated against the sum of all children's `initial_capital` as the starting equity. The resulting merged equity curve is passed to `calculate_metrics()` and `calculate_trade_metrics()` exactly as in the per-account report. The report header must state `"Aggregate report for <parent-name> (N child accounts)"`.

## File Locations

- `src/phantom/cli.py` — `report` command updated with `--aggregate` flag
- `src/phantom/reports/metrics.py` — `build_aggregate_curve()` helper function

## Acceptance Criteria

- [ ] `--aggregate` flag fetches all child accounts via `ph.accounts.list(parent_id=...)`
- [ ] Closed positions from all children merged and sorted by `close_datetime` ascending
- [ ] Starting equity = sum of all children's `initial_capital` values
- [ ] Report header: `"Aggregate report for <name> (N child accounts)"`
- [ ] `ValidationError` raised if parent account `account_type != "aggregate"`
- [ ] If parent has no child accounts: print `"No child accounts found."` and exit 0

## Implementation Notes

```python
# src/phantom/reports/metrics.py
def build_aggregate_curve(
    child_accounts: list[Account],
    all_positions: list[Position],
) -> list[EquityPoint]:
    """Build single merged equity curve from multiple child accounts."""
    closed = sorted(
        [p for p in all_positions if p.status == "closed"],
        key=lambda p: p.close_datetime,
    )
    equity = sum(a.initial_capital for a in child_accounts)
    curve: list[EquityPoint] = []
    for pos in closed:
        equity += pos.realized_pnl or 0.0
        curve.append(EquityPoint(timestamp=pos.close_datetime, equity=equity))
    return curve

# CLI fragment
if aggregate:
    parent = ph.accounts.get_by_name(account)
    if parent.account_type != "aggregate":
        console.print("[red]Error:[/red] Account is not of type 'aggregate'.")
        raise typer.Exit(code=1)
    children = ph.accounts.list(parent_id=parent.id)
    if not children:
        console.print("No child accounts found.")
        return
    all_positions = []
    for child in children:
        all_positions.extend(ph.positions.list(account_name=child.name))
    curve = build_aggregate_curve(children, all_positions)
```
