# E6-S07: CLI — order place

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP
**Depends on:** [E6-S03](e06-s03.md)

## Description

Wire up `phantom order place` with all supported flags.

## File Locations

- `src/phantom/cli.py` — add `order_place` command

## Acceptance Criteria

- [ ] `phantom order place --account insider_buys --ticker AAPL --direction long --type market --quantity 10` places a market order
- [ ] `--tp`, `--sl`, `--limit-price`, `--stop-price`, `--trailing-amount`, `--trailing-pct` flags accepted
- [ ] `--instrument` flag accepts `stock` (default) or `cfd`
- [ ] `--at "2025-06-15T14:30:00"` sets `created_at` to that historical timestamp (for replayed orders)
- [ ] `--good-til "2025-07-01T16:00:00"` sets expiry
- [ ] On success, prints the created Order as a Rich panel including estimated entry cost
- [ ] Exits 1 with friendly error on `InsufficientFundsError`, `NotFoundError`, or `ValidationError`
