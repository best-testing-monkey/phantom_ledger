# E7-S03: PositionManager.update()

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP
**Depends on:** [E7-S01](e07-s01.md), [E7-S02](e07-s02.md)

## Description

Implement `PositionManager.update()` which is called on each bar for all open positions. It computes unrealized P&L, checks TP/SL conditions, and returns whether the position should be closed (actual close logic in E7-S04).

## File Locations

- `src/phantom/engine/position_manager.py` — `PositionManager` class

## Acceptance Criteria

- [ ] `PositionManager.__init__(self, position_repo, account_repo, cost_engine)`
- [ ] `update(position: Position, bar: pd.Series) -> tuple[Position, bool]` returns updated position and a `should_close` flag
- [ ] Unrealized P&L for long: `(bar["Close"] - entry_price) * quantity`
- [ ] Unrealized P&L for short: `(entry_price - bar["Close"]) * quantity`
- [ ] `should_close = True` when TP or SL is hit (see E7-S04 for actual close logic)
- [ ] `update()` does not write to the DB — the simulation loop handles writes
