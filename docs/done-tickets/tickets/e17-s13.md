# E17-S13: RunnerAPI Paper Trade

**Epic:** [E17: Library API Surface](e17-library-api.md)
**Phase:** P2
**Depends on:** [E9-S06](e09-s06.md), [E17-S08](e17-s08.md)

## Description

Extend `RunnerAPI` with `paper_trade(account_id, interval=300)` which starts the paper trading scheduler in a background `threading.Thread` and returns a `PaperTradeHandle` object. The handle exposes `stop()` and `is_running() -> bool`. This allows library users to start paper trading programmatically without blocking their process. The background thread runs `PaperTradeScheduler.start()` (which itself blocks). `stop()` calls `scheduler.stop()` and joins the thread with a 5-second timeout. The handle is thread-safe: `is_running()` reads a `threading.Event` that is set when the thread terminates.

## File Locations

- `src/phantom/api/runner.py` — `PaperTradeHandle` dataclass and `paper_trade()` method on `RunnerAPI`

## Acceptance Criteria

- [ ] `ph.runner.paper_trade(account_id, interval=300)` returns a `PaperTradeHandle` immediately (non-blocking)
- [ ] `handle.is_running()` returns `True` while the background thread is alive
- [ ] `handle.stop()` signals the scheduler to stop and joins the thread within 5 seconds
- [ ] `handle.is_running()` returns `False` after `stop()` completes
- [ ] Calling `stop()` twice is idempotent (no exception)
- [ ] Unit test: `paper_trade()` starts a thread; calling `stop()` terminates it within 5 seconds

## Implementation Notes

```python
import threading
from dataclasses import dataclass, field

@dataclass
class PaperTradeHandle:
    _scheduler: PaperTradeScheduler
    _thread: threading.Thread
    _done: threading.Event = field(default_factory=threading.Event)

    def stop(self) -> None:
        self._scheduler.stop()
        self._thread.join(timeout=5.0)
        self._done.set()

    def is_running(self) -> bool:
        return self._thread.is_alive()

# In RunnerAPI:
def paper_trade(self, account_id: str, interval: int = 300) -> PaperTradeHandle:
    self._account_repo.get(account_id)  # validate exists
    scheduler = PaperTradeScheduler(self._engine, interval)
    thread = threading.Thread(target=scheduler.start, daemon=True, name=f"phantom-paper-{account_id}")
    thread.start()
    return PaperTradeHandle(_scheduler=scheduler, _thread=thread)
```
