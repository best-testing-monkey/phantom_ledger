# E9-S09: Overnight Cost Accrual Hook in Sim Loop

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** P2
**Depends on:** [E3-S10](e03-s10.md), [E4-S06](e04-s06.md), [E9-S02](e09-s02.md)

## Description

Integrate overnight cost accrual into the simulation loop by detecting day boundary crossings between consecutive bars. Before processing position updates on each bar, compare the current bar's date against the previous bar's date for the account (tracked as `last_bar_date` on the account or simulation state). If the date has changed, iterate over all open CFD positions and call `CostEngine.overnight_cost(position, overnight_model, reference_rate, days_crossed)` for each. The returned charge is deducted from `account.cash` and added to `position.overnight_accrued`. The reference rate (e.g. SOFR or ECB rate) is fetched from the `RateProvider` (E4-S06) for the boundary date. Weekend gaps count as multiple day crossings (e.g. Friday→Monday = 3 days). Stock positions are skipped (no overnight cost). All overnight charges for a bar are applied before TP/SL checks so that cash balances are correct when margin is evaluated.

## File Locations

- `src/phantom/engine/simulation_engine.py` — add `_apply_overnight_costs()` call inside `run_backtest()` and `run_paper()` bar loops

## Acceptance Criteria

- [ ] Overnight cost is applied once per day boundary per open CFD position
- [ ] Friday-to-Monday gap applies 3 days of overnight charges (Fri, Sat, Sun)
- [ ] Stock positions receive zero overnight charges regardless of day gaps
- [ ] Reference rate is fetched from `RateProvider` for the crossing date (mocked in tests)
- [ ] Overnight charges are deducted from `account.cash` and accumulated in `position.overnight_accrued` before TP/SL evaluation
- [ ] If `RateProvider` raises `DataError`, log WARNING and use `0.0` as the reference rate (degraded mode)

## Implementation Notes

```python
def _apply_overnight_costs(
    self,
    account: Account,
    open_positions: list[Position],
    prev_bar_date: date | None,
    current_bar_date: date,
) -> None:
    if prev_bar_date is None or prev_bar_date >= current_bar_date:
        return
    days_crossed = (current_bar_date - prev_bar_date).days
    cfd_positions = [p for p in open_positions if p.instrument_type == "cfd"]
    if not cfd_positions:
        return
    try:
        reference_rate = self._rate_provider.get_rate(prev_bar_date)
    except DataError as exc:
        logger.warning("Rate fetch failed for %s: %s. Using 0.0.", prev_bar_date, exc)
        reference_rate = 0.0
    for position in cfd_positions:
        charge = self._cost_engine.overnight_cost(
            position=position,
            overnight_model=self._broker_profile.overnight,
            reference_rate=reference_rate,
            days=days_crossed,
        )
        account.cash -= charge
        position.overnight_accrued += charge
    logger.debug(
        "Applied overnight costs for %d day(s) to %d CFD positions",
        days_crossed, len(cfd_positions),
    )
```
