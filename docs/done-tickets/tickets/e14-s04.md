# E14-S04: Discord Webhook Sender

**Epic:** [E14: Alerts & Notifications](e14-alerts.md)
**Phase:** P3
**Depends on:** [E14-S01](e14-s01.md)

## Description

Implement `DiscordSender`, an `AlertSender` that delivers alert messages to a Discord channel via an incoming webhook URL. The sender is configured with a single `webhook_url`. On `send(event)`, it POSTs to the webhook URL with a JSON body `{"content": "<formatted message>"}`. Discord webhooks return 204 No Content on success, so the check is `resp.status_code == 204`. If the response is not 204, raise `DataError("discord", resp.text)`. The message format should include event type, account ID, position ID (if set), and the human-readable message. Use `httpx` for the HTTP call.

## File Locations

- `src/phantom/alerts/discord.py` — `DiscordSender` class

## Acceptance Criteria

- [ ] `DiscordSender(webhook_url: str)` stores the URL
- [ ] `send(event)` POSTs to `webhook_url` with JSON body `{"content": formatted_message}`
- [ ] Success is defined as HTTP 204; any other status raises `DataError("discord", resp.text)`
- [ ] Message format: `"[{event_type}] Account {account_id}: {message}"` (position_id appended if set)
- [ ] `httpx` is used for the HTTP call (sync)
- [ ] Unit test: mock `httpx.post` to return 204 and verify payload; mock 400 and verify `DataError` raised

## Implementation Notes

```python
import httpx
from phantom.alerts.events import AlertEvent
from phantom.errors import DataError

class DiscordSender:
    def __init__(self, webhook_url: str) -> None:
        self._url = webhook_url

    def send(self, event: AlertEvent) -> None:
        content = f"[{event.event_type}] Account {event.account_id}: {event.message}"
        if event.position_id:
            content += f" (position {event.position_id})"
        resp = httpx.post(self._url, json={"content": content})
        if resp.status_code != 204:
            raise DataError("discord", resp.text)
```
