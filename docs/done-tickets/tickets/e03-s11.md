# E3-S11: FX Conversion Cost

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E3-S04](e03-s04.md)

## Description

Extend `CostEngine` to compute FX conversion cost when the position's instrument currency differs from the account's base currency. The cost is a percentage of the notional value (e.g. DEGIRO charges 0.25% on currency conversion).

## File Locations

- `src/phantom/costs/fx.py` — `FXModel.calculate()` (or inline in CostEngine)
- `src/phantom/costs/engine.py` — use FX cost in `entry_costs()` and `exit_costs()`

## Acceptance Criteria

- [ ] FX cost = `price * quantity * fx_conversion_pct` when `fx_required=True`
- [ ] FX cost = `0.0` when `fx_required=False`
- [ ] `CostBreakdown.fx` reflects this correctly
- [ ] `CostBreakdown.total` includes FX
- [ ] Unit tests: FX required basic, FX not required returns zero
