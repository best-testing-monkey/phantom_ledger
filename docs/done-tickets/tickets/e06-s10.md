# E6-S10: Stop-Limit Order

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** P2
**Depends on:** [E6-S09](e06-s09.md)

## Description

Extend `OrderManager.evaluate()` to handle stop-limit orders. A stop-limit triggers a limit order (not a market order) when `stop_price` is hit. The limit order then only fills if the price reaches `limit_price` within the same or subsequent bars.

## File Locations

- `src/phantom/engine/order_manager.py` — extend `evaluate()`

## Acceptance Criteria

- [ ] When stop is hit: order transitions to `status="triggered"` with `triggered_at` set; the order is now treated as a limit order
- [ ] Subsequent bars: triggered stop-limit fills when limit price is reached (same logic as regular limit)
- [ ] If limit is never reached before `good_til`: order expires normally
- [ ] Unit tests: stop hit then limit filled, stop hit but limit never filled (expires)
