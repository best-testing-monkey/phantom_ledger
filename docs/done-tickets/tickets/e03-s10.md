# E3-S10: OvernightModel.calculate()

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E2-S01](e02-s01.md)

## Description

Implement `OvernightModel.calculate()` for CFD overnight financing costs. The charge is based on the reference rate (SOFR, ESTR, etc.) plus the broker's markup, divided by the day divisor (365 or 360). Wednesday carries a triple charge to account for the weekend settlement (triple swap day).

## File Locations

- `src/phantom/costs/overnight.py` — `OvernightModel.calculate()`

## Acceptance Criteria

- [ ] `OvernightModel.calculate(notional: float, direction: str, reference_rate: float, day_of_week: int) -> float`
- [ ] `daily_rate = (reference_rate + markup_pct) / day_divisor` where `markup_pct` is `long_markup_pct` for long positions and `short_markup_pct` for short
- [ ] `charge = notional * daily_rate`
- [ ] On Wednesday (`day_of_week == 2`): `charge *= 3` (triple swap)
- [ ] `reference_rate` of `0.0` with zero markup returns `0.0`
- [ ] Unit tests: long position basic, short position basic, triple swap Wednesday
