# E4-S05: Dividend Data Fetching

**Epic:** [E4: Data Layer](e04-data-layer.md)
**Phase:** P2
**Depends on:** [E4-S01](e04-s01.md)

## Description

Extend `HistoricalProvider` to fetch dividend ex-dates and amounts from yfinance, caching them alongside price data. This data feeds the dividend hooks in E7-S13 and E9-S10.

## File Locations

- `src/phantom/data/dividends.py` — `DividendEvent` model + fetch logic
- `src/phantom/data/yahoo.py` — extend `HistoricalProvider.get_dividends()`

## Acceptance Criteria

- [ ] `DividendEvent` dataclass/model with fields: `ticker`, `ex_date: datetime`, `gross_amount: float`
- [ ] `HistoricalProvider.get_dividends(ticker, start, end) -> list[DividendEvent]` fetches from yfinance `ticker.dividends`
- [ ] Dividends cached to `data/prices/{ticker}_dividends.parquet`
- [ ] Returns empty list (not error) if ticker has no dividends
- [ ] In tests, yfinance calls are mocked
