# E9-S05: LiveClock

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** P2

## Description

Implement `LiveClock`, a concrete implementation of the `Clock` protocol for paper trading mode. Unlike `BacktestClock` which steps through a pre-loaded index, `LiveClock` operates in real wall-clock time. `now()` returns `datetime.now(timezone.utc)` — always the current wall-clock time, not a fixed value. `advance()` sleeps until the next tick, where a tick is defined by the `interval` parameter (in seconds) passed at construction. The sleep is computed as `next_tick = last_advance_time + interval - now()`, so if the bar processing takes some time the sleep is shortened accordingly (no drift accumulation). `is_done()` always returns `False` — the live loop runs until stopped externally via the stop event set by the graceful shutdown mechanism (E9-S08). `LiveClock` must not be used in backtest mode.

## File Locations

- `src/phantom/engine/clock.py` — add `LiveClock` class alongside `BacktestClock`

## Acceptance Criteria

- [ ] `LiveClock(interval=60)` sleeps approximately 60 seconds between `advance()` calls
- [ ] `now()` returns a timezone-aware UTC datetime equal to the current wall-clock time (not a cached value)
- [ ] `is_done()` always returns `False` regardless of elapsed time
- [ ] `advance()` compensates for processing time: if a tick takes 2s and interval is 60s, it sleeps 58s
- [ ] `advance()` does not sleep a negative duration if processing time exceeds the interval; it returns immediately
- [ ] Unit test mocks `time.sleep` and verifies the computed sleep duration accounts for elapsed processing time

## Implementation Notes

```python
import time
from datetime import datetime, timezone

class LiveClock:
    def __init__(self, interval: float) -> None:
        self._interval = interval
        self._last_tick = time.monotonic()

    def now(self) -> datetime:
        return datetime.now(timezone.utc)

    def advance(self) -> None:
        elapsed = time.monotonic() - self._last_tick
        sleep_for = max(0.0, self._interval - elapsed)
        time.sleep(sleep_for)
        self._last_tick = time.monotonic()

    def is_done(self) -> bool:
        return False
```
