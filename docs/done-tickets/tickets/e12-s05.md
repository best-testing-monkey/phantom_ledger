# E12-S05: Sharpe and Sortino Ratios

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P2
**Depends on:** [E12-S01](e12-s01.md)

## Description

Extend `EquityMetrics` with two additional fields: `sharpe_ratio: float` and `sortino_ratio: float`. Both are computed from daily returns derived from the equity curve. Daily returns are `(equity_t / equity_{t-1}) - 1` for consecutive equity points resampled to calendar days (if multiple points fall on the same day, use the last one). Sharpe ratio: `(mean_return - risk_free_rate) / std_return * sqrt(252)`. Sortino ratio: `(mean_return - risk_free_rate) / downside_deviation * sqrt(252)` where `downside_deviation = sqrt(mean(min(r - target, 0)^2 for r in daily_returns))` and `target = risk_free_rate`. The risk-free rate defaults to `0.0` (can be passed as a parameter to `calculate_metrics()`). If `std_return == 0` (flat equity curve), return `sharpe_ratio = 0.0`. If there are no downside returns, return `sortino_ratio = float("inf")`. Requires at least 2 daily return observations.

## Implementation Notes

```python
import math

def _daily_returns(curve: list[EquityPoint]) -> list[float]:
    """Resample equity curve to daily, compute log returns."""
    by_day: dict = {}
    for pt in curve:
        by_day[pt.timestamp.date()] = pt.equity
    days = sorted(by_day)
    equities = [by_day[d] for d in days]
    return [(equities[i] / equities[i - 1]) - 1 for i in range(1, len(equities))]

def _sharpe(returns: list[float], rfr: float) -> float:
    n = len(returns)
    if n < 2:
        return 0.0
    mean = sum(returns) / n
    variance = sum((r - mean) ** 2 for r in returns) / (n - 1)
    std = math.sqrt(variance)
    return 0.0 if std == 0 else (mean - rfr) / std * math.sqrt(252)

def _sortino(returns: list[float], rfr: float) -> float:
    downside = [min(r - rfr, 0) ** 2 for r in returns]
    if not any(d > 0 for d in downside):
        return float("inf")
    mean = sum(returns) / len(returns)
    dd = math.sqrt(sum(downside) / len(downside))
    return (mean - rfr) / dd * math.sqrt(252)
```
