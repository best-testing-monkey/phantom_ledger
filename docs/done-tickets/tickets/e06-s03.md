# E6-S03: OrderManager.place()

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP
**Depends on:** [E6-S01](e06-s01.md), [E6-S02](e06-s02.md), [E5-S01](e05-s01.md)

## Description

Implement `OrderManager.place()` — the entry point for all order placement. It validates the account has sufficient cash for a market order (estimated cost = price × quantity + estimated commission), then persists the order as `"pending"`.

## File Locations

- `src/phantom/engine/__init__.py` — package marker
- `src/phantom/engine/order_manager.py` — `OrderManager` class

## Acceptance Criteria

- [ ] `OrderManager.__init__(self, order_repo, account_repo, cost_engine)`
- [ ] `place(account_id: str, order: Order) -> Order` validates cash and persists with `status="pending"`
- [ ] Raises `InsufficientFundsError` if `account.cash < estimated_cost` (estimated_cost = price × quantity for market orders; notional for limit/stop)
- [ ] Sets `order.created_at = now_utc()` if not already set (for historical orders, caller sets `created_at`)
- [ ] Returns the persisted `Order` with its ULID `id`
- [ ] Does not modify account cash — cash is only deducted on fill (E6-S05)
