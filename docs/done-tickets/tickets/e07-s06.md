# E7-S06: max_close_datetime Auto-Close

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP
**Depends on:** [E7-S04](e07-s04.md)

## Description

Implement the `max_close_datetime` deadline. When the simulation clock reaches this datetime, the position is force-closed at the bar's close price regardless of TP/SL conditions.

## File Locations

- `src/phantom/engine/position_manager.py` — check in `update()`

## Acceptance Criteria

- [ ] On each bar, if `position.max_close_datetime is not None` and `bar.name >= max_close_datetime`: position is closed at `bar["Close"]` with `close_reason = "max_time"`
- [ ] `max_close_datetime` check runs before TP/SL check (time-based close takes priority)
- [ ] Exit costs computed at `bar["Close"]`
- [ ] Unit test: position with past `max_close_datetime` closes on first bar evaluated
