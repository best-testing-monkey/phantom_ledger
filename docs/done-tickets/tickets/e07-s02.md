# E7-S02: position_repo

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP
**Depends on:** [E7-S01](e07-s01.md)

## Description

Implement `PositionRepo` for CRUD operations on the `positions` SQLite table. This repo is frequently updated during the simulation loop (every bar for open positions).

## File Locations

- `src/phantom/db/repositories/position_repo.py` — `PositionRepo` class

## Acceptance Criteria

- [ ] `create(position: Position) -> Position` inserts all fields
- [ ] `get(position_id: str) -> Position` raises `NotFoundError("Position", position_id)` on miss
- [ ] `update(position: Position) -> Position` updates all mutable fields; raises `NotFoundError` on rowcount == 0
- [ ] `list_by_account(account_id, status=None, ticker=None) -> list[Position]` supports optional filters; returns `[]` when empty
- [ ] `list_open(account_id: str) -> list[Position]` returns all positions with `status="open"` for an account
- [ ] Nullable float fields serialized as `NULL` in SQLite, not `0.0`
- [ ] Unit tests in `tests/unit/test_position_repo.py`
