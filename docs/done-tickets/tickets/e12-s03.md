# E12-S03: Cost Breakdown Aggregation

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** MVP
**Depends on:** [E3-S04](e03-s04.md)

## Description

Implement `aggregate_costs(positions: list[Position]) -> CostSummary` in `src/phantom/reports/metrics.py`. This function sums the individual cost components across all closed positions by reading each position's `cost_breakdown` field (a JSON blob stored on the `Position` model as a `CostBreakdown` object or dict). `CostSummary` is a frozen Pydantic model with fields: `total_commission`, `total_spread`, `total_slippage`, `total_overnight`, `total_fx`, `total_dividends`, `total_cost`. Open positions are included in the aggregation (they may have accumulated overnight costs), but positions with no `cost_breakdown` set are skipped silently. `total_cost` is the arithmetic sum of all other fields. If the input list is empty, return a `CostSummary` with all zeros (not an error). This is a pure aggregation — no DB access, no IO.

## File Locations

- `src/phantom/reports/metrics.py` — `CostSummary`, `aggregate_costs()`

## Acceptance Criteria

- [ ] `CostSummary` is `frozen=True` Pydantic model with seven float fields (all default `0.0`)
- [ ] Positions with `cost_breakdown is None` are silently skipped
- [ ] Open positions are included in aggregation (not filtered out)
- [ ] `total_cost` equals sum of all six component fields

## Implementation Notes

```python
class CostSummary(BaseModel, frozen=True):
    total_commission: float = 0.0
    total_spread: float = 0.0
    total_slippage: float = 0.0
    total_overnight: float = 0.0
    total_fx: float = 0.0
    total_dividends: float = 0.0
    total_cost: float = 0.0

def aggregate_costs(positions: list[Position]) -> CostSummary:
    commission = spread = slippage = overnight = fx = dividends = 0.0
    for pos in positions:
        if pos.cost_breakdown is None:
            continue
        cb = pos.cost_breakdown
        commission += cb.commission
        spread += cb.spread
        slippage += cb.slippage
        overnight += cb.overnight
        fx += cb.fx
        dividends += cb.dividends
    total = commission + spread + slippage + overnight + fx + dividends
    return CostSummary(
        total_commission=commission, total_spread=spread,
        total_slippage=slippage, total_overnight=overnight,
        total_fx=fx, total_dividends=dividends, total_cost=total,
    )
```
