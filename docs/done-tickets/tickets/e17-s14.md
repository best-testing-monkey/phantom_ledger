# E17-S14: ReportAPI Broker Comparison

**Epic:** [E17: Library API Surface](e17-library-api.md)
**Phase:** P2
**Depends on:** [E12-S09](e12-s09.md), [E17-S10](e17-s10.md)

## Description

Extend `ReportAPI` with `compare_brokers(account_id, profile_names) -> dict[str, CostSummary]`. This method loads the closed positions for the account, then for each named broker profile, re-runs the cost calculation (using the profile's `CostEngine`) against each trade's fill price and quantity. The result is a dictionary mapping profile name to the aggregated `CostSummary` for that profile. This allows users to answer "how much would I have paid in commissions if I used broker X instead of broker Y?" without re-running the full simulation. Profiles not found in the DB are skipped with a WARNING log.

## Acceptance Criteria

- [ ] `compare_brokers(account_id, ["ibkr", "degiro"])` returns `{"ibkr": CostSummary(...), "degiro": CostSummary(...)}`
- [ ] Each `CostSummary` is computed by applying the profile's `CostEngine` to all closed positions of the account
- [ ] If a profile name is not loaded in the DB, it is skipped and logged at WARNING (not an error)
- [ ] Empty `profile_names` list returns an empty dict without error
- [ ] `account_id` that does not exist raises `NotFoundError`
- [ ] Integration test: two profiles produce different `CostSummary` totals for the same set of trades

## Implementation Notes

```python
def compare_brokers(self, account_id: str, profile_names: list[str]) -> dict[str, CostSummary]:
    self._account_repo.get(account_id)  # raises NotFoundError on miss
    closed = self._position_repo.list(account_id=account_id, status="closed")
    result = {}
    for name in profile_names:
        try:
            profile = self._broker_repo.get_by_name(name)
        except NotFoundError:
            logger.warning("Broker profile %r not loaded, skipping comparison", name)
            continue
        engine = CostEngine(profile)
        result[name] = aggregate_costs_with_engine(closed, engine)
    return result
```
