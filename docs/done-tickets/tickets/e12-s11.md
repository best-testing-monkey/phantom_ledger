# E12-S11: Equity Curve CSV Export

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P2
**Depends on:** [E12-S01](e12-s01.md)

## Description

Add `phantom report --account <name> --export-csv <path>` CLI option that writes the equity curve to a CSV file. The CSV has three columns: `timestamp` (ISO 8601 string in UTC), `equity` (float, 2 decimal places), `drawdown_pct` (float, the drawdown at that point as a positive percentage, 4 decimal places). The `drawdown_pct` per point is `max(0, (peak_so_far - equity) / peak_so_far * 100)` computed from the running peak, matching the logic in `calculate_metrics()`. The file is written using Python's `csv.writer` (stdlib only, no pandas dependency). If the output path's parent directory does not exist, create it with `Path.mkdir(parents=True, exist_ok=True)`. If fewer than 1 closed position exists, print a notice and exit 0. Print confirmation on success: `"Equity curve exported to <path> (N rows)."`.

## File Locations

- `src/phantom/cli.py` — `report` command updated with `--export-csv` option
- `src/phantom/reports/exporters.py` — `export_equity_csv(curve: list[EquityPoint], path: str | Path) -> int`

## Acceptance Criteria

- [ ] CSV columns: `timestamp`, `equity`, `drawdown_pct` in that order with header row
- [ ] `timestamp` formatted as ISO 8601 UTC string (e.g. `2025-03-15T14:30:00+00:00`)
- [ ] `equity` formatted to 2 decimal places; `drawdown_pct` formatted to 4 decimal places
- [ ] Parent directory created if missing (`parents=True, exist_ok=True`)
- [ ] Returns count of data rows written (excluding header)
- [ ] Empty curve (0 points): writes header only and returns 0

## Implementation Notes

```python
# src/phantom/reports/exporters.py
import csv
from pathlib import Path
from phantom.reports.metrics import EquityPoint

def export_equity_csv(curve: list[EquityPoint], path: str | Path) -> int:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    peak = curve[0].equity if curve else 1.0
    with path.open("w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(["timestamp", "equity", "drawdown_pct"])
        for pt in curve:
            if pt.equity > peak:
                peak = pt.equity
            dd = max(0.0, (peak - pt.equity) / peak * 100)
            writer.writerow([
                pt.timestamp.isoformat(),
                f"{pt.equity:.2f}",
                f"{dd:.4f}",
            ])
    return len(curve)

# CLI fragment
if export_csv:
    n = export_equity_csv(curve, export_csv)
    console.print(f"Equity curve exported to {export_csv} ({n} rows).")
```
