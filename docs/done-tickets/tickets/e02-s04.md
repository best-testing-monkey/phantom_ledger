# E2-S04: broker_repo

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** MVP

## Description

Implement `BrokerRepo` to persist and retrieve broker profiles from the `broker_profiles` SQLite table. The profile is stored as its full JSON serialization in `config_json`. This is the canonical reference implementation from A.13.

## File Locations

- `src/phantom/db/repositories/__init__.py` — package marker
- `src/phantom/db/repositories/broker_repo.py` — `BrokerRepo` class

## Acceptance Criteria

- [ ] `BrokerRepo.__init__(self, conn: sqlite3.Connection)` takes an injected connection
- [ ] `create(profile: BrokerProfile) -> BrokerProfile` inserts using `profile.model_dump_json()`, returns the profile
- [ ] `get_by_name(name: str) -> BrokerProfile` raises `NotFoundError("BrokerProfile", name)` on miss
- [ ] `list() -> list[BrokerProfile]` returns empty list when no profiles exist; returns all profiles ordered by name
- [ ] `delete(name: str) -> None` raises `NotFoundError` when name doesn't exist
- [ ] A profile round-trips faithfully: all sub-model fields survive `create()` → `get_by_name()`
- [ ] Unit tests in `tests/unit/test_broker_repo.py` cover create+get, get_nonexistent, list_empty, and delete
