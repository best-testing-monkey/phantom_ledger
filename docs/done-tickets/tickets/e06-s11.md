# E6-S11: Trailing Stop Order

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** P2
**Depends on:** [E6-S04](e06-s04.md)

## Description

Implement trailing stop order evaluation. The stop price tracks the most favourable price seen since order placement by `trailing_amount` or `trailing_pct`. When price retraces beyond the trail, the order fills as a market order.

## File Locations

- `src/phantom/engine/order_manager.py` — extend `evaluate()`
- `src/phantom/models/order.py` — ensure `trailing_peak: float | None` field exists to track the high/low watermark

## Acceptance Criteria

- [ ] On each bar, the `trailing_peak` is updated: long trailing stop tracks `max(trailing_peak, bar["High"])`; short tracks `min(trailing_peak, bar["Low"])`
- [ ] Long trailing stop triggers when `bar["Low"] <= trailing_peak - trailing_amount` (or `trailing_peak * (1 - trailing_pct)`)
- [ ] Short trailing stop triggers when `bar["High"] >= trailing_peak + trailing_amount` (or `trailing_peak * (1 + trailing_pct)`)
- [ ] `trailing_amount` and `trailing_pct` are mutually exclusive; validate at order placement
- [ ] Unit tests: trailing stop triggered after peak, trailing stop not triggered when still trending
