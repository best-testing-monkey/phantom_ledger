# E11-S07: Note Edit via $EDITOR

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** P2
**Depends on:** [E11-S01](e11-s01.md)

## Description

Add `phantom note edit <note-id>` CLI command that opens an existing note in `$EDITOR` (fallback: `vi`). The flow is: (1) fetch note metadata via `ph.notes.get(note_id)`, (2) copy the current file content into a temp file, (3) open `$EDITOR` on the temp file, (4) on editor exit, compare new content to old content. If unchanged, print `"No changes made."` and exit 0. If changed, write the new content to the original file path (`data_dir / note.file_path`), update `content_size` and `updated_at` in the DB via `NoteRepo.update()`. Always delete the temp file in a `finally` block. The original file is not replaced until after the editor exits cleanly (no exceptions). Print a confirmation line on success: `"Note <id[:12]> updated ({size})."`.

## File Locations

- `src/phantom/cli.py` — `note edit` command on `note_app`
- `src/phantom/notes/manager.py` — `NoteManager.update(note_id, content) -> Note`

## Acceptance Criteria

- [ ] Opens `$EDITOR` (or `vi`) with current note content pre-loaded in temp file
- [ ] If content unchanged after editor exit: print `"No changes made."` and exit 0
- [ ] If content changed: file overwritten, `content_size` and `updated_at` updated in DB via `NoteRepo.update()`
- [ ] Temp file deleted in `finally` block regardless of outcome
- [ ] `NotFoundError` for note ID propagates and exits with code 1
- [ ] File missing from disk at read time raises `DataError` (re-uses `NoteManager.read()`)

## Implementation Notes

```python
@note_app.command("edit")
def note_edit(note_id: str = typer.Argument(..., help="Note ULID")):
    """Edit an existing note in $EDITOR."""
    try:
        ph = get_phantom()
        original_content = ph.notes.read(note_id)
        editor = os.environ.get("EDITOR", "vi")
        tmp = tempfile.NamedTemporaryFile(suffix=".md", mode="w", delete=False, encoding="utf-8")
        try:
            tmp.write(original_content)
            tmp.flush()
            tmp.close()
            subprocess.run([editor, tmp.name], check=False)
            new_content = Path(tmp.name).read_text(encoding="utf-8")
        finally:
            Path(tmp.name).unlink(missing_ok=True)
        if new_content == original_content:
            console.print("No changes made.")
            return
        note = ph.notes.update(note_id, new_content)
        console.print(f"Note {note.id[:12]} updated ({_human_bytes(note.content_size)}).")
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
