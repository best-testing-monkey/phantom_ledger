# E6-S08: CLI — order list / cancel

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP
**Depends on:** [E6-S02](e06-s02.md)

## Description

Wire up `phantom order list` and `phantom order cancel <id>` CLI commands.

## File Locations

- `src/phantom/cli.py` — add `order_list` and `order_cancel` commands

## Acceptance Criteria

- [ ] `phantom order list --account <name>` shows all orders in a Rich table with columns: ID (truncated), Ticker, Direction, Type, Quantity, Status, Created At
- [ ] `phantom order list --account <name> --status pending` filters by status
- [ ] `phantom order cancel <order-id>` sets order status to `"cancelled"` and prints confirmation
- [ ] `phantom order cancel` on an already-filled or cancelled order exits 1 with friendly error
- [ ] `phantom order cancel <nonexistent-id>` exits 1 with `[red]Error:[/red] Order not found: ...`
