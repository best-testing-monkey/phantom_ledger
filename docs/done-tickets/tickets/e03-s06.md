# E3-S06: CommissionModel — per_share and tiered types

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E3-S01](e03-s01.md)

## Description

Extend `CommissionModel.calculate()` to handle `"per_share"` and `"tiered"` model types. Per-share charges a rate per share with a minimum and optional maximum-as-percentage-of-notional. Tiered uses volume thresholds to determine the per-share rate (IBKR's model).

## File Locations

- `src/phantom/costs/commission.py` — extend `CommissionModel.calculate()`

## Acceptance Criteria

- [ ] `"per_share"`: `result = max(per_share_min, quantity * per_share_rate)`; if `per_share_max_pct` is set, also cap at `per_share_max_pct * price * quantity`
- [ ] `"tiered"`: `tiers` is a list of `{"up_to": N, "rate": R}` dicts; applies the rate of the tier whose `up_to` exceeds `monthly_volume`; falls back to highest tier if `monthly_volume` exceeds all tiers
- [ ] Per-share minimum is enforced: `calculate(quantity=10, price=50.0)` with `per_share=0.005, min=1.0` returns `1.0` (not `0.05`)
- [ ] Unit tests added to `test_commission.py` for both types
