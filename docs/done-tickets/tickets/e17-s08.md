# E17-S08: RunnerAPI (MVP)

## Description

`RunnerAPI` is the public interface for running simulations on the `Phantom` facade (`ph.runner`). The MVP version covers three methods: `replay(account_id)` re-runs all historical fills for an account through the engine to reconstruct equity curve and metrics; `replay_position(position_id)` re-runs a single position; and `backtest(account_id, start, end)` runs a full bar-by-bar simulation over historical data. All three return a `BacktestResult` dataclass containing final metrics: `total_return_pct`, `sharpe`, `max_drawdown_pct`, `trade_count`, `total_costs`. Date parameters are accepted as `str | datetime` and parsed by `parse_datetime()`.

## Acceptance Criteria

- [ ] `BacktestResult` is a `dataclasses.dataclass` with fields: `total_return_pct`, `sharpe`, `max_drawdown_pct`, `trade_count`, `total_costs`
- [ ] `replay(account_id)` raises `NotFoundError` if account does not exist
- [ ] `backtest(account_id, start, end)` accepts `str | datetime` for date params and converts with `parse_datetime()`
- [ ] `backtest()` raises `ValidationError("end", "must be after start")` if end <= start
- [ ] All three methods return a populated `BacktestResult`
- [ ] Integration test: backtest over a 30-day window with seeded price data returns a non-zero `trade_count`

## Implementation Notes

```python
from dataclasses import dataclass
from phantom.utils.datetime import parse_datetime

@dataclass
class BacktestResult:
    total_return_pct: float
    sharpe: float
    max_drawdown_pct: float
    trade_count: int
    total_costs: float

class RunnerAPI:
    def __init__(self, simulation_engine: SimulationEngine, replay_engine: ReplayEngine) -> None:
        self._engine = simulation_engine
        self._replay = replay_engine

    def backtest(self, account_id: str, start: str | datetime, end: str | datetime) -> BacktestResult:
        start_dt = parse_datetime(start)
        end_dt = parse_datetime(end)
        if end_dt <= start_dt:
            raise ValidationError("end", "must be after start")
        return self._engine.run_backtest(account_id, start_dt, end_dt)
```
