# E9-S04: Backtest Integration Test

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** MVP
**Depends on:** [E9-S02](e09-s02.md)

## Description

Write an end-to-end integration test that exercises the full backtest loop using the public API and in-memory SQLite. The test uses a controlled price series (deterministic synthetic OHLCV data) so that the expected fill price, TP/SL trigger bar, and final P&L can be computed analytically and asserted with exact equality (not `pytest.approx`). The test places a market buy order with explicit TP and SL, runs `ph.runner.backtest()`, and asserts: the order fills on the first bar at the open price, a position opens with the correct entry price and costs, either TP or SL triggers at the expected bar (depending on the price series), the position closes with `exit_price` matching the trigger level, and the account cash reflects the correct P&L minus costs. External HTTP must be patched so no real yfinance calls are made.

## File Locations

- `tests/integration/test_backtest.py` — integration test module

## Acceptance Criteria

- [ ] Market order fills on bar 1 at `bar[0].Open` price
- [ ] `Position.entry_price` equals the fill price from bar 1
- [ ] Take-profit triggers on the correct bar when the synthetic High exceeds the TP level
- [ ] Stop-loss triggers on the correct bar when the synthetic Low breaches the SL level
- [ ] Closed position `exit_price` matches the TP or SL price (not bar close)
- [ ] Final `account.cash` equals `starting_cash - commission + realized_pnl` within floating-point tolerance

## Implementation Notes

```python
# tests/integration/test_backtest.py
import pytest
import pandas as pd
from unittest.mock import patch
from phantom import Phantom

class TestBacktest:
    def test_market_order_fills_and_tp_triggers(self, phantom_instance):
        """Market buy at open, TP at 195.0, SL at 180.0. Price hits TP on bar 3."""
        ph = phantom_instance
        # Synthetic data: bar 0 open=185, bar 3 high=196 (above TP=195)
        dates = pd.bdate_range("2025-01-02", periods=5, freq="B")
        prices = pd.DataFrame({
            "Open":  [185.0, 186.0, 188.0, 190.0, 191.0],
            "High":  [186.0, 187.0, 189.0, 196.0, 192.0],  # bar 3 high > 195
            "Low":   [184.0, 185.0, 187.0, 189.0, 190.0],
            "Close": [185.5, 186.5, 188.5, 195.5, 191.5],
            "Volume": [1_000_000] * 5,
        }, index=dates)
        with patch("phantom.data.yfinance_provider.yf.download", return_value=prices):
            account = ph.accounts.create("bt_test", "manual", "DEGIRO", 10_000.0)
            ph.orders.place(account_id=account.id, ticker="AAPL", direction="long",
                            order_type="market", quantity=10, take_profit=195.0, stop_loss=180.0)
            result = ph.runner.backtest(
                account_id=account.id, tickers=["AAPL"],
                start="2025-01-02", end="2025-01-08"
            )
        assert len(result.filled_orders) == 1
        assert result.filled_orders[0].fill_price == 185.0
        assert len(result.closed_positions) == 1
        pos = result.closed_positions[0]
        assert pos.exit_price == 195.0
        assert pos.close_reason == "tp"
        assert result.account.cash == pytest.approx(10_000.0 + (195.0 - 185.0) * 10 - pos.commission_paid)
```
