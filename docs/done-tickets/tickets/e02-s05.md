# E2-S05: CLI — broker list / show

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** MVP

## Description

Wire up `phantom broker list` and `phantom broker show <name>` CLI commands. Both commands must follow the CLI conventions from A.8: call `get_phantom()`, invoke the public API, and format output with Rich.

## File Locations

- `src/phantom/cli.py` — add `broker_list` and `broker_show` commands

## Acceptance Criteria

- [ ] `phantom broker list` prints a Rich table with columns: Name, Supported Instruments, Commission Type, FX Cost
- [ ] `phantom broker list` prints an informational message (not an error) when no profiles are loaded
- [ ] `phantom broker show <name>` prints a Rich panel or table with full profile details (commission, spread, slippage, overnight rates, margin levels)
- [ ] `phantom broker show nonexistent` prints `[red]Error:[/red] BrokerProfile not found: nonexistent` and exits with code 1
- [ ] No business logic in the CLI — all data from `ph.brokers.list()` / `ph.brokers.get(name)`
