# E3-S09: SpreadModel — market mode

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E3-S02](e03-s02.md)

## Description

Extend `SpreadModel` to support `"market"` mode, where the actual bid/ask spread is provided directly (e.g. from a live data feed). In market mode, the spread cost is `(ask - bid) / 2 * quantity` instead of a model estimate.

## File Locations

- `src/phantom/costs/spread.py` — extend `SpreadModel.calculate()`

## Acceptance Criteria

- [ ] Method signature extended: `calculate(price, quantity, atr=None, hour_utc=None, bid: float | None = None, ask: float | None = None) -> float`
- [ ] `"market"`: when `bid` and `ask` are provided, returns `(ask - bid) / 2 * quantity`
- [ ] `"market"` with no bid/ask: falls back to `"fixed"` mode using `fixed_spread_pct`
- [ ] Unit tests: market mode with bid/ask, market mode fallback
