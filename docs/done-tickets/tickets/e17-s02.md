## Description

`Phantom` is the top-level object that users create to interact with the system. It accepts `data_dir` (defaults to `"./data"`, resolved to absolute path) and `in_memory=False`. When `in_memory=True`, it uses `:memory:` as the SQLite path (useful for testing). On construction, it creates the data directory if needed, opens the `sqlite3.Connection` with WAL mode and `foreign_keys = ON`, runs the migration runner, instantiates all repositories and managers, and exposes sub-API objects as attributes. Multiple `Phantom` instances can coexist — there is no global state. The `Phantom` class is the only object users need to import for the full feature set.

## Acceptance Criteria

- [ ] `Phantom(data_dir="./data", in_memory=False)` constructs without error when the directory exists
- [ ] `in_memory=True` uses `:memory:` SQLite path (useful for tests)
- [ ] Connection is opened with `PRAGMA journal_mode=WAL` and `PRAGMA foreign_keys=ON`
- [ ] Migration runner is called on every instantiation; already-applied migrations are skipped
- [ ] Sub-API attributes present: `ph.accounts`, `ph.orders`, `ph.positions`, `ph.brokers`, `ph.notes`, `ph.runner`, `ph.data`, `ph.report`
- [ ] Integration test: `Phantom(in_memory=True)` constructs and all sub-API attributes are non-None

## Implementation Notes

```python
class Phantom:
    def __init__(self, data_dir: str = "./data", in_memory: bool = False) -> None:
        self._data_dir = Path(data_dir).resolve()
        if not in_memory:
            self._data_dir.mkdir(parents=True, exist_ok=True)
        db_path = ":memory:" if in_memory else str(self._data_dir / "phantom.db")
        self._conn = sqlite3.connect(db_path)
        self._conn.row_factory = sqlite3.Row
        self._conn.execute("PRAGMA journal_mode=WAL")
        self._conn.execute("PRAGMA foreign_keys=ON")
        run_migrations(self._conn)
        # instantiate repos, managers, sub-APIs ...
        self.accounts = AccountAPI(self._conn)
        self.orders = OrderAPI(self._conn)
        # etc.
```
