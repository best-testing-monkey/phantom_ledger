# E13-S03: Market Hours Awareness

**Epic:** [E13: Paper Trade Scheduler](e13-paper-trade-scheduler.md)
**Phase:** P2
**Depends on:** [E13-S01](e13-s01.md), [E2-S05](e02-s05.md)

## Description

Before executing a tick, check whether the current UTC time falls within the trading hours defined in `BrokerProfile.trading_hours`. The `TradingHoursConfig` object on the broker profile specifies an `open` time, `close` time, a timezone string (e.g. `"America/New_York"`), and a `weekday_mask` (list of integers 0–6 where 0=Monday). If the current moment is outside trading hours or falls on a non-trading weekday, skip the tick entirely and log at DEBUG level. This prevents spurious order matching outside market hours for brokers that are closed on weekends or overnight.

## File Locations

- `src/phantom/engine/scheduler.py` — `_is_market_open()` helper and guard in `_run_tick()`

## Acceptance Criteria

- [ ] `_is_market_open(profile: BrokerProfile) -> bool` converts current UTC time to the profile's timezone and checks open/close window
- [ ] Weekday is checked against `trading_hours.weekday_mask`; returns `False` if today's weekday is not in the mask
- [ ] If `trading_hours` is `None` on the profile, `_is_market_open()` returns `True` (always trade)
- [ ] `_run_tick()` calls `_is_market_open()` first and logs `logger.debug("Market closed, skipping tick")` then returns early if outside hours
- [ ] Unit test: mock `now_utc()` to a Saturday, verify `_is_market_open()` returns `False` for a Mon–Fri profile
- [ ] Unit test: mock `now_utc()` to a weekday inside trading window, verify returns `True`

## Implementation Notes

```python
from phantom.utils.datetime import now_utc

def _is_market_open(self) -> bool:
    th = self._profile.trading_hours
    if th is None:
        return True
    tz = ZoneInfo(th.timezone)
    local_now = now_utc().astimezone(tz)
    if local_now.weekday() not in th.weekday_mask:
        return False
    return th.open <= local_now.time() < th.close
```
