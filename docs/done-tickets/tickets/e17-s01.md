# E17-S01: PhantomError Hierarchy

**Epic:** [E17: Library API Surface](e17-library-api.md)
**Phase:** MVP

## Description

Implement the complete exception hierarchy in `src/phantom/errors.py`. All exceptions inherit from `PhantomError(Exception)` and carry structured fields that encode the context needed to understand the error without parsing a string. Each subclass implements `__str__` to produce a clear, human-readable message. This hierarchy is part of the public API — callers depend on catching specific subclass types. Never raise bare `PhantomError`; it exists only as a base class for `except PhantomError` catch-alls.

## File Locations

- `src/phantom/errors.py` — full exception hierarchy

## Acceptance Criteria

- [ ] `PhantomError(Exception)` is the base; it is never raised directly
- [ ] `NotFoundError(entity: str, id: str)` with `__str__` = `"{entity} '{id}' not found"`
- [ ] `InsufficientFundsError(account_id: str, required: float, available: float)` with clear `__str__`
- [ ] `MarginError(account_id: str, margin_level: float)` with `__str__` including margin level as a percentage
- [ ] `ValidationError(field: str, reason: str)` with `__str__` = `"Validation error on '{field}': {reason}"`
- [ ] `DataError(source: str, reason: str)` and `ProfileError(profile_name: str, reason: str)` defined with matching `__str__`

## Implementation Notes

```python
class PhantomError(Exception):
    """Base class — never raise directly."""

class NotFoundError(PhantomError):
    def __init__(self, entity: str, id: str) -> None:
        self.entity = entity
        self.id = id
        super().__init__(f"{entity} '{id}' not found")

class InsufficientFundsError(PhantomError):
    def __init__(self, account_id: str, required: float, available: float) -> None:
        self.account_id = account_id
        self.required = required
        self.available = available
        super().__init__(
            f"Insufficient funds in account '{account_id}': "
            f"required {required:.2f}, available {available:.2f}"
        )
```
