# E7-S13: Dividend Processing

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** P2
**Depends on:** [E3-S12](e03-s12.md), [E3-S13](e03-s13.md), [E4-S05](e04-s05.md), [E7-S01](e07-s01.md)

## Description

Extend `PositionManager.update()` to check whether the current bar's date matches any ex-dividend date for the position's ticker. If a dividend event is found, apply the `DividendModel` adjustment: for long stock positions, credit `account.cash` with `dividend_per_share * quantity * (1 - withholding_rate)`; for long CFD positions, apply the cash adjustment factor (`cfd_dividend_adjustment`); for short CFD positions, debit `account.cash` with `dividend_per_share * quantity * cfd_short_dividend_charge`. Withholding rate is looked up from `DividendModel.withholding_rates` by the stock's country code (derived from ticker or position metadata); fall back to 0 if not found. The dividend data comes from the `DataProvider` (E4-S05) which provides ex-dates and per-share amounts. Persist the updated account cash immediately after the adjustment.

## File Locations

- `src/phantom/engine/position_manager.py` — add `_apply_dividend()` helper called from `update()`
- `src/phantom/models/position.py` — ensure `country_code: str | None = None` field exists for withholding lookup

## Acceptance Criteria

- [ ] Long stock position on ex-date receives `dividend_per_share * qty * (1 - withholding_rate)` cash credit
- [ ] Long CFD position on ex-date receives `dividend_per_share * qty * cfd_dividend_adjustment` cash credit
- [ ] Short CFD position on ex-date is debited `dividend_per_share * qty * cfd_short_dividend_charge`
- [ ] No dividend applied if the bar date does not match any ex-date in the dividend calendar
- [ ] Unknown country code falls back to zero withholding (full dividend credited)
- [ ] `account.cash` is updated and persisted atomically after each dividend adjustment

## Implementation Notes

```python
def _apply_dividend(
    self,
    position: Position,
    account: Account,
    bar_date: date,
    dividend_model: DividendModel,
    data_provider: DataProvider,
) -> float:
    """Returns the net cash adjustment (positive = credit, negative = debit). 0 if no ex-date."""
    dividend_per_share = data_provider.get_dividend(position.ticker, bar_date)
    if dividend_per_share == 0.0:
        return 0.0
    withholding = dividend_model.withholding_rates.get(position.country_code or "", 0.0)
    if position.instrument_type == "stock" and position.direction == "long":
        adjustment = dividend_per_share * position.quantity * (1 - withholding)
    elif position.instrument_type == "cfd" and position.direction == "long":
        adjustment = dividend_per_share * position.quantity * dividend_model.cfd_dividend_adjustment
    else:  # short CFD
        adjustment = -(dividend_per_share * position.quantity * dividend_model.cfd_short_dividend_charge)
    account.cash += adjustment
    logger.info(
        "Dividend adjustment %.4f applied to position %s on %s",
        adjustment, position.id, bar_date,
    )
    return adjustment
```
