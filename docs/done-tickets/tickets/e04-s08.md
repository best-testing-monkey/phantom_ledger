# E4-S08: LiveProvider

**Epic:** [E4: Data Layer](e04-data-layer.md)
**Phase:** P2
**Depends on:** [E4-S04](e04-s04.md)

## Description

Implement `LiveProvider` for paper trading mode. It fetches the current price via yfinance's real-time quote and bid/ask via the Alpaca free API (no account required for market data).

## File Locations

- `src/phantom/data/alpaca.py` — Alpaca API client for bid/ask
- `src/phantom/data/yahoo.py` — extend or add `LiveProvider` class

## Acceptance Criteria

- [ ] `LiveProvider` implements the `DataProvider` protocol
- [ ] `get_current_price(ticker) -> float` returns the latest quote price from yfinance
- [ ] `get_bid_ask(ticker) -> tuple[float, float] | None` fetches from Alpaca free market data API; returns `None` on failure (graceful degradation)
- [ ] `get_bars(ticker, start, end)` falls back to `HistoricalProvider` for historical data
- [ ] Raises `DataError` (not crashes) on network failure
- [ ] `ALPACA_API_KEY` and `ALPACA_SECRET_KEY` read from env (optional — `get_bid_ask` returns `None` if not configured)
