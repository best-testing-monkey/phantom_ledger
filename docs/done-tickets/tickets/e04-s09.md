# E4-S09: Data Staleness Detection

**Epic:** [E4: Data Layer](e04-data-layer.md)
**Phase:** P2
**Depends on:** [E4-S02](e04-s02.md)

## Description

Add a staleness check that warns the user when entering paper-trade mode if the cached price data for any account position is older than a configurable threshold (default: 1 day).

## File Locations

- `src/phantom/data/price_store.py` — add `check_staleness()` function
- `src/phantom/engine/simulation.py` — call check before starting paper trade loop

## Acceptance Criteria

- [ ] `check_staleness(tickers: list[str], data_dir: Path, max_age_days: int = 1) -> list[str]` returns list of tickers whose cache is stale
- [ ] A ticker's cache is stale if its last date is more than `max_age_days` calendar days before today
- [ ] Before `run_paper()` starts, `check_staleness` is called for all tickers in the account's open/pending positions
- [ ] Stale tickers are logged as WARNING: `"Price cache for {ticker} is stale ({N} days old)"`
- [ ] The paper trade loop still starts even if data is stale — it's a warning, not a blocker
