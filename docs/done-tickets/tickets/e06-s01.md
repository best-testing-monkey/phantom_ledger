# E6-S01: Order Model

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP

## Description

Define the `Order` Pydantic model with all fields from the `orders` table schema. Orders progress through a lifecycle: `pending` → `triggered` → `filled` (or `expired`/`rejected`/`cancelled`).

## File Locations

- `src/phantom/models/order.py` — `Order` model
- `src/phantom/models/types.py` — ensure `OrderType`, `OrderStatus`, `InstrumentType`, `Direction` Literals exist

## Acceptance Criteria

- [ ] `Order` Pydantic model with all fields matching the `orders` table schema in Section 3 of the architecture
- [ ] ID fields: `id` (ULID default_factory), `account_id`, `position_id: str | None`
- [ ] Required trading fields: `ticker`, `instrument_type`, `direction`, `order_type`, `quantity`, `status`
- [ ] Optional price fields: `limit_price`, `stop_price`, `trailing_amount`, `trailing_pct`, `take_profit`, `stop_loss` (all `float | None = None`)
- [ ] Timestamp fields: `created_at` (datetime, required), `triggered_at`, `filled_at` (both `datetime | None`)
- [ ] `fill_price: float | None`, `good_til: datetime | None`, `max_close_datetime: datetime | None`, `rejection_reason: str | None`
- [ ] `order.id` is a 26-character ULID string
