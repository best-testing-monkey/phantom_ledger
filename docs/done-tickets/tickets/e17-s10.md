## Description

`ReportAPI` is the public interface for performance reporting on the `Phantom` facade (`ph.report`). It delegates to the pure metric calculation functions in `phantom.reports` (no DB logic in the report layer — repos are used to fetch the raw data, then computation functions are called). `account_metrics(account_id)` returns an `EquityMetrics` dataclass with total return, CAGR, Sharpe ratio, Sortino ratio, max drawdown, and trade count. `cost_breakdown(account_id)` returns a `CostSummary` dataclass with totals per cost category aggregated across all closed positions for the account.

## Acceptance Criteria

- [ ] `account_metrics(account_id)` raises `NotFoundError` if account does not exist
- [ ] `account_metrics()` returns an `EquityMetrics` with at minimum: `total_return_pct`, `sharpe`, `max_drawdown_pct`, `trade_count`
- [ ] `cost_breakdown(account_id)` returns a `CostSummary` with per-category totals: `commission`, `spread`, `slippage`, `overnight`, `fx`, `dividend`
- [ ] Both methods return zeroed/default values if the account has no closed trades (no exception)
- [ ] `account_metrics()` raises `NotFoundError` if account_id does not exist
- [ ] Integration test: account with 5 closed trades returns correct `trade_count` of 5

## Implementation Notes

```python
from phantom.reports.metrics import calculate_equity_metrics, EquityMetrics
from phantom.reports.costs import aggregate_costs, CostSummary

class ReportAPI:
    def __init__(self, conn: sqlite3.Connection, account_repo: AccountRepo,
                 position_repo: PositionRepo, equity_repo: EquityRepo) -> None:
        self._account_repo = account_repo
        self._position_repo = position_repo
        self._equity_repo = equity_repo

    def account_metrics(self, account_id: str) -> EquityMetrics:
        self._account_repo.get(account_id)  # raises NotFoundError on miss
        equity_curve = self._equity_repo.list(account_id)
        closed = self._position_repo.list(account_id=account_id, status="closed")
        return calculate_equity_metrics(equity_curve, closed)

    def cost_breakdown(self, account_id: str) -> CostSummary:
        closed = self._position_repo.list(account_id=account_id, status="closed")
        return aggregate_costs(closed)
```
