# E3-S07: CommissionModel — zero type

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E3-S01](e03-s01.md)

## Description

Extend `CommissionModel.calculate()` for `"zero"` model type. XTB and similar brokers offer zero-commission trading up to a monthly free volume threshold. Above the threshold, a standard per-share or fixed fee kicks in.

## File Locations

- `src/phantom/costs/commission.py` — extend `CommissionModel.calculate()`

## Acceptance Criteria

- [ ] `"zero"`: returns `0.0` when `monthly_volume < monthly_free_volume`
- [ ] When `monthly_volume >= monthly_free_volume`, applies a fallback commission (configurable, e.g. fixed fee or per-share rate stored on the model)
- [ ] When no `monthly_free_volume` is set: always returns `0.0`
- [ ] Unit tests: below threshold (free), above threshold (charged)
