# E7-S12: Overnight Log Persistence

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** P2
**Depends on:** [E7-S11](e07-s11.md)

## Description

Create the `overnight_log` database table and a corresponding `OvernightLogRepo` that persists each individual overnight financing charge as an immutable audit record. Each time `_apply_overnight_cost()` fires in `PositionManager`, it should call `OvernightLogRepo.create()` to write a row capturing the position, account, date, rate applied, and charge amount. This log is append-only — there is no `update()` or `delete()` on the repo. The `overnight_log` table enables downstream reporting (E12) to reconstruct total financing costs by period, instrument, or account. The migration SQL must be added as a numbered file in `src/phantom/db/migrations/`.

## File Locations

- `src/phantom/db/repositories/overnight_log_repo.py` — `OvernightLogRepo` with `create()` and `list()` methods
- `src/phantom/db/migrations/XXXX_create_overnight_log.sql` — migration creating the `overnight_log` table
- `src/phantom/models/overnight_log.py` — `OvernightLog` Pydantic model

## Acceptance Criteria

- [ ] `overnight_log` table has columns: `id` (TEXT PK), `position_id` (TEXT FK → positions), `account_id` (TEXT FK → accounts), `date` (TEXT ISO date), `rate` (REAL), `charge_amount` (REAL), `created_at` (TEXT ISO 8601)
- [ ] `OvernightLogRepo.create()` inserts a row and commits; returns the `OvernightLog` model
- [ ] `OvernightLogRepo.list(position_id=...)` returns all charges for a given position ordered by `date` ascending
- [ ] `OvernightLogRepo.list(account_id=...)` returns all charges for a given account
- [ ] `OvernightLog` Pydantic model has `id` (ULID default factory), all table columns with correct types
- [ ] Migration file is numbered correctly (follows existing migration sequence) and is idempotent when run twice

from pydantic import BaseModel, Field
from phantom.utils.ids import new_id

class OvernightLog(BaseModel):
    id: str = Field(default_factory=new_id)
    position_id: str
    account_id: str
    date: str          # ISO date string "YYYY-MM-DD"
    rate: float
    charge_amount: float
    created_at: str    # ISO 8601 datetime

# src/phantom/db/repositories/overnight_log_repo.py
class OvernightLogRepo:
    def __init__(self, conn: sqlite3.Connection):
        self._conn = conn

    def create(self, log: OvernightLog) -> OvernightLog:
        self._conn.execute(
            "INSERT INTO overnight_log (id, position_id, account_id, date, rate, charge_amount, created_at) "
            "VALUES (?, ?, ?, ?, ?, ?, ?)",
            (log.id, log.position_id, log.account_id, log.date,
             log.rate, log.charge_amount, log.created_at),
        )
        self._conn.commit()
