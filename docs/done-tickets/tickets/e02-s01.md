# E2-S01: BrokerProfile Pydantic Models

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** MVP

## Description

Define the full `BrokerProfile` Pydantic model and all its sub-models. These models are the typed representation of the broker JSON files (see Section 6 of the architecture doc). The DEGIRO JSON example in Section 6 must round-trip cleanly through these models.

## File Locations

- `src/phantom/models/broker.py` — all broker models
- `src/phantom/models/types.py` — add any new `Literal` type aliases needed

## Acceptance Criteria

- [ ] `src/phantom/models/broker.py` defines: `CommissionModel`, `SpreadModel`, `SlippageModel`, `OvernightModel`, `MarginModel`, `DividendModel`, `TradingHoursConfig`, `BrokerProfile`
- [ ] `CommissionModel` has `model_type: Literal["fixed","per_share","tiered","zero"]` and all optional fields (`fixed_fee`, `per_share`, `per_share_min`, `per_share_max_pct`, `tiers`, `monthly_free_volume`)
- [ ] `SpreadModel` has `model_type: Literal["fixed","dynamic","market"]`, `fixed_spread_pct`, `base_spread_pct`, `volatility_multiplier`, `time_of_day_curve: dict[str, float] | None`
- [ ] `SlippageModel` has `model_type: Literal["fixed_pct","volume_based"]` and relevant fields
- [ ] `OvernightModel` has `long_markup_pct`, `short_markup_pct`, `day_divisor`, `rate_source: Literal["sofr","estr","sonia","manual"]`, `manual_rate`
- [ ] `MarginModel` has `default_margin_pct`, `margin_call_level`, `stop_out_level`
- [ ] `DividendModel` has `withholding_rates: dict[str, float]`, `cfd_dividend_adjustment`, `cfd_short_dividend_charge`
- [ ] `TradingHoursConfig` has `timezone`, `open`, `close`, `pre_market: bool`, `post_market: bool`
- [ ] `BrokerProfile` composes all sub-models plus: `name`, `min_order_size`, `max_leverage`, `supported_instruments: list[str]`, `fx_conversion_pct`, `fx_base_currency`
- [ ] `BrokerProfile.model_dump_json()` followed by `BrokerProfile.model_validate_json()` round-trips without data loss
