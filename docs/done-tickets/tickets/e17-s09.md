# E17-S09: DataAPI

## Description

`DataAPI` is the public interface for market data access on the `Phantom` facade (`ph.data`). It provides a clean abstraction over the underlying `HistoricalProvider` so callers never import from `phantom.data` directly. `fetch_prices(symbol, start, end, interval="1d")` returns a `pd.DataFrame` with OHLCV columns and a timezone-aware UTC DatetimeIndex. On cache miss it fetches from yfinance and caches to Parquet. `fetch_rates(currency_pair, date)` returns a single `float` exchange rate for the given currency pair on the given date. Both methods raise `DataError` on network failure or when the symbol is not found.

## File Locations

- `src/phantom/api/data.py` — `DataAPI` class

## Acceptance Criteria

- [ ] `fetch_prices(symbol, start, end, interval="1d")` returns a `pd.DataFrame` with columns `open`, `high`, `low`, `close`, `volume`
- [ ] `fetch_prices()` raises `DataError("yfinance", reason)` on network failure or unknown symbol
- [ ] `fetch_rates(currency_pair, date)` returns a `float` exchange rate
- [ ] `fetch_rates()` raises `DataError("fx", reason)` on failure
- [ ] Date parameters accept `str | datetime` and are converted with `parse_datetime()`
- [ ] Integration test: `fetch_prices("AAPL", ...)` with mocked yfinance returns correctly shaped DataFrame

## Implementation Notes

```python
import pandas as pd
from phantom.data.historical import HistoricalProvider
from phantom.utils.datetime import parse_datetime
from phantom.errors import DataError

class DataAPI:
    def __init__(self, provider: HistoricalProvider) -> None:
        self._provider = provider

    def fetch_prices(self, symbol: str, start: str | datetime,
                     end: str | datetime, interval: str = "1d") -> pd.DataFrame:
        start_dt = parse_datetime(start)
        end_dt = parse_datetime(end)
        try:
            return self._provider.get_prices(symbol, start_dt, end_dt, interval)
        except Exception as e:
            raise DataError("yfinance", str(e))

    def fetch_rates(self, currency_pair: str, date: str | datetime) -> float:
        try:
            return self._provider.get_fx_rate(currency_pair, parse_datetime(date))
        except Exception as e:
            raise DataError("fx", str(e))
```
