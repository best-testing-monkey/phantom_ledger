# E17-S16: Thread Safety

**Epic:** [E17: Library API Surface](e17-library-api.md)
**Phase:** P2
**Depends on:** [E17-S02](e17-s02.md)

## Description

Apply a `threading.RLock` to the `Phantom` facade to ensure thread safety for mutating API calls. Mutating operations — `orders.place`, `positions.close`, `positions.modify`, `accounts.create`, `accounts.delete` — must acquire the lock before executing. Read-only operations — `accounts.list`, `accounts.get`, `positions.list`, `positions.get`, `report.*`, `data.*` — do not require the lock and can execute concurrently. The lock is a reentrant lock (`RLock`) because some write operations (e.g. `orders.place` which may also update account balance) call multiple repo methods that individually would also be locked if `RLock` were applied at the repo level. The lock lives on the `Phantom` instance and is passed to the sub-APIs.

## File Locations

- `src/phantom/api/phantom.py` — `_lock: threading.RLock` attribute and lock injection into mutating sub-APIs

## Acceptance Criteria

- [ ] `Phantom.__init__` creates `self._lock = threading.RLock()`
- [ ] `OrderAPI.place()`, `PositionAPI.close()`, `PositionAPI.modify()`, `AccountAPI.create()`, `AccountAPI.delete()` all acquire `self._lock` before executing
- [ ] Read methods (`list`, `get`, `report.*`) do NOT acquire the lock
- [ ] Lock acquisition uses a context manager (`with self._lock:`) not manual acquire/release
- [ ] Unit test: two threads calling `orders.place()` concurrently do not produce data corruption (use an in-memory DB)
- [ ] Unit test: concurrent reads while a write holds the lock do not deadlock

## Implementation Notes

```python
import threading

class Phantom:
    def __init__(self, ...) -> None:
        ...
        self._lock = threading.RLock()
        self.accounts = AccountAPI(conn=self._conn, lock=self._lock)
        self.orders = OrderAPI(conn=self._conn, lock=self._lock)
        self.positions = PositionAPI(conn=self._conn, lock=self._lock)
        # read-only APIs get no lock:
        self.report = ReportAPI(conn=self._conn)
        self.data = DataAPI(provider=self._provider)

# In AccountAPI.create():
def create(self, ...) -> Account:
    with self._lock:
        # ... existing create logic
```
