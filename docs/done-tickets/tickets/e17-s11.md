# E17-S11: Public Re-Exports

**Epic:** [E17: Library API Surface](e17-library-api.md)
**Phase:** MVP
**Depends on:** [E17-S01](e17-s01.md), [E17-S02](e17-s02.md)

## Description

Set up `src/phantom/__init__.py` to re-export exactly the symbols that form the public API surface. Nothing from `phantom.db`, `phantom.engine`, `phantom.data`, or `phantom.reports` should be importable at the top level — only the facade, domain models, and error classes. This `__init__.py` is the contract: any symbol not listed here is an internal implementation detail subject to change without notice. Use explicit `from X import Y` statements (no wildcard imports) so static analysis tools can verify the exports.

## File Locations

- `src/phantom/__init__.py` — public re-exports

## Acceptance Criteria

- [ ] `from phantom import Phantom` works without error
- [ ] `from phantom import Account, Order, Position, BrokerProfile, CostEngine` all work
- [ ] `from phantom import PhantomError, NotFoundError, InsufficientFundsError, MarginError, ValidationError, DataError, ProfileError` all work
- [ ] `phantom.__all__` is defined and lists all exported names
- [ ] Importing `phantom` does not trigger any network calls or file I/O side effects
- [ ] Unit test: `import phantom; assert hasattr(phantom, "Phantom")` and all other expected exports
