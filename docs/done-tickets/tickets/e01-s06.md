# E1-S06: Typer CLI Skeleton

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Create `src/phantom/cli.py` with a Typer application that has all 9 subcommand groups registered. Each group should have at least one placeholder command so `--help` works at every level. Zero business logic belongs here — all real work will be added as later stories fill in the API.

## File Locations

- `src/phantom/cli.py` — main CLI module

## Acceptance Criteria

- [ ] Top-level `app = typer.Typer()` with 9 sub-apps added: `account`, `order`, `position`, `note`, `report`, `data`, `broker`, `run`, `replay`
- [ ] `uv run phantom --help` lists all 9 sub-command groups without error
- [ ] Each sub-app has at least one stub command, so `phantom account --help`, `phantom order --help`, etc. all work
- [ ] `get_phantom() -> Phantom` helper function reads `PHANTOM_DATA` env var (default `"./data"`)
- [ ] `cli.py` imports only from `phantom` (public API) and `phantom.errors` — no internal module imports
- [ ] No business logic in `cli.py`

## Implementation Notes

```python
import os, typer
from rich.console import Console

app = typer.Typer(help="Phantom Ledger — paper trading and backtesting engine")
account_app = typer.Typer()
order_app = typer.Typer()
# ... etc.

app.add_typer(account_app, name="account", help="Manage accounts")
app.add_typer(order_app, name="order", help="Place and manage orders")
# ... etc.

console = Console()

def get_phantom():
    from phantom import Phantom
    return Phantom(data_dir=os.environ.get("PHANTOM_DATA", "./data"))
```
