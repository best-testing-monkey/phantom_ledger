# E10-S07: Replay with Margin Simulation

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** P2
**Depends on:** [E8-S01](e08-s01.md)

## Description

Extend `ReplayEngine.replay_position()` to run `MarginEngine.check()` on each bar during replay for margin-enabled positions (CFDs or leveraged instruments). On each bar, compute the current margin level using `account.equity / account.used_margin` and pass it to `MarginEngine.check(margin_level)`. If the margin level breaches the stop-out threshold, force-close the affected positions at the current bar's close price with `close_reason = "margin_call"` and record a `MarginCallEvent` (a dataclass or model capturing: account_id, position_id, bar_timestamp, margin_level, close_price). The replay engine is not responsible for adjusting the account balance in the DB during this step — it records the event for the caller to handle. Multiple positions in the same account being replayed simultaneously must share a single running equity calculation across bars. Log at WARNING when stop-out is triggered: `"Stop-out triggered for %s at margin_level=%.2f%%"`.

## File Locations

- `src/phantom/engine/replay_engine.py` — `_check_margin()` private helper and `MarginCallEvent` dataclass

## Acceptance Criteria

- [ ] `_check_margin()` called on every bar for positions where `instrument_type == "cfd"` or account has `leverage > 1.0`
- [ ] Margin level computed as `(account_equity + unrealized_pnl) / used_margin`
- [ ] If margin level <= `BrokerProfile.margin.stop_out_level`: position force-closed at `bar.Close`, `close_reason = "margin_call"`
- [ ] `MarginCallEvent` dataclass created and returned alongside the updated position
- [ ] WARNING log: `"Stop-out triggered for %s at margin_level=%.2f%%"` with position ID and level as percentage
- [ ] `MarginEngine.check()` is called (not reimplemented) — this story wires it into the replay loop

## Implementation Notes

```python
from dataclasses import dataclass
from datetime import datetime

@dataclass
class MarginCallEvent:
    account_id: str
    position_id: str
    bar_timestamp: datetime
    margin_level: float
    close_price: float

def _check_margin(
    self,
    pos: Position,
    margin_engine: MarginEngine,
    equity: float,
    used_margin: float,
    bar_close: float,
    bar_ts: datetime,
) -> MarginCallEvent | None:
    level = margin_engine.check(equity, used_margin)
    if level.stop_out_triggered:
        logger.warning(
            "Stop-out triggered for %s at margin_level=%.2f%%",
            pos.id, level.margin_pct * 100,
        )
        return MarginCallEvent(
            account_id=pos.account_id,
            position_id=pos.id,
            bar_timestamp=bar_ts,
            margin_level=level.margin_pct,
            close_price=bar_close,
        )
    return None
```
