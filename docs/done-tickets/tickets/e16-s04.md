# E16-S04: Order Placement Form

**Epic:** [E16: Web UI](e16-web-ui.md)
**Phase:** P3
**Depends on:** [E16-S01](e16-s01.md)

## Description

Implement the order placement form at `/orders/new`. The GET route renders an HTML form with fields for: account (dropdown of existing accounts), symbol (text), side (buy/sell radio), quantity (number), order_type (market/limit radio), limit_price (number, shown only when limit is selected), stop_loss (number, optional), and take_profit (number, optional). The POST route reads the form data, calls `ph.orders.place(...)`, and on success redirects to `/positions/{new_position_id}` with a flash message "Order placed successfully". On `PhantomError`, re-renders the form with the error message displayed at the top.

## File Locations

- `src/phantom/web/routes/orders.py` — GET and POST routes for `/orders/new`
- `src/phantom/web/templates/order_form.html` — Jinja2 template

## Acceptance Criteria

- [ ] `GET /orders/new` renders `order_form.html` with account dropdown populated from `ph.accounts.list()`
- [ ] `POST /orders/new` calls `ph.orders.place()` with form data and redirects to `/positions/{id}` on success
- [ ] `PhantomError` from order placement re-renders the form with the error displayed (not a crash)
- [ ] `limit_price` field is present in the form HTML; JavaScript or CSS can hide it when `market` is selected (optional enhancement)
- [ ] Form uses CSRF-safe POST (no token required for MVP since it's localhost-only)
- [ ] Test: POST with valid market order data to a seeded account returns redirect 302

## Implementation Notes

```python
from fastapi import APIRouter, Request, Form
from fastapi.responses import RedirectResponse
from phantom.errors import PhantomError

router = APIRouter()

@router.get("/orders/new")
async def order_form(request: Request):
    ph = get_phantom()
    accounts = ph.accounts.list()
    return templates.TemplateResponse("order_form.html", {"request": request, "accounts": accounts})

@router.post("/orders/new")
async def place_order(request: Request, account: str = Form(...), symbol: str = Form(...), ...):
    ph = get_phantom()
    try:
        order = ph.orders.place(account_id=account, symbol=symbol, ...)
        return RedirectResponse(f"/positions/{order.position_id}", status_code=302)
    except PhantomError as e:
        accounts = ph.accounts.list()
        return templates.TemplateResponse("order_form.html", {"request": request, "accounts": accounts, "error": str(e)})
```
