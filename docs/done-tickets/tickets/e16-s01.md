# E16-S01: FastAPI Setup

**Epic:** [E16: Web UI](e16-web-ui.md)
**Phase:** P3

## Description

Set up the FastAPI application that serves the Phantom Ledger web UI. The app mounts static files from `src/phantom/web/static/` at `/static`, uses `Jinja2Templates` from `src/phantom/web/templates/`, and applies CORS middleware allowing localhost origins on all common ports. The `phantom web serve --port 8080` CLI command creates the app, calls `uvicorn.run()` with the given port, and opens the browser automatically. The application factory `create_app()` is separate from the CLI so the app can be imported by tests without starting a server. All route modules are registered via `app.include_router()`.

## File Locations

- `src/phantom/web/app.py` — `create_app()` factory and app instance
- `src/phantom/cli.py` — `web serve` subcommand

## Acceptance Criteria

- [ ] `create_app()` returns a `FastAPI` instance with CORS middleware allowing `http://localhost:*` origins
- [ ] Static files are mounted at `/static` from `src/phantom/web/static/`
- [ ] `Jinja2Templates` is configured with `src/phantom/web/templates/` directory
- [ ] `phantom web serve --port 8080` starts uvicorn on the given port
- [ ] `fastapi`, `uvicorn`, and `jinja2` are in `pyproject.toml` dependencies
- [ ] Unit test: `create_app()` returns a FastAPI instance with a CORS middleware configured

## Implementation Notes

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates
from pathlib import Path

_HERE = Path(__file__).parent

def create_app() -> FastAPI:
    app = FastAPI(title="Phantom Ledger")
    app.add_middleware(
        CORSMiddleware,
        allow_origins=["http://localhost", "http://127.0.0.1"],
        allow_origin_regex=r"http://localhost:\d+",
        allow_methods=["*"],
        allow_headers=["*"],
    )
    app.mount("/static", StaticFiles(directory=_HERE / "static"), name="static")
    return app

templates = Jinja2Templates(directory=_HERE / "templates")
```
