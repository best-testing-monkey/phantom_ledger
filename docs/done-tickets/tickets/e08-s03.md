# E8-S03: Stop-Out Cascade

**Epic:** [E8: Margin Engine](e08-margin-engine.md)
**Phase:** P2
**Depends on:** [E8-S01](e08-s01.md), [E7-S04](e07-s04.md)

## Description

Implement the stop-out cascade in `MarginEngine.handle_stop_out()`. When `MarginStatus.status == "stop_out"`, the engine must force-close open positions one at a time until the margin level recovers above `stop_out_level` or no open positions remain. The position closed on each iteration is the one with the largest unrealized loss (most negative `unrealized_pnl`) — this is the standard broker behaviour that minimises the number of positions liquidated. Each forced close uses the current bar's close price as the exit price and sets `close_reason = "margin_call"`. After each close, recompute the margin level. If the margin level has recovered above `stop_out_level`, stop the cascade. Log at INFO for each position closed. If all positions are closed and the margin level is still at or below stop_out_level, log a WARNING that the account is fully liquidated.

## Acceptance Criteria

- [ ] Positions are closed in order of largest unrealized loss first (most negative P&L)
- [ ] Each forced close sets `close_reason = "margin_call"` and uses `bar.Close` as exit price
- [ ] After each close, margin level is recomputed before deciding whether to continue the cascade
- [ ] Cascade stops as soon as `margin_level > stop_out_level` (not all positions need to be closed)
- [ ] All positions closed logs a WARNING; partial cascade (level recovered) logs INFO for each close
- [ ] Integration test in E8-S04 verifies correct cascade order across at least three positions

## Implementation Notes

```python
def handle_stop_out(
    self,
    account: Account,
    open_positions: list[Position],
    broker_profile: BrokerProfile,
    current_bar: Bar,
    position_manager: PositionManager,
    account_repo: AccountRepo,
) -> list[Position]:
    """Force-close positions from largest loss until margin recovers. Returns list of closed positions."""
    closed = []
    # Sort ascending by unrealized_pnl (largest loss first)
    remaining = sorted(open_positions, key=lambda p: p.unrealized_pnl or 0.0)
    for position in remaining:
        market_value = sum(
            (p.quantity * current_bar.close) for p in open_positions if p.id != position.id
        )
        status = self.check(account, broker_profile, market_value)
        if status.status != "stop_out":
            break
        logger.info(
            "Stop-out: closing position %s (pnl=%.2f) for account %s",
            position.id, position.unrealized_pnl or 0.0, account.id,
        )
        position_manager.close(
            position_id=position.id,
            exit_price=current_bar.close,
            close_reason="margin_call",
        )
        closed.append(position)
    else:
        logger.warning("Account %s fully liquidated by stop-out cascade", account.id)
    return closed
```
