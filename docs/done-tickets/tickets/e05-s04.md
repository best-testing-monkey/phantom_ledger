**Epic:** [E5: Account System](e05-account-system.md)

## Description

Wire up `phantom account list` and `phantom account show <name>` CLI commands.

## File Locations

- `src/phantom/cli.py` — add `account_list` and `account_show` commands

## Acceptance Criteria

- [ ] `phantom account list` outputs a Rich table with columns: Name, Type, Broker, Initial Capital, Cash
- [ ] `phantom account list` prints a message (not error) when no accounts exist
- [ ] `phantom account show <name>` outputs a Rich panel with all account fields
- [ ] `phantom account show nonexistent` exits 1 with `[red]Error:[/red] Account not found: nonexistent`
