# E7-S01: Position Model

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP

## Description

Define the `Position` Pydantic model with all fields from the `positions` table schema. This model is the core domain object — it tracks the full lifecycle of a trade from entry through exit, including all cost accumulators.

## File Locations

- `src/phantom/models/position.py` — `Position` model
- `src/phantom/models/types.py` — ensure `PositionStatus`, `CloseReason` Literals exist

## Acceptance Criteria

- [ ] `Position` Pydantic model with all fields from the `positions` table in Section 3
- [ ] Entry fields: `id` (ULID), `account_id`, `ticker`, `instrument_type`, `direction`, `entry_order_id`, `entry_price`, `entry_datetime`, `quantity`, `notional`
- [ ] Exit condition fields: `take_profit`, `stop_loss`, `trailing_stop_amount`, `trailing_stop_pct`, `trailing_stop_peak`, `max_close_datetime` (all nullable)
- [ ] Cost accumulator fields: `commission_entry`, `commission_exit`, `spread_cost`, `slippage_cost`, `overnight_costs`, `dividend_adjustments`, `fx_conversion_cost` (all `float`, default `0.0`)
- [ ] Margin fields: `margin_required: float = 0.0`, `leverage: float = 1.0`
- [ ] Exit fields: `exit_price`, `exit_datetime`, `realized_pnl` (all nullable), `status: PositionStatus = "open"`, `close_reason: CloseReason | None = None`
- [ ] Metadata: `pattern_tag: str | None`, `created_at: datetime`
