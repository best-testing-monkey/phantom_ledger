# E10-S05: Replay Idempotency — replay_completed_at Tracking

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** MVP
**Depends on:** [E7-S01](e07-s01.md)

## Description

Track replay completion per position via a `replay_completed_at` column (ISO 8601 TEXT, nullable) on the `positions` table. This is the single source of truth for whether a position has been replayed. `ReplayEngine.replay_position()` must read this field at the start of each call and raise `ValidationError("Position already replayed: <id>")` if it is set (unless the caller explicitly reset it first). `PositionRepo` gains two new methods: `mark_replay_complete(position_id, dt)` sets the column; `reset_replay(position_id)` sets it back to NULL. The migration that adds this column must be idempotent (`ALTER TABLE ... ADD COLUMN IF NOT EXISTS` is not supported in SQLite — use a `SELECT` on `pragma_table_info` guard or a separate numbered migration file). The `Position` Pydantic model gains a `replay_completed_at: str | None = None` field.

## File Locations

- `src/phantom/db/repositories/position_repo.py` — `mark_replay_complete()`, `reset_replay()`, `list()` filter support
- `src/phantom/models/position.py` — add `replay_completed_at: str | None = None`
- `src/phantom/db/migrations/` — new numbered migration SQL file adding the column

## Acceptance Criteria

- [ ] `positions` table has `replay_completed_at TEXT` column (nullable, default NULL)
- [ ] `Position` Pydantic model has `replay_completed_at: str | None = None`
- [ ] `PositionRepo.mark_replay_complete(position_id, dt)` updates the column and commits
- [ ] `PositionRepo.reset_replay(position_id)` sets column to NULL and commits; raises `NotFoundError` if ID not found
- [ ] `PositionRepo.list()` accepts optional `replay_completed_at=None` kwarg to filter to un-replayed positions (`WHERE replay_completed_at IS NULL`)
- [ ] `ReplayEngine.replay_position()` raises `ValidationError` if `position.replay_completed_at` is already set

## Implementation Notes

```python
# Migration SQL (e.g., 0009_add_replay_completed_at.sql)
ALTER TABLE positions ADD COLUMN replay_completed_at TEXT;

# PositionRepo additions
def mark_replay_complete(self, position_id: str, dt: datetime) -> None:
    cursor = self._conn.execute(
        "UPDATE positions SET replay_completed_at = ? WHERE id = ?",
        (to_iso(dt), position_id),
    )
    if cursor.rowcount == 0:
        raise NotFoundError("Position", position_id)
    self._conn.commit()

def reset_replay(self, position_id: str) -> None:
    cursor = self._conn.execute(
        "UPDATE positions SET replay_completed_at = NULL WHERE id = ?",
        (position_id,),
    )
    if cursor.rowcount == 0:
        raise NotFoundError("Position", position_id)
    self._conn.commit()
```
