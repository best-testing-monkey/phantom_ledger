# E6-S02: order_repo

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP
**Depends on:** [E6-S01](e06-s01.md)

## Description

Implement `OrderRepo` for CRUD operations on the `orders` SQLite table.

## File Locations

- `src/phantom/db/repositories/order_repo.py` — `OrderRepo` class

## Acceptance Criteria

- [ ] `create(order: Order) -> Order` inserts all fields; nullable fields serialized as `None`/`NULL`
- [ ] `get(order_id: str) -> Order` raises `NotFoundError("Order", order_id)` on miss
- [ ] `update_status(order_id, status, **kwargs) -> Order` updates status and any provided additional fields (e.g. `fill_price`, `filled_at`); raises `NotFoundError` if order not found
- [ ] `list_by_account(account_id: str, status: str | None = None) -> list[Order]` returns all orders for account, optionally filtered by status
- [ ] `list_pending() -> list[Order]` returns all orders with `status="pending"` across all accounts
- [ ] Unit tests in `tests/unit/test_order_repo.py`
