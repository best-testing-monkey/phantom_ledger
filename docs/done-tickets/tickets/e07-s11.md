# E7-S11: Overnight Cost Accrual

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** P2
**Depends on:** [E3-S10](e03-s10.md), [E4-S06](e04-s06.md), [E7-S01](e07-s01.md)

## Description

Extend `PositionManager.update()` to detect when a bar crosses one or more trading-day boundaries and calculate an overnight financing charge for each crossing. A day boundary is crossed whenever the date of the current bar differs from the date of the previous bar processed for that position (tracked via `position.last_bar_date`). For each day boundary crossed, the charge is computed as `notional_value * overnight_rate / day_divisor` where `notional_value = position.quantity * position.entry_price`, `overnight_rate` is the sum of the broker's base reference rate (from `OvernightModel.rate_source`) plus the markup (`long_markup_pct` for longs, `short_markup_pct` for shorts), and `day_divisor` is from the broker profile (typically 360 or 365). The charge is subtracted from `account.cash` and added to `position.overnight_accrued`. Only CFD positions accrue overnight costs — stock positions are skipped. After applying charges, persist the updated position and account to their respective repos.

## File Locations

- `src/phantom/engine/position_manager.py` — add `_apply_overnight_cost()` helper called from `update()`
- `src/phantom/models/position.py` — ensure `overnight_accrued: float = 0.0` and `last_bar_date: str | None = None` fields exist

## Acceptance Criteria

- [ ] A CFD position held over one day boundary accrues exactly `notional * rate / divisor` in overnight charges
- [ ] Multiple day boundaries in a single bar (e.g. weekend gap) accrue charges for each day crossed
- [ ] Stock positions (`instrument_type == "stock"`) accrue zero overnight charges
- [ ] `position.overnight_accrued` accumulates across bars and is persisted after each update
- [ ] `account.cash` is reduced by the overnight charge and persisted atomically with the position update
- [ ] `position.last_bar_date` is updated to the current bar date after processing

## Implementation Notes

```python
def _apply_overnight_cost(
    self,
    position: Position,
    account: Account,
    bar: Bar,
    overnight_model: OvernightModel,
    reference_rate: float,
) -> None:
    if position.instrument_type != "cfd":
        return
    if position.last_bar_date is None:
        position.last_bar_date = bar.date.isoformat()
        return
    prev_date = date.fromisoformat(position.last_bar_date)
    current_date = bar.date
    days_crossed = (current_date - prev_date).days
    if days_crossed <= 0:
        return
    markup = (overnight_model.long_markup_pct if position.direction == "long"
               else overnight_model.short_markup_pct)
    rate = reference_rate + markup
    notional = position.quantity * position.entry_price
    charge = notional * rate / overnight_model.day_divisor * days_crossed
    position.overnight_accrued += charge
    account.cash -= charge
    position.last_bar_date = current_date.isoformat()
    logger.info(
        "Overnight charge %.4f applied to position %s (days=%d)",
        charge, position.id, days_crossed,
    )
```
