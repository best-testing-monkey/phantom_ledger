# E3-S01: CommissionModel — fixed type

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** MVP
**Depends on:** [E2-S01](e02-s01.md)

## Description

Implement `CommissionModel.calculate()` for `model_type = "fixed"`. The fixed model charges a flat fee per trade, regardless of quantity or notional value. This is DEGIRO's model (€1.00 per trade).

## File Locations

- `src/phantom/costs/__init__.py` — package marker
- `src/phantom/costs/commission.py` — `CommissionModel` with `calculate()` method

## Acceptance Criteria

- [ ] `CommissionModel` is a Pydantic model (part of the hierarchy from E2-S01 or a standalone calculate method on the existing model)
- [ ] `CommissionModel.calculate(quantity: float, price: float, monthly_volume: float) -> float`
- [ ] For `model_type == "fixed"`: returns `fixed_fee` regardless of `quantity`, `price`, or `monthly_volume`
- [ ] Returns `0.0` when `fixed_fee == 0.0`
- [ ] Works for fractional quantities (e.g. `quantity=0.5`)
- [ ] Unit tests in `tests/unit/test_commission.py`: basic case, independence from quantity, independence from price, zero fee
