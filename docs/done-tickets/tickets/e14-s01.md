# E14-S01: Alert Event Types

**Epic:** [E14: Alerts & Notifications](e14-alerts.md)
**Phase:** P3

## Description

Define the `AlertEvent` Pydantic model that represents a single notification-worthy event in the trading engine. The model is immutable (frozen) because events are facts about the past. The `event_type` field uses a `Literal` type alias covering all six event categories. `position_id` is optional because account-level events (margin warning, margin call) are not tied to a specific position. `timestamp` defaults to `now_utc()`. This model is the shared contract between the engine that emits events and the dispatcher/senders that deliver them.

## File Locations

- `src/phantom/alerts/events.py` — `AlertEvent` Pydantic model and `AlertEventType` Literal alias

## Acceptance Criteria

- [ ] `AlertEventType` Literal covers exactly: `"order_filled"`, `"tp_hit"`, `"sl_hit"`, `"margin_warning"`, `"margin_call"`, `"position_expired"`
- [ ] `AlertEvent` has fields: `event_type: AlertEventType`, `account_id: str`, `position_id: str | None`, `message: str`, `timestamp: datetime`
- [ ] `AlertEvent` is `frozen=True` (immutable value object)
- [ ] `timestamp` field defaults to `now_utc()` via `default_factory`
- [ ] `AlertEvent` can be serialized to JSON via `.model_dump_json()`
- [ ] Unit test: constructing each of the six event types succeeds and round-trips through JSON

## Implementation Notes

```python
from typing import Literal
from datetime import datetime
from pydantic import BaseModel, Field
from phantom.utils.datetime import now_utc

AlertEventType = Literal[
    "order_filled", "tp_hit", "sl_hit",
    "margin_warning", "margin_call", "position_expired",
]

class AlertEvent(BaseModel, frozen=True):
    event_type: AlertEventType
    account_id: str
    position_id: str | None = None
    message: str
    timestamp: datetime = Field(default_factory=now_utc)
```
