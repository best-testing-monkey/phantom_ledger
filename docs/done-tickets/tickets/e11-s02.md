# E11-S02: Note Creation from File

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** MVP
**Depends on:** [E11-S01](e11-s01.md)

## Description

Add the `--file` option to `phantom note add <pos-id> --title <title> --file <path>`, allowing the user to import an existing Markdown file as a note. The CLI command resolves the given path, reads its content, and passes it to `NoteManager.create()`. If the file does not exist or cannot be read, raise `DataError("Note source file not found: <path>")` before touching the DB or note storage. The position's `account_id` must be resolved from the position record (via `ph.positions.get(pos_id).account_id`) to construct the correct note storage path. After creation, print a Rich panel showing: note ID, title, file size (human-readable bytes), and storage path. The `--file` and the `$EDITOR` flow (E11-S03) are mutually exclusive — if both are somehow supplied, `--file` takes precedence.

## File Locations

- `src/phantom/cli.py` — `note add` command with `--file` option
- `src/phantom/notes/manager.py` — validation logic in `create_from_file()` method

## Acceptance Criteria

- [ ] `phantom note add <pos-id> --title <title> --file <path>` reads file content and calls `NoteManager.create()`
- [ ] File not found raises `DataError` (not a raw `FileNotFoundError`); error message includes the supplied path
- [ ] `account_id` resolved from `ph.positions.get(pos_id)` before calling `NoteManager.create()`
- [ ] Rich panel printed on success: note ID, title, size in human-readable form (e.g. `"4.2 KB"`), and file_path
- [ ] `NotFoundError` for position ID propagates and exits with code 1
- [ ] Empty source file (`content == ""`) raises `ValidationError("Note file is empty")`

## Implementation Notes

```python
@note_app.command("add")
def note_add(
    position_id: str = typer.Argument(..., help="Position ULID"),
    title: str = typer.Option(..., "--title", help="Note title"),
    file: str | None = typer.Option(None, "--file", help="Source markdown file"),
):
    """Add a note to a position."""
    try:
        ph = get_phantom()
        pos = ph.positions.get(position_id)
        if file:
            note = ph.notes.create_from_file(
                position_id=position_id,
                account_id=pos.account_id,
                title=title,
                source_path=file,
            )
        else:
            # falls through to E11-S03 editor flow
            ...
        console.print(Panel(
            f"[bold]ID:[/bold] {note.id}\n"
            f"[bold]Title:[/bold] {note.title}\n"
            f"[bold]Size:[/bold] {_human_bytes(note.content_size)}\n"
            f"[bold]Path:[/bold] {note.file_path}",
            title="Note Created",
        ))
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
