# E1-S09: Ruff Configuration

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Add a `[tool.ruff]` section to `pyproject.toml` that configures linting and formatting for the project. The configuration should enforce the code style conventions from A.10 (absolute imports, consistent formatting). The project skeleton must pass both `ruff check` and `ruff format --check` with zero errors.

## File Locations

- `pyproject.toml` — `[tool.ruff]` and `[tool.ruff.lint]` sections

## Acceptance Criteria

- [ ] `[tool.ruff]` section exists in `pyproject.toml` with at minimum `line-length = 100`
- [ ] `[tool.ruff.lint]` section selects at minimum `["E", "F", "I"]` (pycodestyle errors, pyflakes, isort)
- [ ] `uv run ruff check src/ tests/` exits with code 0 on the project skeleton
- [ ] `uv run ruff format --check src/ tests/` exits with code 0 on the project skeleton
- [ ] Isort config enforces absolute imports (no relative imports) — set `force-sort-within-sections = true` or equivalent
