# E4-S03: CLI — data fetch

**Epic:** [E4: Data Layer](e04-data-layer.md)
**Phase:** MVP
**Depends on:** [E4-S01](e04-s01.md)

## Description

Wire up `phantom data fetch --ticker AAPL --start 2024-01-01` CLI command. It calls the `DataAPI.fetch_prices()` method and shows progress feedback.

## File Locations

- `src/phantom/cli.py` — add `data_fetch` command

## Acceptance Criteria

- [ ] `phantom data fetch --ticker AAPL --start 2024-01-01` fetches and caches price data
- [ ] `--start` and optional `--end` (default: today) are accepted
- [ ] Prints number of bars fetched on success (e.g. `"Fetched 252 bars for AAPL"`)
- [ ] Shows a Rich progress indicator while fetching
- [ ] Exits 1 with a `[red]Error:[/red]` message if fetch fails (network error, invalid ticker)
- [ ] `phantom data fetch --ticker AAPL --start 2024-01-01` run twice uses cache on second call
