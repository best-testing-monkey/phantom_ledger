# E6-S06: Order Expiry

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP
**Depends on:** [E6-S04](e06-s04.md)

## Description

Implement GTC (Good Till Cancelled) order expiry. Before each bar is evaluated, orders whose `good_til` datetime has passed are expired and removed from the pending list. No cash changes on expiry.

## File Locations

- `src/phantom/engine/order_manager.py` — add `expire_orders()` method

## Acceptance Criteria

- [ ] `expire_orders(pending_orders: list[Order], now: datetime) -> tuple[list[Order], list[Order]]` returns `(active_orders, expired_orders)`
- [ ] An order is expired when `order.good_til is not None and order.good_til < now`
- [ ] Expired orders get `status = "expired"` set on the returned object
- [ ] The simulation loop calls `expire_orders()` before `evaluate()` on each bar
- [ ] Account cash is NOT modified when an order expires
- [ ] Expired orders are logged at INFO level: `"Order %s expired (good_til=%s)"`
