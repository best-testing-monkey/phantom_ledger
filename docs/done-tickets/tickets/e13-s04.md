# E13-S04: Paper Trade Run CLI

**Epic:** [E13: Paper Trade Scheduler](e13-paper-trade-scheduler.md)
**Phase:** P2
**Depends on:** [E13-S01](e13-s01.md)

## Description

Add a `phantom run` CLI command that creates and starts the paper trade scheduler for a named account. The command accepts `--account <name>`, `--mode paper`, and `--interval <seconds>` (default 300). Before starting, it validates that the account exists and has a broker profile loaded — if not, it prints an error and exits with code 1. On start it prints "Starting paper trade for account {name} at {interval}s intervals" using Rich. The command blocks until the user presses Ctrl+C (SIGINT), at which point it calls `scheduler.stop()` and prints "Stopped." gracefully. The CLI must not contain any scheduling or engine logic — it delegates entirely to `PaperTradeScheduler`.

## File Locations

- `src/phantom/cli.py` — `run` command group with `paper` subcommand

## Acceptance Criteria

- [ ] `phantom run --account <name> --mode paper --interval 300` starts the scheduler and blocks
- [ ] Command validates account exists via `ph.accounts.get(name)` and raises `NotFoundError` with exit 1 on miss
- [ ] Command validates account has a non-null `broker_profile_id`; exits 1 with clear message if not
- [ ] Rich output: `"Starting paper trade for account [bold]{name}[/bold] at {interval}s intervals"` before blocking
- [ ] SIGINT (Ctrl+C) calls `scheduler.stop()` and prints `"Stopped."` with exit code 0
- [ ] Integration test: invoking command with nonexistent account returns exit code 1

## Implementation Notes

```python
@app.command()
def run(
    account: str = typer.Option(...),
    mode: str = typer.Option("paper"),
    interval: int = typer.Option(300),
) -> None:
    try:
        ph = get_phantom()
        acct = ph.accounts.get(account)
        scheduler = PaperTradeScheduler(ph.runner._engine, interval)
        console.print(f"Starting paper trade for account [bold]{account}[/bold] at {interval}s intervals")
        scheduler.start()  # blocks
    except KeyboardInterrupt:
        scheduler.stop()
        console.print("Stopped.")
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
