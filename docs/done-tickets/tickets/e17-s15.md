# E17-S15: NoteAPI Edit and Search

**Epic:** [E17: Library API Surface](e17-library-api.md)
**Phase:** P2
**Depends on:** [E11-S07](e11-s07.md), [E11-S08](e11-s08.md), [E17-S07](e17-s07.md)

## Description

Extend `NoteAPI` with `edit(note_id, content)` and `search(account_id, keyword) -> list[NoteSearchResult]`. `edit()` updates the note's content and sets `updated_at = now_utc()` — it raises `NotFoundError` if the note does not exist. `search()` performs a case-insensitive full-text search across all note titles and content for positions belonging to the account. It returns a list of `NoteSearchResult` objects, each containing the note ID, title, position ID, and a snippet of context around the first match (50 chars before and after). The search uses SQLite `LIKE` with `%keyword%` — no external search index needed at this scale.

## File Locations

- `src/phantom/api/notes.py` — `edit()` and `search()` methods on `NoteAPI`

## Acceptance Criteria

- [ ] `edit(note_id, content)` updates content and `updated_at`; raises `NotFoundError` on miss
- [ ] `edit()` returns the updated `Note` object
- [ ] `search(account_id, keyword)` returns `list[NoteSearchResult]` matching the keyword in title or content
- [ ] `NoteSearchResult` has fields: `note_id`, `position_id`, `title`, `snippet`
- [ ] Search is case-insensitive (use `LOWER()` in SQL or Python post-filter)
- [ ] Integration test: add two notes with different content, search for a word in one returns only that note

## Implementation Notes

```python
from dataclasses import dataclass

@dataclass
class NoteSearchResult:
    note_id: str
    position_id: str
    title: str
    snippet: str

# In NoteAPI:
def edit(self, note_id: str, content: str) -> Note:
    self._manager.get(note_id)  # raises NotFoundError on miss
    return self._manager.update(note_id, content=content, updated_at=now_utc())

def search(self, account_id: str, keyword: str) -> list[NoteSearchResult]:
    return self._manager.search(account_id=account_id, keyword=keyword)
```
