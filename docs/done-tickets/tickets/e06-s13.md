# E6-S13: Margin Validation on Order Placement

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** P2
**Depends on:** [E5-S06](e05-s06.md), [E6-S03](e06-s03.md)

## Description

When placing a CFD order, validate that the account has sufficient free margin. `required_margin = notional / leverage`. If `free_margin < required_margin`, reject with `MarginError`.

## File Locations

- `src/phantom/engine/order_manager.py` — add margin check to `place()`

## Acceptance Criteria

- [ ] For `instrument_type == "cfd"`: `required_margin = (price * quantity) * default_margin_pct`
- [ ] Raises `MarginError("Insufficient margin: need {required:.2f}, free {free:.2f}")` when free margin insufficient
- [ ] For stock orders (`instrument_type == "stock"`): no margin check (full notional from cash)
- [ ] Validation fires before order is persisted to DB
- [ ] Unit test: CFD order rejected on insufficient margin, CFD order accepted with sufficient margin
