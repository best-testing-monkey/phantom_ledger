# E10-S03: Replay All CLI Command

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** MVP
**Depends on:** [E10-S01](e10-s01.md), [E10-S05](e10-s05.md)

## Description

Add `phantom replay --account <name>` CLI command that replays all positions belonging to the given account that have a historical `entry_datetime` and have not yet been replayed (`replay_completed_at IS NULL`). The command uses `ph.positions.list(account_name=name, replay_completed_at=None)` to fetch pending positions, then calls `ph.replay.replay_position(pos)` for each one in sequence. Progress is shown using Rich's `Progress` context manager with a task for the total count and a per-position description showing the ticker. On completion, print a summary row: `"Replayed N positions: X closed, Y still open"`. Any `PhantomError` from an individual replay is caught, printed as a warning, and processing continues to the next position (partial failure tolerance).

## File Locations

- `src/phantom/cli.py` — `replay_app` Typer sub-application, `replay_all` command

## Acceptance Criteria

- [ ] Command registered as `phantom replay --account <name>` (not a sub-sub-command)
- [ ] Fetches only positions where `replay_completed_at IS NULL` for the given account
- [ ] Rich `Progress` bar shows current ticker and position number out of total
- [ ] Individual `PhantomError` per position is caught and printed as `[yellow]Warning:[/yellow]`; remaining positions continue
- [ ] Summary line printed after loop: total replayed, how many closed, how many left open
- [ ] `NotFoundError` for the account itself propagates and exits with code 1

## Implementation Notes

```python
@replay_app.command("all")
def replay_all(account: str = typer.Option(..., "--account", help="Account name")):
    """Replay all un-replayed positions for an account."""
    try:
        ph = get_phantom()
        positions = ph.positions.list(account_name=account, replay_completed_at=None)
        closed_count = 0
        with Progress() as progress:
            task = progress.add_task("Replaying...", total=len(positions))
            for pos in positions:
                progress.update(task, description=f"[cyan]{pos.ticker}[/cyan]")
                try:
                    result = ph.replay.replay_position(pos)
                    if result.status == "closed":
                        closed_count += 1
                except PhantomError as e:
                    console.print(f"[yellow]Warning:[/yellow] {pos.id}: {e}")
                progress.advance(task)
        console.print(
            f"Replayed {len(positions)} positions: "
            f"{closed_count} closed, {len(positions) - closed_count} still open"
        )
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
