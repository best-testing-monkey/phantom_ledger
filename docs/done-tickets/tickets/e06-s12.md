# E6-S12: OCO — One-Cancels-Other

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** P2
**Depends on:** [E6-S04](e06-s04.md)

## Description

Implement OCO (One-Cancels-Other) order pairs. When a position is opened with both `take_profit` and `stop_loss`, two linked exit orders are created. When one fills, the other is automatically cancelled.

## File Locations

- `src/phantom/engine/order_manager.py` — `create_oco_pair()` and OCO cancellation logic
- `src/phantom/models/order.py` — add `oco_sibling_id: str | None` field

## Acceptance Criteria

- [ ] `Order` model has `oco_sibling_id: str | None = None` field
- [ ] When a position is created with both `take_profit` and `stop_loss` set, two orders are created with each other's IDs as `oco_sibling_id`
- [ ] When one OCO order fills, `OrderManager.evaluate()` immediately sets the sibling to `status="cancelled"`
- [ ] `oco_sibling_id` is persisted in the `orders` table (requires migration `002_add_oco.sql` or similar)
- [ ] Unit test: OCO pair created, TP hits → SL is cancelled
