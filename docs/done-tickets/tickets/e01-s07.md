# E1-S07: Config Module

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Implement `src/phantom/config.py` to handle app-wide settings. The data directory path comes from the `PHANTOM_DATA` environment variable (default `"./data"`). On first use, all required subdirectories must be created. A `.env` file in the project root should be loaded automatically if it exists.

## File Locations

- `src/phantom/config.py` — settings and path resolution
- `.env.example` — documents available env vars

## Acceptance Criteria

- [ ] `get_data_dir() -> Path` returns `Path(os.environ.get("PHANTOM_DATA", "./data"))`
- [ ] `ensure_dirs(data_dir: Path)` creates `prices/`, `rates/`, and `notes/` subdirectories inside `data_dir` (using `mkdir(parents=True, exist_ok=True)`)
- [ ] `.env` file in the project root is loaded automatically on module import (using `python-dotenv` or manual `dotenv` loading)
- [ ] `.env.example` exists at repo root and documents `PHANTOM_DATA` (and any other env vars used by the app)
- [ ] `ensure_dirs` is called when `Phantom.__init__` is called (wired up in E1-S05 or here)
