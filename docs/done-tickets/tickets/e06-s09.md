# E6-S09: Stop Order

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** P2
**Depends on:** [E6-S04](e06-s04.md)

## Description

Extend `OrderManager.evaluate()` to handle stop orders. A stop order becomes a market order when the stop price is hit. For a buy-stop, it triggers when price rises to `stop_price`. For a sell-stop, it triggers when price falls to `stop_price`.

## File Locations

- `src/phantom/engine/order_manager.py` — extend `evaluate()`

## Acceptance Criteria

- [ ] Buy stop (`direction == "long"`, `order_type == "stop"`): triggers when `bar["High"] >= stop_price`; fills at `stop_price` (or bar open if gap-up)
- [ ] Sell stop (`direction == "short"`, `order_type == "stop"`): triggers when `bar["Low"] <= stop_price`; fills at `stop_price` (or bar open if gap-down)
- [ ] `status` transitions through `"triggered"` then `"filled"` in the same bar evaluation
- [ ] Unit tests: buy stop triggered, sell stop triggered, stop not yet hit
