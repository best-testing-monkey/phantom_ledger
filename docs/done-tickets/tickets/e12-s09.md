# E12-S09: Cost Comparison Across Broker Profiles

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P2
**Depends on:** [E3-S04](e03-s04.md), [E2](e02-broker-profiles.md)

## Description

Implement `compare_broker_costs(positions: list[Position], profile_names: list[str], profile_loader: callable) -> dict[str, CostSummary]` in `src/phantom/reports/cost_comparison.py`. For each `profile_name` in `profile_names`, load the `BrokerProfile` via `profile_loader(name)` (which calls `ph.brokers.get(name)`), then replay every closed position's costs through that profile using `CostEngine(profile).calculate(quantity, price, instrument_type, direction, ...)`. The function returns a dict mapping profile name to `CostSummary`. Each position's cost is recomputed from scratch using the historical `entry_price`, `quantity`, `instrument_type`, and `direction` fields — not from stored `cost_breakdown`. Overnight charges are estimated from `(close_datetime - entry_datetime).days` times the profile's overnight rate. Positions without `close_datetime` (still open) are skipped. Raises `NotFoundError` if any named profile does not exist.

## File Locations

- `src/phantom/reports/cost_comparison.py` — `compare_broker_costs()` function

## Acceptance Criteria

- [ ] Function signature: `compare_broker_costs(positions, profile_names, profile_loader) -> dict[str, CostSummary]`
- [ ] Loops over each profile name, loads profile via `profile_loader`, recomputes costs for each closed position
- [ ] Commission, spread, slippage computed per-profile per-position; summed into `CostSummary`
- [ ] Overnight estimated as `nights = (close_datetime - entry_datetime).days`; multiplied by daily rate from profile
- [ ] Open positions (no `close_datetime`) silently skipped
- [ ] `NotFoundError` propagates if profile name not found

## Implementation Notes

```python
from phantom.costs.engine import CostEngine
from phantom.models.broker import BrokerProfile
from phantom.models.position import Position
from phantom.reports.metrics import CostSummary

def compare_broker_costs(
    positions: list[Position],
    profile_names: list[str],
    profile_loader,  # callable: str -> BrokerProfile
) -> dict[str, CostSummary]:
    result: dict[str, CostSummary] = {}
    closed = [p for p in positions if p.close_datetime is not None]
    for name in profile_names:
        profile = profile_loader(name)  # raises NotFoundError if missing
        engine = CostEngine(profile)
        commission = spread = slippage = overnight = fx = dividends = 0.0
        for pos in closed:
            nights = (pos.close_datetime - pos.entry_datetime).days
            cb = engine.calculate(
                quantity=pos.quantity,
                entry_price=pos.entry_price,
                close_price=pos.close_price,
                instrument_type=pos.instrument_type,
                direction=pos.direction,
                nights=nights,
            )
            commission += cb.commission
            spread += cb.spread
            slippage += cb.slippage
            overnight += cb.overnight
            fx += cb.fx
        total = commission + spread + slippage + overnight + fx + dividends
        result[name] = CostSummary(
            total_commission=commission, total_spread=spread,
            total_slippage=slippage, total_overnight=overnight,
            total_fx=fx, total_dividends=dividends, total_cost=total,
        )
    return result
```
