# E3-S12: DividendModel — stock withholding

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E2-S01](e02-s01.md)

## Description

Implement `DividendModel` withholding calculation for stock (equity) positions. When a stock pays a dividend, the broker withholds tax at the source country's rate before crediting the holder. The net dividend is the gross minus withholding.

## File Locations

- `src/phantom/costs/dividend.py` — `DividendModel.calculate_stock_dividend()`

## Acceptance Criteria

- [ ] `calculate_stock_dividend(gross: float, country: str) -> tuple[float, float]` returns `(net_amount, withholding)`
- [ ] `withholding = gross * withholding_rates.get(country, 0.0)`
- [ ] `net_amount = gross - withholding`
- [ ] Unknown country returns zero withholding (full gross credited)
- [ ] Unit tests: US dividend (15%), NL dividend (15%), unknown country (0%)
