# E9-S06: SimulationEngine.run_paper()

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** P2
**Depends on:** [E9-S05](e09-s05.md), [E9-S02](e09-s02.md)

## Description

Implement `SimulationEngine.run_paper()`, the live paper-trading loop. It mirrors the structure of `run_backtest()` but uses `LiveClock` for timing and a `LiveProvider` for price data. On each tick: (1) fetch the latest OHLCV bar for each tracked ticker from `LiveProvider`; (2) call `OrderManager.evaluate(bar)` to fill pending orders; (3) call `PositionManager.update(position, bar)` for each open position; (4) record an equity point; (5) commit all DB changes; (6) call `clock.advance()` to sleep until the next tick. The loop runs until `stop_event.is_set()` returns `True` (the stop event is a `threading.Event` injected at construction or passed to `run_paper()`). After the loop exits, perform a final DB commit and log `"paper trading loop stopped cleanly"` at INFO level.

## File Locations

- `src/phantom/engine/simulation_engine.py` — add `run_paper()` method to `SimulationEngine`

## Acceptance Criteria

- [ ] `run_paper()` uses `LiveClock` and `LiveProvider` (not `BacktestClock` or `HistoricalProvider`)
- [ ] Loop exits cleanly when `stop_event.is_set()` is `True`, checked at the top of each iteration
- [ ] All state changes within a tick are committed to DB before `clock.advance()` sleeps
- [ ] `PositionManager.update()` is called for every open position on every tick
- [ ] Equity point is recorded after position updates on every tick
- [ ] On loop exit, a final `self._conn.commit()` is called and INFO log `"paper trading loop stopped cleanly"` is emitted

## Implementation Notes

```python
import threading

def run_paper(
    self,
    account_id: str,
    tickers: list[str],
    interval: float,
    stop_event: threading.Event,
) -> None:
    """Run the paper trading loop until stop_event is set."""
    clock = LiveClock(interval=interval)
    logger.info("Paper trading loop started for account %s", account_id)
    while not stop_event.is_set():
        bar_time = clock.now()
        bars = {ticker: self._live_provider.fetch(ticker, bar_time) for ticker in tickers}
        for ticker, bar in bars.items():
            self._order_manager.evaluate(bar, account_id)
        open_positions = self._position_repo.list(account_id=account_id, status="open")
        for position in open_positions:
            bar = bars.get(position.ticker)
            if bar is not None:
                self._position_manager.update(position, bar)
        self._equity_recorder.record(account_id, open_positions, bar_time)
        self._conn.commit()
        clock.advance()
    self._conn.commit()
    logger.info("Paper trading loop stopped cleanly for account %s", account_id)
```
