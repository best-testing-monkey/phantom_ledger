# E5-S08: CLI — account delete

**Epic:** [E5: Account System](e05-account-system.md)
**Phase:** P2
**Depends on:** [E5-S02](e05-s02.md)

## Description

Wire up `phantom account delete <name>` with a confirmation prompt and a cascade warning if the account has open positions or orders.

## File Locations

- `src/phantom/cli.py` — add `account_delete` command

## Acceptance Criteria

- [ ] `phantom account delete <name>` prompts: `"Are you sure you want to delete account '<name>'? [y/N]"`
- [ ] `phantom account delete <name> --yes` skips the prompt
- [ ] If account has open positions, prints a warning before the confirmation prompt: `"Warning: this account has N open positions that will also be deleted."`
- [ ] `phantom account delete nonexistent` exits 1 with friendly error (no prompt shown)
- [ ] On successful deletion, prints confirmation message
