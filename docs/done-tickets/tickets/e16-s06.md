# E16-S06: HTMX Live Updates

**Epic:** [E16: Web UI](e16-web-ui.md)
**Phase:** P3
**Depends on:** [E16-S02](e16-s02.md)

## Description

Add HTMX polling to the dashboard so that the equity value and open position P&Ls refresh automatically every 30 seconds without a full page reload. The dashboard template includes the HTMX library from CDN and adds `hx-get="/api/equity-snapshot" hx-trigger="every 30s" hx-target="#equity-panel" hx-swap="outerHTML"` to the equity summary panel element. The `/api/equity-snapshot` endpoint returns a rendered HTML fragment (not JSON) containing the updated equity value and position P&L rows. A separate `/api/positions-rows` endpoint returns an HTML fragment of the positions table body for partial updates. Both endpoints accept `?account=<name>`.

## File Locations

- `src/phantom/web/routes/api.py` — `/api/equity-snapshot` and `/api/positions-rows` fragment endpoints
- `src/phantom/web/templates/dashboard.html` — HTMX polling attributes added to equity panel

## Acceptance Criteria

- [ ] `GET /api/equity-snapshot?account=<name>` returns an HTML fragment with current equity and cash balance
- [ ] `GET /api/positions-rows?account=<name>` returns an HTML `<tbody>` fragment with current open position rows
- [ ] Dashboard template includes `<script src="https://unpkg.com/htmx.org@..."></script>` in `<head>`
- [ ] Equity panel element has `hx-get="/api/equity-snapshot"`, `hx-trigger="every 30s"`, `hx-target="#equity-panel"`, `hx-swap="outerHTML"`
- [ ] Both fragment endpoints return `text/html` content-type (use `HTMLResponse`)
- [ ] Test: GET `/api/equity-snapshot?account=<name>` for a seeded account returns 200 with equity value in body

## Implementation Notes

```python
from fastapi import APIRouter, Query
from fastapi.responses import HTMLResponse

router = APIRouter(prefix="/api")

@router.get("/equity-snapshot", response_class=HTMLResponse)
async def equity_snapshot(account: str = Query(...)):
    ph = get_phantom()
    acct = ph.accounts.get(account)
    metrics = ph.report.account_metrics(acct.id)
    html = templates.get_template("_equity_panel.html").render(account=acct, metrics=metrics)
    return HTMLResponse(content=html)
```
