# E5-S06: Account-Level Margin Tracking

**Epic:** [E5: Account System](e05-account-system.md)
**Phase:** P2
**Depends on:** [E7-S15](e07-s15.md)

## Description

Add computed margin properties to the account layer. `used_margin` is the sum of `margin_required` across all open CFD positions. `free_margin` is `equity - used_margin`. `margin_level` is `equity / used_margin`.

## File Locations

- `src/phantom/api/accounts.py` — `get_margin_summary()` method
- `src/phantom/models/account.py` — `MarginSummary` dataclass

## Acceptance Criteria

- [ ] `MarginSummary` dataclass with: `used_margin`, `free_margin`, `equity`, `margin_level` (all float)
- [ ] `AccountAPI.get_margin_summary(account_name) -> MarginSummary` computes from open positions
- [ ] `margin_level = equity / used_margin`; returns `None` (or `float("inf")`) when `used_margin == 0`
- [ ] `free_margin = equity - used_margin`
- [ ] Returns zeros for accounts with no open CFD positions
