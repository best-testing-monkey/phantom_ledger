# E11-S05: Note Show CLI

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** MVP
**Depends on:** [E11-S01](e11-s01.md)

## Description

Add `phantom note show <note-id>` CLI command that prints the raw Markdown content of a note to stdout. This command is deliberately pipe-friendly: it must use `print()` (not `console.print()`) so that Rich formatting codes are never injected into the output stream. The content is read from the filesystem via `NoteManager.read(note_id)`, which loads the `Note` metadata from `NoteRepo.get(note_id)`, reconstructs the absolute file path as `data_dir / note.file_path`, and returns `path.read_text(encoding="utf-8")`. If the note ID does not exist in the DB, raise `NotFoundError`. If the file exists in DB but is missing from disk (filesystem/DB desync), raise `DataError("Note file missing from disk: <path>")`. CLI catches `PhantomError` and uses `console.print(f"[red]Error:[/red] {e}")` + exit 1.

## File Locations

- `src/phantom/cli.py` — `note show` command on `note_app`
- `src/phantom/notes/manager.py` — `NoteManager.read(note_id) -> str`

## Acceptance Criteria

- [ ] `phantom note show <note-id>` prints raw file content using `print()` (no Rich)
- [ ] `NoteManager.read()` calls `NoteRepo.get(note_id)` then reads file from `data_dir / note.file_path`
- [ ] Missing DB record raises `NotFoundError("Note", note_id)`
- [ ] File missing from disk raises `DataError` with the absolute path in the message
- [ ] Output is exactly the file content with no trailing newline added or stripped (pass-through)
- [ ] CLI error path uses `console.print(f"[red]Error:[/red] {e}")` and exits 1

## Implementation Notes

```python
# NoteManager
def read(self, note_id: str) -> str:
    note = self._repo.get(note_id)
    abs_path = self._data_dir / note.file_path
    if not abs_path.exists():
        raise DataError(f"Note file missing from disk: {abs_path}")
    return abs_path.read_text(encoding="utf-8")

# CLI
@note_app.command("show")
def note_show(note_id: str = typer.Argument(..., help="Note ULID")):
    """Print note content to stdout (pipe-friendly)."""
    try:
        ph = get_phantom()
        content = ph.notes.read(note_id)
        print(content, end="")
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
