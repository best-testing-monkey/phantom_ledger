# E14-S05: Alert Config CLI

**Epic:** [E14: Alerts & Notifications](e14-alerts.md)
**Phase:** P3

## Description

Add a `phantom config alerts` CLI command that saves alert channel configuration to `data/alerts.json`. Two channels are supported: Telegram (requires `--telegram-token` and `--telegram-chat`) and Discord (requires `--discord-webhook`). Both can be configured simultaneously. The `--show` flag reads and displays the current configuration using Rich, masking the Telegram token to show only the last 4 characters. The alerts config file is loaded by `get_phantom()` on startup and used to configure the `AlertDispatcher` with the appropriate senders. Config is stored as a flat JSON object in `data/alerts.json`.

## File Locations

- `src/phantom/cli.py` — `config alerts` subcommand
- `src/phantom/config.py` — `AlertsConfig` Pydantic model and `load_alerts_config()` / `save_alerts_config()` helpers

## Acceptance Criteria

- [ ] `phantom config alerts --telegram-token <tok> --telegram-chat <id>` writes telegram fields to `data/alerts.json`
- [ ] `phantom config alerts --discord-webhook <url>` writes discord field to `data/alerts.json`
- [ ] Both flags can be combined in one invocation; existing fields not in the invocation are preserved (merge, not overwrite)
- [ ] `phantom config alerts --show` displays current config with Rich, masking telegram token as `****{last4}`
- [ ] `AlertsConfig` is a Pydantic model with optional `telegram_token`, `telegram_chat_id`, `discord_webhook_url` fields
- [ ] Unit test: save then load round-trips correctly; show masks the token

## Implementation Notes

```python
class AlertsConfig(BaseModel):
    telegram_token: str | None = None
    telegram_chat_id: str | None = None
    discord_webhook_url: str | None = None

def load_alerts_config(data_dir: Path) -> AlertsConfig:
    path = data_dir / "alerts.json"
    if not path.exists():
        return AlertsConfig()
    return AlertsConfig.model_validate_json(path.read_text())

def save_alerts_config(data_dir: Path, config: AlertsConfig) -> None:
    path = data_dir / "alerts.json"
    path.write_text(config.model_dump_json(indent=2))
```
