# E7-S09: Position List/Show CLI

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP
**Depends on:** [E7-S01](e07-s01.md), [E7-S02](e07-s02.md), [E7-S05](e07-s05.md)

## Description

Add two CLI commands to the `position` Typer group. `phantom position list` renders a Rich table of all open positions, showing a truncated ID, symbol, side, quantity, entry price, unrealized P&L (coloured green for profit, red for loss), and holding duration formatted as a human-readable string (e.g. `"3d 4h"`). `phantom position show <id>` renders a Rich panel with the full picture: everything in the list view plus cost breakdown paid on open (commission, spread, slippage), current TP/SL levels, peak price tracked for trailing stop, total overnight charges accrued to date, and instrument type (stock vs CFD). Both commands call only the public API — no direct DB access. Unrealized P&L is computed by the API layer using the last known price from the data provider.

## File Locations

- `src/phantom/cli.py` — add `position list` and `position show` sub-commands to the `position_app` Typer group

## Acceptance Criteria

- [ ] `phantom position list` prints a Rich table with columns: ID (first 8 chars), Symbol, Side, Qty, Entry Price, Unrealized P&L, Duration
- [ ] Unrealized P&L is coloured green (profit) or red (loss) using Rich markup; zero is green
- [ ] `phantom position list` prints an empty table (not an error) and exits 0 when no open positions exist
- [ ] `phantom position show <id>` prints a Rich panel with all list fields plus TP, SL, cost breakdown, overnight accrued, instrument type
- [ ] `phantom position show <id>` with an unknown ID prints `[red]Error:[/red]` and exits 1
- [ ] Duration is formatted as `"Xd Yh"` or `"Yh Zm"` depending on magnitude (no raw seconds shown)

## Implementation Notes

```python
def _format_duration(entry_datetime: datetime) -> str:
    delta = now_utc() - entry_datetime
    days = delta.days
    hours, remainder = divmod(delta.seconds, 3600)
    minutes = remainder // 60
    if days > 0:
        return f"{days}d {hours}h"
    return f"{hours}h {minutes}m"

@position_app.command("list")
def position_list():
    """List all open positions."""
    try:
        ph = get_phantom()
        positions = ph.positions.list(status="open")
        table = Table(title="Open Positions")
        table.add_column("ID"); table.add_column("Symbol"); table.add_column("Side")
        table.add_column("Qty", justify="right"); table.add_column("Entry", justify="right")
        table.add_column("Unrealized P&L", justify="right"); table.add_column("Duration")
        for p in positions:
            pnl = p.unrealized_pnl or 0.0
            pnl_str = f"[green]+{pnl:.2f}[/green]" if pnl >= 0 else f"[red]{pnl:.2f}[/red]"
            table.add_row(p.id[:8], p.ticker, p.direction, str(p.quantity),
                          f"{p.entry_price:.4f}", pnl_str, _format_duration(p.entry_datetime))
        console.print(table)
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)

@position_app.command("show")
def position_show(position_id: str = typer.Argument(..., help="Position ID")):
    """Show full detail for a single position."""
    try:
        ph = get_phantom()
        p = ph.positions.get(position_id)
        lines = [
            f"[bold]ID:[/bold] {p.id}",
            f"[bold]Symbol:[/bold] {p.ticker}  [bold]Type:[/bold] {p.instrument_type}",
            f"[bold]Side:[/bold] {p.direction}  [bold]Qty:[/bold] {p.quantity}",
            f"[bold]Entry:[/bold] {p.entry_price:.4f}  [bold]Duration:[/bold] {_format_duration(p.entry_datetime)}",
            f"[bold]TP:[/bold] {p.take_profit}  [bold]SL:[/bold] {p.stop_loss}",
            f"[bold]Overnight Accrued:[/bold] {p.overnight_accrued:.4f}",
        ]
        console.print(Panel("\n".join(lines), title="Position Detail"))
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
