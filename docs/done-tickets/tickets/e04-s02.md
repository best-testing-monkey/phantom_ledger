# E4-S02: Parquet Cache Management

**Epic:** [E4: Data Layer](e04-data-layer.md)
**Phase:** MVP
**Depends on:** [E4-S01](e04-s01.md)

## Description

Implement Parquet cache helpers in `price_store.py` to manage the local price cache. The cache must handle freshness (don't serve stale data), incremental updates (append new bars), and split/adjustment detection (re-download when yfinance returns modified historical data).

## File Locations

- `src/phantom/data/price_store.py` — cache management functions

## Acceptance Criteria

- [ ] `is_cache_fresh(ticker: str, data_dir: Path) -> bool` returns `False` if cache file doesn't exist or if the last date in the cache is before today
- [ ] `read_cache(ticker: str, data_dir: Path) -> pd.DataFrame | None` returns cached DataFrame or `None` if missing
- [ ] `write_cache(ticker: str, df: pd.DataFrame, data_dir: Path) -> None` saves to `{data_dir}/prices/{ticker}.parquet`
- [ ] `append_bars(ticker, new_df, data_dir)` merges new rows into existing cache without duplicating dates (upsert by date index)
- [ ] When split detection is needed (caller passes `force_refresh=True`), the full history is re-downloaded and the cache is overwritten
