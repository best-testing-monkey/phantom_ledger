# E12-S07: Per-Algorithm-Version Filtering

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P2
**Depends on:** [E12-S01](e12-s01.md), [E12-S02](e12-s02.md)

## Description

Add `--algo-version <ver>` filter option to `phantom report --account <name> --algo-version <ver>` that restricts metric computation to positions whose `algorithm_version` field exactly matches the supplied version string. This mirrors E12-S06 (`--pattern`) but for a different field. The `PositionRepo.list()` method gains an `algorithm_version: str | None = None` kwarg alongside the `pattern_tag` filter — both can be applied simultaneously via `WHERE pattern_tag = ? AND algorithm_version = ?`. The report header must display `"Algorithm version: <ver>"`. If no positions match, print a notice and exit 0. `algorithm_version` is a free-form string stored on the `Position` model and `positions` table (added in E7 as a nullable TEXT column).

## File Locations

- `src/phantom/cli.py` — `report` command updated with `--algo-version` option
- `src/phantom/db/repositories/position_repo.py` — `list()` gains `algorithm_version: str | None = None` filter

## Acceptance Criteria

- [ ] `phantom report --account <name> --algo-version <ver>` filters positions by exact `algorithm_version` match
- [ ] `PositionRepo.list()` accepts `algorithm_version: str | None = None`; adds `WHERE algorithm_version = ?` when set
- [ ] Both `--pattern` and `--algo-version` can be combined in a single report call (AND logic)
- [ ] Report header includes `"Algorithm version: <ver>"` when filter is active
- [ ] No matching positions: prints `"No positions found with algorithm_version='<ver>'"` and exits 0
- [ ] Without `--algo-version`, behaviour is identical to prior stories (no regression)

# PositionRepo.list() — both filters applied with AND logic
def list(
    self,
    account_name: str | None = None,
    pattern_tag: str | None = None,
    algorithm_version: str | None = None,
    replay_completed_at: str | None = _UNSET,
) -> list[Position]:
    clauses, params = [], []
    if account_name:
        clauses.append("account_id = (SELECT id FROM accounts WHERE name = ?)")
        params.append(account_name)
    if pattern_tag is not None:
        clauses.append("pattern_tag = ?")
        params.append(pattern_tag)
    if algorithm_version is not None:
        clauses.append("algorithm_version = ?")
        params.append(algorithm_version)
    where = ("WHERE " + " AND ".join(clauses)) if clauses else ""
    rows = self._conn.execute(
        f"SELECT * FROM positions {where} ORDER BY entry_datetime ASC", params
    ).fetchall()
    return [self._row_to_model(r) for r in rows]
