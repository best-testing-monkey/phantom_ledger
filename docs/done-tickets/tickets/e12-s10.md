# E12-S10: Broker Cost Comparison CLI

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P2
**Depends on:** [E12-S09](e12-s09.md)

## Description

Add `phantom report --compare-brokers <broker-list> --account <name>` CLI command that calls `compare_broker_costs()` and renders the results as a side-by-side Rich `Table`. `--compare-brokers` accepts a comma-separated list of broker profile names (e.g. `degiro,ibkr,xtb`). The table has a `Cost Type` column (rows: Commission, Spread, Slippage, Overnight, FX, Dividends, Total) and one column per broker, right-aligned with monetary values formatted as `"{:.2f}"`. The `Total` row is styled `bold`. If any named broker profile does not exist (`NotFoundError`), print the error and exit 1. If the account has no closed positions, print a notice and exit 0. The profile loader is `ph.brokers.get` passed as a callable.

## File Locations

- `src/phantom/cli.py` — `report` command updated with `--compare-brokers` option

## Acceptance Criteria

- [ ] `--compare-brokers` accepts comma-separated broker names; parses to `list[str]` inside the command
- [ ] Rich `Table` has `Cost Type` column plus one column per broker name
- [ ] Rows: Commission, Spread, Slippage, Overnight, FX, Dividends, **Total** (bold)
- [ ] Values right-aligned, formatted to 2 decimal places
- [ ] `NotFoundError` for any broker name prints error and exits 1
- [ ] No closed positions: prints `"No closed positions to compare costs."` and exits 0

## Implementation Notes

```python
@app.command("report")
def report(
    account: str = typer.Option(..., "--account"),
    compare_brokers: str | None = typer.Option(None, "--compare-brokers"),
    # ... other options
):
    try:
        ph = get_phantom()
        if compare_brokers:
            broker_names = [b.strip() for b in compare_brokers.split(",")]
            positions = ph.positions.list(account_name=account)
            closed = [p for p in positions if p.close_datetime is not None]
            if not closed:
                console.print("No closed positions to compare costs.")
                return
            summaries = compare_broker_costs(positions, broker_names, ph.brokers.get)
            table = Table(title="Broker Cost Comparison")
            table.add_column("Cost Type")
            for name in broker_names:
                table.add_column(name, justify="right")
            rows = [
                ("Commission", "total_commission"),
                ("Spread", "total_spread"),
                ("Slippage", "total_slippage"),
                ("Overnight", "total_overnight"),
                ("FX", "total_fx"),
                ("Dividends", "total_dividends"),
                ("[bold]Total[/bold]", "total_cost"),
            ]
            for label, field in rows:
                table.add_row(label, *[f"{getattr(summaries[n], field):.2f}" for n in broker_names])
            console.print(table)
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
