# E9-S01: BacktestClock

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** MVP

## Description

Implement `BacktestClock`, a concrete implementation of the `Clock` protocol that drives the simulation loop during backtesting. It accepts a `pandas.DatetimeIndex` of bar timestamps at construction time and maintains an internal cursor. `now()` returns the datetime at the current cursor position as a timezone-aware UTC `datetime`. `advance()` moves the cursor forward by one position. `is_done()` returns `True` when the cursor has moved past the final timestamp. The `Clock` protocol itself (defined as a `typing.Protocol`) should be co-located in `clock.py` and must be satisfied by both `BacktestClock` (this story) and `LiveClock` (E9-S05). All timestamps emitted by `now()` must be timezone-aware UTC regardless of the timezone information present in the source `DatetimeIndex` — use `parse_datetime()` from `phantom.utils.datetime` to normalise.

## File Locations

- `src/phantom/engine/clock.py` — `Clock` protocol + `BacktestClock` implementation

## Acceptance Criteria

- [ ] `Clock` protocol defines `now() -> datetime`, `advance() -> None`, `is_done() -> bool`
- [ ] `BacktestClock(index)` initialises with cursor at position 0
- [ ] `now()` returns the current bar's timestamp as timezone-aware UTC `datetime`
- [ ] `advance()` increments the cursor by one; subsequent `now()` returns the next timestamp
- [ ] `is_done()` returns `False` when cursor is within the index and `True` after `advance()` moves past the last element
- [ ] Calling `now()` after `is_done()` raises `StopIteration` or `IndexError` (not silently returning stale data)

## Implementation Notes

```python
# src/phantom/engine/clock.py
import pandas as pd
from datetime import datetime
from typing import Protocol

from phantom.utils.datetime import parse_datetime


class Clock(Protocol):
    def now(self) -> datetime: ...
    def advance(self) -> None: ...
    def is_done(self) -> bool: ...


class BacktestClock:
    def __init__(self, index: pd.DatetimeIndex) -> None:
        self._index = index
        self._pos = 0

    def now(self) -> datetime:
        if self._pos >= len(self._index):
            raise StopIteration("BacktestClock exhausted")
        return parse_datetime(self._index[self._pos].to_pydatetime())

    def advance(self) -> None:
        self._pos += 1

    def is_done(self) -> bool:
        return self._pos >= len(self._index)
```
