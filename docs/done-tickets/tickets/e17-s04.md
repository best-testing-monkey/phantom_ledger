## Description

`BrokerAPI` is the public interface for broker profile management on the `Phantom` facade (`ph.brokers`). It wraps `BrokerProfileLoader` (which reads bundled JSON files from `src/phantom/profiles/`) and `BrokerRepo` (which persists loaded profiles to SQLite for reference by accounts). `load(profile_name)` reads the JSON file, validates it, and upserts it into the DB. `get(name)` raises `ProfileError` if the profile has not been loaded. `validate(profile_name)` loads and validates the JSON without persisting — useful for checking user-provided custom profiles.

## File Locations

## Acceptance Criteria

- [ ] `load(profile_name)` reads the bundled JSON, constructs a `BrokerProfile`, upserts to `BrokerRepo`, and returns it
- [ ] `load()` raises `ProfileError(profile_name, "not found")` if the JSON file does not exist
- [ ] `load()` raises `ProfileError(profile_name, "invalid JSON: ...")` if the file fails Pydantic validation
- [ ] `list()` returns all loaded profiles from the DB as `list[BrokerProfile]`
- [ ] `get(name)` raises `ProfileError(name, "not loaded")` if the profile is not in the DB
- [ ] Integration test: loading a bundled profile, then calling `get()` returns the same profile

## Implementation Notes

```python
class BrokerAPI:
    def __init__(self, conn: sqlite3.Connection, profiles_dir: Path) -> None:
        self._loader = BrokerProfileLoader(profiles_dir)
        self._repo = BrokerRepo(conn)

    def load(self, profile_name: str) -> BrokerProfile:
        try:
            profile = self._loader.load(profile_name)
        except FileNotFoundError:
            raise ProfileError(profile_name, "not found")
        except Exception as e:
            raise ProfileError(profile_name, f"invalid JSON: {e}")
        self._repo.upsert(profile)
        return profile

    def get(self, name: str) -> BrokerProfile:
        try:
            return self._repo.get_by_name(name)
        except NotFoundError:
            raise ProfileError(name, "not loaded")
```
