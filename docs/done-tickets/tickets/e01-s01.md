# E1-S01: Initialize uv Project

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Bootstrap the project using `uv`. Create `pyproject.toml` with the correct metadata, all runtime and dev dependencies, and the `phantom` CLI entry point. Establish the `src/phantom/` package layout and the `tests/` directory structure with `unit/` and `integration/` subdirectories.

## File Locations

- `pyproject.toml` — project metadata, dependencies, entry point, tool config
- `src/phantom/__init__.py` — empty package marker
- `tests/__init__.py`, `tests/unit/__init__.py`, `tests/integration/__init__.py` — package markers
- `tests/conftest.py` — empty placeholder (populated in E1-S08)
- `uv.lock` — auto-generated by `uv sync`

## Acceptance Criteria

- [ ] `pyproject.toml` has `name = "phantom-ledger"`, `requires-python = ">=3.12"`, and all 9 runtime dependencies: `typer>=0.12`, `yfinance>=0.2`, `httpx>=0.27`, `pandas>=2.2`, `pyarrow>=17`, `rich>=13`, `pydantic>=2.8`, `apscheduler>=3.10`, `python-ulid>=2`
- [ ] `pyproject.toml` has `[project.scripts]` with `phantom = "phantom.cli:app"`
- [ ] Dev dependencies include `pytest>=8`, `pytest-cov>=5`, `ruff>=0.5`
- [ ] `build-system` uses `hatchling`
- [ ] `src/phantom/__init__.py` exists (can be empty)
- [ ] `tests/unit/` and `tests/integration/` directories exist
- [ ] `uv sync` completes without error
- [ ] `uv run pytest` runs without import errors (zero tests is fine)
