# E12-S01: Equity Curve Metrics

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** MVP

## Description

Implement `calculate_metrics(equity_curve: list[EquityPoint]) -> EquityMetrics` in `src/phantom/reports/metrics.py`. `EquityPoint` is a dataclass with `timestamp: datetime` and `equity: float`. `EquityMetrics` is a frozen Pydantic model with fields: `total_return_pct`, `cagr_pct`, `max_drawdown_pct`, `max_drawdown_duration_days`. Total return is `(final_equity / initial_equity - 1) * 100`. CAGR is `((final / initial) ** (1 / years) - 1) * 100` where `years = (last_ts - first_ts).days / 365.25`. Max drawdown is the largest peak-to-trough percentage decline across the entire equity curve: iterate through points tracking the running peak; drawdown at each point is `(peak - equity) / peak * 100`. Max drawdown duration is the longest streak of consecutive points (by calendar days) where equity remains below the previous peak. If the equity curve has fewer than 2 points, raise `ValidationError("Equity curve too short to compute metrics")`.

## Acceptance Criteria

- [ ] `EquityPoint(timestamp: datetime, equity: float)` dataclass defined (or Pydantic model)
- [ ] `EquityMetrics` is a `frozen=True` Pydantic model with `total_return_pct`, `cagr_pct`, `max_drawdown_pct`, `max_drawdown_duration_days`
- [ ] Total return computed as `(final / initial - 1) * 100`; CAGR annualized over `days / 365.25`
- [ ] Max drawdown correctly identifies the worst peak-to-trough decline (not just the largest single drop)
- [ ] `ValidationError` raised if `len(equity_curve) < 2`
- [ ] Unit tests: flat curve → 0% drawdown, monotone decline → drawdown equals total decline, known sequence → exact values

## Implementation Notes

```python
from dataclasses import dataclass
from datetime import datetime
from pydantic import BaseModel

@dataclass
class EquityPoint:
    timestamp: datetime
    equity: float

class EquityMetrics(BaseModel, frozen=True):
    total_return_pct: float
    cagr_pct: float
    max_drawdown_pct: float
    max_drawdown_duration_days: int

def calculate_metrics(equity_curve: list[EquityPoint]) -> EquityMetrics:
    if len(equity_curve) < 2:
        raise ValidationError("Equity curve too short to compute metrics")
    initial, final = equity_curve[0].equity, equity_curve[-1].equity
    years = (equity_curve[-1].timestamp - equity_curve[0].timestamp).days / 365.25
    total_return = (final / initial - 1) * 100
    cagr = ((final / initial) ** (1 / years) - 1) * 100 if years > 0 else 0.0
    peak = initial
    peak_ts = equity_curve[0].timestamp
    max_dd = 0.0
    max_dd_days = 0
    for pt in equity_curve:
        if pt.equity > peak:
            peak = pt.equity
            peak_ts = pt.timestamp
        dd = (peak - pt.equity) / peak * 100
        dd_days = (pt.timestamp - peak_ts).days
        max_dd = max(max_dd, dd)
        max_dd_days = max(max_dd_days, dd_days)
    return EquityMetrics(
        total_return_pct=total_return, cagr_pct=cagr,
        max_drawdown_pct=max_dd, max_drawdown_duration_days=max_dd_days,
    )
```
