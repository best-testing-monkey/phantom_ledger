# E4-S06: Reference Rate Fetcher

**Epic:** [E4: Data Layer](e04-data-layer.md)
**Phase:** P2

## Description

Implement fetchers for benchmark overnight rates used by the OvernightModel: SOFR from the NY Fed API and ESTR from the ECB SDMX API. Rates are cached as Parquet files.

## File Locations

- `src/phantom/data/rates.py` — `fetch_sofr()`, `fetch_estr()`, `get_rate(rate_name, date)`

## Acceptance Criteria

- [ ] `fetch_sofr(start: datetime, end: datetime, data_dir: Path) -> pd.Series` returns daily SOFR rates
- [ ] `fetch_estr(start: datetime, end: datetime, data_dir: Path) -> pd.Series` returns daily ESTR rates
- [ ] Rates cached to `data/rates/{rate_name}.parquet`
- [ ] `get_rate(rate_name: str, date: datetime, data_dir: Path) -> float` returns the rate for a given date; fills missing dates by forward-filling (weekends, holidays)
- [ ] In tests, HTTP calls are mocked with `unittest.mock.patch`
- [ ] Raises `DataError` on network failure
