# E5-S02: account_repo

**Epic:** [E5: Account System](e05-account-system.md)
**Phase:** MVP
**Depends on:** [E5-S01](e05-s01.md)

## Description

Implement `AccountRepo` for CRUD operations on the `accounts` SQLite table. Follows the standard repo conventions from A.6. The `algorithm_params` and `child_account_ids` fields are stored as JSON blobs.

## File Locations

- `src/phantom/db/repositories/account_repo.py` — `AccountRepo` class

## Acceptance Criteria

- [ ] `AccountRepo.__init__(self, conn: sqlite3.Connection)`
- [ ] `create(account: Account) -> Account` inserts all fields; `algorithm_params` and `child_account_ids` serialized as JSON
- [ ] `get(account_id: str) -> Account` raises `NotFoundError("Account", account_id)` on miss
- [ ] `get_by_name(name: str) -> Account` raises `NotFoundError("Account", name)` on miss
- [ ] `list(account_type: str | None = None) -> list[Account]` filters by type when provided; returns `[]` when empty
- [ ] `update(account: Account) -> Account` raises `NotFoundError` when ID doesn't exist
- [ ] `delete(account_id: str) -> None` raises `NotFoundError` when ID doesn't exist
- [ ] JSON fields round-trip correctly through `create()` → `get()`
- [ ] Unit tests in `tests/unit/test_account_repo.py`
