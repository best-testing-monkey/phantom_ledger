# E5-S01: Account Model

**Epic:** [E5: Account System](e05-account-system.md)
**Phase:** MVP

## Description

Define the `Account` Pydantic model. Accounts are the top-level container for all trading activity. There are four types: `pattern` (tagged trade groups), `manual` (discretionary trading), `algorithm` (automated strategy), and `aggregate` (virtual account summing child accounts).

## File Locations

- `src/phantom/models/account.py` — `Account` model
- `src/phantom/models/types.py` — `AccountType` Literal (likely already added in E2-S01)

## Acceptance Criteria

- [ ] `Account` Pydantic model in `src/phantom/models/account.py`
- [ ] Required fields: `id` (ULID default_factory), `name: str`, `account_type: AccountType`, `broker_profile_id: str`, `base_currency: str`, `initial_capital: float`, `cash: float`, `created_at: datetime`
- [ ] Nullable type-specific fields: `pattern_tag: str | None`, `algorithm_id: str | None`, `algorithm_version: str | None`, `algorithm_params: dict | None`, `child_account_ids: list[str] | None`
- [ ] `account.id` is a 26-character ULID string
- [ ] `Account(name="test", account_type="manual", ...)` constructs without error
