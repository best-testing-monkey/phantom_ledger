# E3-S08: SlippageModel — volume_based type

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E3-S03](e03-s03.md)

## Description

Extend `SlippageModel.calculate()` for `"volume_based"` type. Volume-based slippage scales with the order size relative to average daily volume (ADV) — larger orders move the market more.

## File Locations

- `src/phantom/costs/slippage.py` — extend `SlippageModel.calculate()`

## Acceptance Criteria

- [ ] Method signature extended: `calculate(price, quantity, adv: float | None = None) -> float`
- [ ] `"volume_based"`: `slippage = base_pct * (quantity / adv) ^ exponent * price * quantity` where `base_pct` and `exponent` are stored on the model
- [ ] When `adv` is `None` or `0`: falls back to `fixed_pct` if set, else returns `0.0`
- [ ] Unit tests: basic case with ADV, no ADV fallback
