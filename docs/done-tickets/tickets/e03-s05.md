# E3-S05: Unit Tests — MVP Cost Models

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** MVP
**Depends on:** [E3-S01](e03-s01.md), [E3-S02](e03-s02.md), [E3-S03](e03-s03.md), [E3-S04](e03-s04.md)

## Description

Write the unit test suite for the MVP cost models. All cost model functions are pure functions — no side effects, no DB, no network. Tests use exact equality for deterministic results. Each model gets its own test file.

## File Locations

- `tests/unit/test_commission.py`
- `tests/unit/test_spread.py`
- `tests/unit/test_slippage.py`
- `tests/unit/test_cost_engine.py`

## Acceptance Criteria

- [ ] `test_commission.py`: at least 4 tests — flat fee basic, independence from quantity, independence from price, zero fee
- [ ] `test_spread.py`: at least 4 tests — fixed basic, dynamic basic with ATR, dynamic with no ATR, zero spread
- [ ] `test_slippage.py`: at least 2 tests — basic case with expected value, zero slippage
- [ ] `test_cost_engine.py`: at least 2 tests — `total == sum of components`, FX is 0 when `fx_required=False`
- [ ] All tests use exact equality (not `pytest.approx`) where the expected value is computed precisely
- [ ] `uv run pytest tests/unit/test_commission.py tests/unit/test_spread.py tests/unit/test_slippage.py tests/unit/test_cost_engine.py` passes with zero failures
