# E1-S02: SQLite Database Module

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Create the SQLite connection factory in `src/phantom/db/database.py`. Every connection must have WAL journal mode, foreign key enforcement, and the `sqlite3.Row` row factory set. The module must accept `":memory:"` for in-memory connections used in tests.

## File Locations

- `src/phantom/db/__init__.py` — package marker
- `src/phantom/db/database.py` — `get_connection()` function

## Acceptance Criteria

- [ ] `get_connection(path: str | Path) -> sqlite3.Connection` exists in `src/phantom/db/database.py`
- [ ] Every returned connection has `conn.row_factory = sqlite3.Row`
- [ ] Every returned connection has `PRAGMA journal_mode = WAL` applied
- [ ] Every returned connection has `PRAGMA foreign_keys = ON` applied
- [ ] `get_connection(":memory:")` returns a valid in-memory connection
- [ ] `get_connection(path)` creates the parent directory if it does not exist

## Implementation Notes

```python
import sqlite3
from pathlib import Path

def get_connection(path: str | Path) -> sqlite3.Connection:
    path = Path(path)
    if str(path) != ":memory:":
        path.parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(str(path))
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA journal_mode = WAL")
    conn.execute("PRAGMA foreign_keys = ON")
    return conn
```
