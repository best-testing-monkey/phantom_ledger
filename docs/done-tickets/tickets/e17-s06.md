## Description

`PositionAPI` is the public interface for position management on the `Phantom` facade (`ph.positions`). `list(account_id)` returns all open positions for the account. `get(position_id)` returns a single position by ID, raising `NotFoundError` if not found. `close(position_id, reason="manual")` delegates to `PositionManager.close()` which calculates realized P&L, applies any remaining costs, and marks the position closed. `modify(position_id, take_profit=None, stop_loss=None)` updates the TP/SL levels on an open position — passing `None` for a field leaves it unchanged. Modifying a closed position raises `ValidationError`.

## File Locations

- `src/phantom/api/positions.py` — `PositionAPI` class

## Acceptance Criteria

- [ ] `list(account_id)` returns `list[Position]` of open positions only (closed positions excluded)
- [ ] `get(position_id)` raises `NotFoundError("Position", position_id)` if not found
- [ ] `close(position_id, reason="manual")` returns the closed `Position` with `realized_pnl` populated
- [ ] `close()` raises `NotFoundError` if the position does not exist
- [ ] `modify(position_id, take_profit=None, stop_loss=None)` updates only the provided fields
- [ ] `modify()` raises `ValidationError("position", "already closed")` if the position is not open

## Implementation Notes

```python
class PositionAPI:
    def __init__(self, conn: sqlite3.Connection, position_manager: PositionManager) -> None:
        self._manager = position_manager
        self._repo = PositionRepo(conn)

    def list(self, account_id: str) -> list[Position]:
        return self._repo.list(account_id=account_id, status="open")

    def get(self, position_id: str) -> Position:
        return self._repo.get(position_id)  # raises NotFoundError on miss

    def close(self, position_id: str, reason: str = "manual") -> Position:
        return self._manager.close(position_id, reason=reason)

    def modify(self, position_id: str, take_profit: float | None = None,
               stop_loss: float | None = None) -> Position:
        pos = self._repo.get(position_id)
        if pos.status != "open":
            raise ValidationError("position", "already closed")
        return self._manager.modify(position_id, take_profit=take_profit, stop_loss=stop_loss)
```
