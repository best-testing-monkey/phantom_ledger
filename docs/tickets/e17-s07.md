## Description

`NoteAPI` is the public interface for trade note management on the `Phantom` facade (`ph.notes`). Notes are Markdown text documents attached to positions. `add(position_id, title, content)` creates a new note with a ULID, validates that the referenced position exists, and persists via `NoteManager`. `add_from_file(position_id, title, file_path)` reads the file content and delegates to `add()`. `list(position_id)` returns all notes for the position sorted by `created_at` descending. `get(note_id)` raises `NotFoundError` if the note does not exist.

## Acceptance Criteria

- [ ] `add(position_id, title, content)` validates position exists before creating note
- [ ] `add()` raises `NotFoundError("Position", position_id)` if position does not exist
- [ ] `add_from_file(position_id, title, file_path)` raises `DataError("filesystem", reason)` if file cannot be read
- [ ] `list(position_id)` returns `list[Note]` sorted by `created_at` descending; empty list if none
- [ ] `get(note_id)` raises `NotFoundError("Note", note_id)` on miss
- [ ] Integration test: add two notes to a position, `list()` returns both in reverse creation order

## Implementation Notes

```python
class NoteAPI:
    def __init__(self, conn: sqlite3.Connection, position_repo: PositionRepo, note_manager: NoteManager) -> None:
        self._position_repo = position_repo
        self._manager = note_manager

    def add(self, position_id: str, title: str, content: str) -> Note:
        self._position_repo.get(position_id)  # raises NotFoundError on miss
        return self._manager.create(position_id=position_id, title=title, content=content)

    def add_from_file(self, position_id: str, title: str, file_path: str) -> Note:
        try:
            content = Path(file_path).read_text(encoding="utf-8")
        except OSError as e:
            raise DataError("filesystem", str(e))
        return self.add(position_id, title, content)
```
