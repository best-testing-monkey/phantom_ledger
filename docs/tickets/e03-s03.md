# E3-S03: SlippageModel — fixed_pct type

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** MVP
**Depends on:** [E2-S01](e02-s01.md)

## Description

Implement `SlippageModel.calculate()` for `model_type = "fixed_pct"`. Slippage is the cost of market impact — the difference between the expected price and the actual fill price. The fixed percentage model applies a constant fraction of notional value.

## File Locations

- `src/phantom/costs/slippage.py` — `SlippageModel.calculate()`

## Acceptance Criteria

- [ ] `SlippageModel.calculate(price: float, quantity: float) -> float`
- [ ] For `model_type == "fixed_pct"`: returns `fixed_pct * price * quantity`
- [ ] Returns `0.0` when `fixed_pct == 0.0`
- [ ] Unit tests: basic case (`price=185.0, quantity=10, fixed_pct=0.0003` → `0.555`), zero slippage
