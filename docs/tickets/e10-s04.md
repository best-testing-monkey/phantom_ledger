# E10-S04: Replay Single Position CLI Command

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** MVP
**Depends on:** [E10-S01](e10-s01.md), [E10-S05](e10-s05.md)

## Description

Add `phantom replay --position <id>` CLI command that replays a single position by ID. Before calling `ph.replay.replay_position()`, the command checks whether the position has already been replayed (`replay_completed_at IS NOT NULL`). If it has been replayed and `--force` was not passed, print an error and exit code 1. If `--force` is passed, reset `replay_completed_at` to `None` via `ph.positions.reset_replay(position_id)` before proceeding. After successful replay, print a Rich panel summarising the outcome: ticker, direction, entry price, close price (if closed), close reason (if closed), realized P&L (if closed), or "still open" if no exit was triggered. This is the interactive single-position replay path, so no progress bar is needed — a spinner via `console.status()` is sufficient.

## File Locations

- `src/phantom/cli.py` — `replay_single` command on `replay_app`

## Acceptance Criteria

- [ ] Accepts `--position <id>` and optional `--force` flag
- [ ] If `replay_completed_at IS NOT NULL` and `--force` not set: print `[red]Error:[/red] Position already replayed. Use --force to re-run.` and exit 1
- [ ] If `--force`: calls `ph.positions.reset_replay(position_id)` before replaying
- [ ] Uses `console.status("Replaying...")` spinner during the replay call
- [ ] Prints Rich `Panel` with outcome: ticker, direction, entry/close prices, close_reason, realized_pnl or "open"
- [ ] `NotFoundError` for position ID propagates and exits with code 1

## Implementation Notes

```python
@replay_app.command("single")
def replay_single(
    position_id: str = typer.Option(..., "--position", help="Position ULID"),
    force: bool = typer.Option(False, "--force", help="Re-run even if already replayed"),
):
    """Replay a single position by ID."""
    try:
        ph = get_phantom()
        pos = ph.positions.get(position_id)
        if pos.replay_completed_at and not force:
            console.print("[red]Error:[/red] Position already replayed. Use --force to re-run.")
            raise typer.Exit(code=1)
        if force:
            ph.positions.reset_replay(position_id)
            pos = ph.positions.get(position_id)
        with console.status("Replaying..."):
            result = ph.replay.replay_position(pos)
        # render Panel with outcome fields
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
