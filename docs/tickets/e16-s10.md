# E16-S10: Simulated Clock Control Panel

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

Manual backtesting requires control over simulated time. The user needs to see the current simulated datetime and be able to:
1. **Set** it to an arbitrary date/time
2. **Step forward** by N days (default 1)
3. **Step backward** by N days

The simulated clock is stored as a single row in a new `clock` table in the DB (or as a JSON config file in the data dir). This is a web-only feature — the CLI `phantom run backtest` uses the engine's own `BacktestClock`.

## File Locations

- `src/phantom/web/clock.py` *(new)* — `get_clock()`, `set_clock()`, `step_clock()` reading/writing the data dir
- `src/phantom/web/routes/clock.py` *(new)* — `GET /api/clock` (fragment), `POST /clock/set`, `POST /clock/step`
- `src/phantom/web/app.py` — register the new clock router
- `src/phantom/web/templates/_clock_panel.html` *(new)* — the clock widget fragment
- `src/phantom/web/templates/dashboard.html` — embed the clock panel in the header area

## Current State

No simulated clock exists in the web layer. `src/phantom/engine/clock.py` has `BacktestClock` and `LiveClock` but these are engine-level, not web-level.

## Acceptance Criteria

- [ ] A clock panel is visible on the dashboard showing the current simulated datetime (ISO format, UTC)
- [ ] "Set Date" form accepts a `datetime-local` input and writes to the clock store
- [ ] "−N days" and "+N days" buttons step the clock; N defaults to 1 and is editable
- [ ] If no clock has been set, the panel shows "Not set — using wall clock" and the Set form
- [ ] Clock state persists between page reloads (file-backed, not in-memory)
- [ ] The clock panel refreshes via HTMX every 10 s so simultaneous updates are reflected

## Implementation Notes

**`src/phantom/web/clock.py`** — use a simple JSON file in the data dir:

```python
import json
from datetime import datetime, timedelta, timezone
from pathlib import Path
from phantom.config import get_data_dir

_CLOCK_FILE = Path(get_data_dir()) / "web_clock.json"

def get_simulated_now() -> datetime | None:
    if not _CLOCK_FILE.exists():
        return None
    raw = json.loads(_CLOCK_FILE.read_text())
    return datetime.fromisoformat(raw["simulated_now"])

def set_simulated_now(dt: datetime) -> datetime:
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=timezone.utc)
    _CLOCK_FILE.write_text(json.dumps({"simulated_now": dt.isoformat()}))
    return dt

def step_simulated_now(days: int) -> datetime:
    current = get_simulated_now() or datetime.now(timezone.utc)
    return set_simulated_now(current + timedelta(days=days))
```

**`src/phantom/web/routes/clock.py`**:

```python
from fastapi import APIRouter, Form, Request
from fastapi.responses import HTMLResponse, RedirectResponse
from datetime import datetime, timezone
from phantom.web.app import templates
from phantom.web.clock import get_simulated_now, set_simulated_now, step_simulated_now

router = APIRouter()

@router.get("/api/clock", response_class=HTMLResponse)
async def clock_fragment(request: Request):
    now = get_simulated_now()
    return templates.TemplateResponse(
        request=request, name="_clock_panel.html", context={"simulated_now": now}
    )

@router.post("/clock/set")
async def clock_set(dt_str: str = Form(..., alias="simulated_now")):
    dt = datetime.fromisoformat(dt_str).replace(tzinfo=timezone.utc)
    set_simulated_now(dt)
    return RedirectResponse(url="/", status_code=303)

@router.post("/clock/step")
async def clock_step(days: int = Form(...)):
    step_simulated_now(days)
    return RedirectResponse(url="/", status_code=303)
```

**`_clock_panel.html`** example:

```html
<div id="clock-panel" class="card"
     hx-get="/api/clock" hx-trigger="every 10s" hx-target="#clock-panel" hx-swap="outerHTML">
  <h2>Simulated Clock</h2>
  {% if simulated_now %}
    <p><strong>{{ simulated_now.strftime('%Y-%m-%d %H:%M UTC') }}</strong></p>
    <form method="post" action="/clock/step" style="display:inline">
      <input type="number" name="days" value="1" style="width:4rem"> days
      <button name="days" value="-1" type="submit">← Back</button>
      <button type="submit">Forward →</button>
    </form>
  {% else %}
    <p class="neutral">Not set — using wall clock.</p>
  {% endif %}
  <form method="post" action="/clock/set" style="margin-top:0.75rem">
    <input type="datetime-local" name="simulated_now" required>
    <button type="submit">Set</button>
  </form>
</div>
```

Note: the step form above uses a trick — two submit buttons, each with a different `value`. Use separate forms or JS-free hidden field toggling if the browser doesn't support this reliably. Simpler alternative: two separate forms, one for forward and one for back.

---

> **Implementation Standards:** No global state in `clock.py` — always read from the file. The clock file is in `get_data_dir()`, same as the SQLite DB.
