# E16-S11: Order History Page

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

There is no page listing historical orders. Add `/orders` — a full order log for an account showing all statuses (pending, filled, cancelled, rejected), with basic pagination (50 per page).

## File Locations

- `src/phantom/web/routes/orders.py` — add `GET /orders` handler
- `src/phantom/web/templates/order_history.html` *(new)*
- `src/phantom/web/templates/base.html` — add "Orders" nav link

## Current State

- `ph.orders.list(account_name=..., status=None)` returns all orders for an account regardless of status
- Order model fields: `id`, `ticker`, `direction`, `order_type`, `quantity`, `limit_price`, `status`, `created_at`, `filled_at`, `fill_price`
- There is no `/orders` route; the only order route is `GET/POST /orders/new`

## Acceptance Criteria

- [ ] `GET /orders?account=<name>&page=1` renders the order history page
- [ ] Table columns: Symbol, Direction, Type, Qty, Limit Price, Fill Price, Status, Created At, Filled At
- [ ] Status is shown as a coloured badge: `pending`=yellow, `filled`=green, `cancelled`=grey, `rejected`=red
- [ ] 50 orders per page; Previous/Next links appear when there are more
- [ ] If `account` query param is missing, redirect to `/?error=account+required`
- [ ] "Orders" is added to the nav in `base.html` (links to `/orders`)
- [ ] Page title is "Order History — <account name>"

## Implementation Notes

**`orders.py`** — new route:

```python
PAGE_SIZE = 50

@router.get("/orders", response_class=HTMLResponse)
async def order_history(request: Request, account: str | None = None, page: int = 1):
    if not account:
        return RedirectResponse(url="/?error=account+required", status_code=303)
    try:
        ph = get_phantom()
        account_obj = ph.accounts.get(account)
        all_orders = ph.orders.list(account_name=account)
        # Sort newest first
        all_orders.sort(key=lambda o: o.created_at, reverse=True)
        total = len(all_orders)
        start = (page - 1) * PAGE_SIZE
        orders = all_orders[start : start + PAGE_SIZE]
        return templates.TemplateResponse(
            request=request,
            name="order_history.html",
            context={
                "account": account_obj,
                "orders": orders,
                "page": page,
                "total": total,
                "page_size": PAGE_SIZE,
                "has_prev": page > 1,
                "has_next": start + PAGE_SIZE < total,
            },
        )
    except PhantomError as e:
        return RedirectResponse(url=f"/?error={e}", status_code=303)
```
