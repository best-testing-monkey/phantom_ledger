# E11-S06: Note Size Tracking and 5 MB Warning

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** MVP
**Depends on:** [E11-S01](e11-s01.md)

## Description

`NoteManager` must track the byte size of note content on every write operation (`create()` and `update()`). The size is computed as `len(content.encode("utf-8"))` (UTF-8 byte count, not character count). This value is stored in `trade_notes.content_size` and kept in sync on every write. After computing the size, if `content_size > 4_500_000` bytes (4.5 MB), emit a WARNING log: `"Note %s approaching 5 MB limit: current size %d bytes"`. The 5 MB cap itself is not enforced — it is advisory only. The CLI may choose to surface this warning to the user but is not required to by this story. The `content_size` field on the `Note` model must always reflect the actual byte size of the file at the time of last write; the repo `update()` must be called with the new size so the DB stays consistent.

## File Locations

- `src/phantom/notes/manager.py` — `_track_size()` private helper used in `create()` and `update()`

## Acceptance Criteria

- [ ] `content_size` computed as `len(content.encode("utf-8"))` on every write
- [ ] `content_size` persisted to `trade_notes` table on both `create()` and `update()`
- [ ] WARNING log emitted when `content_size > 4_500_000`: `"Note %s approaching 5 MB limit: current size %d bytes"` with note ID and byte count
- [ ] No exception raised — the warning is advisory; write proceeds normally
- [ ] Unit test: create note with 4.6 MB content and assert WARNING was logged (use `caplog`)
- [ ] `Note.content_size` after `create()` matches `len(content.encode("utf-8"))` exactly

## Implementation Notes

```python
import logging
logger = logging.getLogger(__name__)

SIZE_WARNING_THRESHOLD = 4_500_000  # 4.5 MB in bytes

class NoteManager:
    def _track_size(self, note_id: str, content: str) -> int:
        size = len(content.encode("utf-8"))
        if size > SIZE_WARNING_THRESHOLD:
            logger.warning(
                "Note %s approaching 5 MB limit: current size %d bytes",
                note_id, size,
            )
        return size
```
