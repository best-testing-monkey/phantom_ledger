# E1-S04: Initial SQL Migration

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Write `001_initial.sql` creating all MVP database tables and indexes. The schema must match Section 3 of the architecture document exactly, including all `CHECK` constraints, nullable fields, and default values.

## File Locations

- `src/phantom/db/migrations/001_initial.sql`

## Acceptance Criteria

- [ ] All 8 tables created: `broker_profiles`, `accounts`, `orders`, `positions`, `trade_notes`, `equity_curve`, `overnight_log`, `dividend_log`
- [ ] `accounts.account_type` CHECK matches `('pattern','manual','algorithm','aggregate')`
- [ ] `orders.status` CHECK matches `('pending','triggered','filled','expired','rejected','cancelled')`
- [ ] `orders.instrument_type` CHECK matches `('stock','cfd')`, `orders.direction` CHECK matches `('long','short')`
- [ ] `orders.order_type` CHECK matches all 6 types from the architecture
- [ ] `positions.status` CHECK matches `('open','closed','liquidated')`
- [ ] `positions.close_reason` CHECK matches `('tp','sl','trailing_sl','max_time','margin_call','manual',NULL)`
- [ ] All 7 indexes from Section 3 are created (`idx_orders_account`, `idx_orders_status`, `idx_positions_account`, `idx_positions_status`, `idx_positions_ticker`, `idx_equity_account_ts`, `idx_notes_position`)
- [ ] `run_migrations(get_connection(":memory:"))` applies this file without error

## Implementation Notes

Use the exact schema from Section 3 of the architecture document. All IDs are `TEXT PRIMARY KEY`. All timestamps are `TEXT NOT NULL`. Foreign key references use `REFERENCES table(id)`. Cost accumulator columns in `positions` default to `0`.
