# E7-S16: Stock vs CFD Position Behavior

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** P2
**Depends on:** [E7-S11](e07-s11.md), [E7-S15](e07-s15.md)

## Description

Enforce the behavioral distinction between stock and CFD positions throughout `PositionManager`. The two instrument types have different economic models: stocks have no overnight financing cost and require full notional capital (no leverage); CFDs carry overnight financing charges, have broker-defined leverage (so margin requirement is a fraction of notional), and can be short with a dividend charge on ex-dates. These differences are controlled solely by `position.instrument_type` (a `Literal["stock", "cfd"]` field). No separate class hierarchy is needed — the distinction is handled by `if/else` guards in each relevant hook. The goal of this story is to ensure all hooks (`_apply_overnight_cost`, `_compute_margin`, `_apply_dividend`) correctly branch on `instrument_type` and that the behavior is covered by tests for both types.

## File Locations

- `src/phantom/engine/position_manager.py` — verify all hooks guard on `instrument_type`
- `src/phantom/models/position.py` — `instrument_type: InstrumentType` field (already from E7-S01; confirm it is present and typed correctly)
- `tests/unit/test_position_instrument_types.py` — unit tests for both stock and CFD branches

## Acceptance Criteria

- [ ] Stock positions: `overnight_accrued` stays `0.0` after multiple day boundaries
- [ ] Stock positions: `margin_required = 0.0` and `account.used_margin` is unchanged on open/close
- [ ] CFD positions: overnight charge is computed and applied on each day boundary crossing
- [ ] CFD positions: `margin_required > 0` and `account.used_margin` is updated on open/close
- [ ] `instrument_type` field on `Position` is typed as `InstrumentType = Literal["stock", "cfd"]` (not a plain `str`)
- [ ] Unit tests with explicit assertions for stock-no-overnight and CFD-with-overnight in the same test file

# In PositionManager — pattern applied consistently across all hooks:

def _apply_overnight_cost(self, position: Position, ...) -> None:
    if position.instrument_type != "cfd":
        return  # stocks never accrue overnight cost
    ...

def _compute_margin(self, position: Position, margin_model: MarginModel, account: Account) -> float:
    if position.instrument_type == "stock":
        return 0.0  # stocks require full notional, tracked via cash, not margin
    return compute_margin_required(
        quantity=position.quantity,
        price=position.entry_price,
        margin_pct=margin_model.default_margin_pct,
    )
