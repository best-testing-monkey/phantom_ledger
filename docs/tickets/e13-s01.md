# E13-S01: APScheduler Integration

**Epic:** [E13: Paper Trade Scheduler](e13-paper-trade-scheduler.md)
**Phase:** P2
**Depends on:** [E9-S06](e09-s06.md)

## Description

Configure APScheduler's `BlockingScheduler` with an `IntervalTrigger` so that `SimulationEngine.run_paper_tick()` is invoked on a recurring interval. The `PaperTradeScheduler` class wraps the APScheduler instance and exposes `start()` and `stop()` methods. The interval is configurable in seconds. On `start()` the scheduler is started and blocks until `stop()` is called (from a signal handler) or the process is killed. The scheduler must be reentrant-safe: if a tick is still running when the next interval fires, the new tick is skipped rather than overlapping.

## File Locations

- `src/phantom/engine/scheduler.py` — `PaperTradeScheduler` class wrapping APScheduler

## Acceptance Criteria

- [ ] `PaperTradeScheduler(engine, interval_seconds)` instantiates a `BlockingScheduler` with `IntervalTrigger(seconds=interval_seconds)`
- [ ] `scheduler.start()` registers the job and starts the scheduler (blocks until stopped)
- [ ] `scheduler.stop()` shuts down the scheduler cleanly without waiting for running jobs
- [ ] APScheduler job coalesce mode is enabled so overlapping ticks are skipped, not queued
- [ ] `apscheduler` is listed in `pyproject.toml` dependencies
- [ ] Unit test verifies that `start()` schedules a job with the correct interval

## Implementation Notes

```python
from apscheduler.schedulers.blocking import BlockingScheduler
from apscheduler.triggers.interval import IntervalTrigger

class PaperTradeScheduler:
    def __init__(self, engine: SimulationEngine, interval_seconds: int) -> None:
        self._engine = engine
        self._interval = interval_seconds
        self._scheduler = BlockingScheduler()

    def start(self) -> None:
        self._scheduler.add_job(
            self._engine.run_paper_tick,
            trigger=IntervalTrigger(seconds=self._interval),
            coalesce=True,
            max_instances=1,
        )
        self._scheduler.start()

    def stop(self) -> None:
        self._scheduler.shutdown(wait=False)
```
