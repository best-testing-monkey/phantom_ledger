# E8-S02: Margin Call Warning

**Epic:** [E8: Margin Engine](e08-margin-engine.md)
**Phase:** P2
**Depends on:** [E8-S01](e08-s01.md)

## Description

Extend `MarginEngine` with a `handle_margin_call()` method that is invoked when `MarginStatus.status == "margin_call"`. The method must: (1) log a WARNING with the account ID and current margin level; (2) set `account.margin_call_at = now_utc()` if it is not already set (to avoid overwriting the first warning timestamp on repeated calls); (3) persist the updated account to the DB via the account repo; and (4) emit an alert event `"margin_warning"` by calling the alert dispatcher if one is configured. The alert event carries a payload of `{"account_id": ..., "margin_level": ..., "threshold": margin_call_level}`. The alert dispatcher is optional (may be `None` if alerts are not configured) — if absent, skip the dispatch silently. This method must not close any positions; it is a warning only.

## File Locations

- `src/phantom/engine/margin_engine.py` — add `handle_margin_call()` method to `MarginEngine`
- `src/phantom/models/account.py` — ensure `margin_call_at: datetime | None = None` field exists

## Acceptance Criteria

- [ ] `account.margin_call_at` is set to `now_utc()` on the first warning and NOT overwritten on subsequent calls
- [ ] WARNING is logged with account ID and margin level using `%s` formatting (not f-strings)
- [ ] Account is persisted via repo after `margin_call_at` is set
- [ ] Alert event `"margin_warning"` is dispatched when dispatcher is configured; silently skipped when `dispatcher=None`
- [ ] No positions are closed or modified by `handle_margin_call()`
- [ ] Unit test confirms `margin_call_at` is set exactly once across two consecutive calls

## Implementation Notes

```python
def handle_margin_call(
    self,
    account: Account,
    margin_status: MarginStatus,
    account_repo: AccountRepo,
    dispatcher=None,
) -> None:
    """Log margin call warning, flag account, and optionally emit alert."""
    logger.warning(
        "Margin call on account %s: level=%.1f%% threshold=%.1f%%",
        account.id, margin_status.level, margin_status.margin_call_level,
    )
    if account.margin_call_at is None:
        account.margin_call_at = now_utc()
        account_repo.update(account)
    if dispatcher is not None:
        dispatcher.emit("margin_warning", {
            "account_id": account.id,
            "margin_level": margin_status.level,
            "threshold": margin_status.margin_call_level,
        })
```
