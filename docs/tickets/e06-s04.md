# E6-S04: OrderManager.evaluate()

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP
**Depends on:** [E6-S03](e06-s03.md)

## Description

Implement `OrderManager.evaluate()` which is called on each price bar. It checks all pending orders against the bar and determines which should be triggered or filled. Market orders fill immediately; limit orders fill when price crosses the limit.

## File Locations

- `src/phantom/engine/order_manager.py` — add `evaluate()` to `OrderManager`

## Acceptance Criteria

- [ ] `evaluate(bar: pd.Series, pending_orders: list[Order]) -> list[Order]` returns orders that were filled this bar
- [ ] Market orders (`order_type == "market"`): fill at `bar["Open"]`; `status` becomes `"filled"`, `fill_price = bar["Open"]`, `filled_at = bar.name` (bar timestamp)
- [ ] Limit buy (`direction == "long"`): fills when `bar["Low"] <= limit_price`; `fill_price = limit_price`
- [ ] Limit sell (`direction == "short"`): fills when `bar["High"] >= limit_price`; `fill_price = limit_price`
- [ ] Orders that don't trigger remain in `"pending"` status and are returned unchanged (caller keeps them for next bar)
- [ ] `evaluate()` is a pure function — it does not write to the DB (the caller writes fills)
