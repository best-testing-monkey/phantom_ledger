# E2-S02: Broker Profile JSON Loader

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** MVP

## Description

Implement `load_profile(path)` in `src/phantom/profiles/loader.py`. It reads a broker JSON file, flattens the nested structure (the JSON has a top-level `"profile"` key alongside sibling keys for each cost model), validates it against `BrokerProfile`, and returns a typed instance. This function is the canonical reference implementation from A.13.

## File Locations

- `src/phantom/profiles/__init__.py` — package marker
- `src/phantom/profiles/loader.py` — `load_profile()` function

## Acceptance Criteria

- [ ] `load_profile(path: str | Path) -> BrokerProfile` exists
- [ ] Raises `ProfileError("Profile file not found: {path}")` if file doesn't exist
- [ ] Raises `ProfileError("Invalid JSON in {path}: ...")` if JSON is malformed
- [ ] Raises `ProfileError("Validation failed for {path}: ...")` if Pydantic validation fails
- [ ] Correctly flattens the JSON structure: merges `raw["profile"]` fields with the other top-level sections (`commission`, `spread`, `slippage`, `overnight`, `margin`, `dividend`, `trading_hours`)
- [ ] Returns a valid `BrokerProfile` instance on success
- [ ] Unit tests in `tests/unit/test_broker_loader.py` cover: valid load, missing file, invalid JSON, missing required field
