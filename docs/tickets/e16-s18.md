# E16-S18: Broker Comparison Fix and Account Selector

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

The "Broker Compare" nav link goes to `/brokers/compare` with no `?account=` parameter, which immediately renders an error: `"account parameter is required"`. Fix this by adding an account selector form that appears when no account is specified, rather than showing an error.

## File Locations

- `src/phantom/web/routes/brokers.py` — handle the no-account case gracefully
- `src/phantom/web/templates/broker_comparison.html` — render selector form when no account chosen
- `src/phantom/web/templates/base.html` — update nav link

## Current State

`brokers.py` line ~10: `if not account: return TemplateResponse(..., status_code=400, context={"error": "account parameter is required"})`.

The template then renders a red error box. There is no way to select an account from that page.

## Acceptance Criteria

- [ ] `GET /brokers/compare` with no `?account=` renders a clean "Select an account to compare broker costs" page with a `<select>` dropdown populated from `ph.accounts.list()`
- [ ] Selecting an account and clicking "Compare" navigates to `/brokers/compare?account=<name>`
- [ ] The existing comparison table renders correctly when `?account=<name>` is provided
- [ ] Nav link in `base.html` remains `/brokers/compare` (no hardcoded account) — the landing page now handles the empty state gracefully
- [ ] If no accounts exist, show "Create an account first using the CLI." instead of the selector
- [ ] HTTP status is 200 (not 400) when no account is specified

## Implementation Notes

**`brokers.py`** — replace the early return:

```python
@router.get("/brokers/compare", response_class=HTMLResponse)
async def broker_comparison(request: Request, account: str | None = Query(None)):
    ph = get_phantom()
    accounts = ph.accounts.list()

    if not account:
        return templates.TemplateResponse(
            request=request,
            name="broker_comparison.html",
            context={"account": None, "comparison": None, "accounts": accounts},
        )
    # ... existing logic unchanged ...
```

**`broker_comparison.html`** — add at the top of the content block:

```html
{% if not account %}
  <h1>Broker Comparison</h1>
  {% if not accounts %}
    <div class="card">
      <p class="neutral">No accounts found. Create one using the CLI first.</p>
    </div>
  {% else %}
    <div class="card">
      <p>Select an account to compare broker costs across DEGIRO, IBKR, and XTB.</p>
      <form method="get" action="/brokers/compare" style="margin-top:1rem;">
        <label>Account</label>
        <select name="account">
          {% for a in accounts %}
          <option value="{{ a.name }}">{{ a.name }}</option>
          {% endfor %}
        </select>
        <button type="submit">Compare</button>
      </form>
    </div>
  {% endif %}
{% else %}
  {# existing comparison table content #}
{% endif %}
```

Also pass `accounts` to the context in the existing account-selected path so the page can show a switcher when the account is already chosen.

---

> **Implementation Standards:** Never return HTTP 400 for a missing optional filter — show a selection UI instead. Keep the existing comparison logic unchanged; only the empty-state handling changes.
