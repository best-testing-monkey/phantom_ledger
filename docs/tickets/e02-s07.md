# E2-S07: XTB Broker Profile JSON

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** P2

## Description

Write the XTB broker profile JSON. XTB offers zero-commission stock trading but earns revenue through wider spreads on stocks and overnight financing on CFDs.

## File Locations

- `src/phantom/profiles/xtb.json`

## Acceptance Criteria

- [ ] File exists at `src/phantom/profiles/xtb.json`
- [ ] `load_profile("src/phantom/profiles/xtb.json")` returns a valid `BrokerProfile` without error
- [ ] `profile.name == "XTB"`
- [ ] `profile.commission.model_type == "zero"` for stocks (with a `monthly_free_volume` threshold)
- [ ] `profile.spread.base_spread_pct` reflects XTB's wider spread compared to DEGIRO
- [ ] `profile.supported_instruments` includes `"stock"` and `"cfd"`
- [ ] `profile.overnight` has non-zero rates for CFD positions
