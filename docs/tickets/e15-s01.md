# E15-S01: Strategy Protocol Definition

**Epic:** [E15: Strategy Automation Hooks](e15-strategy-automation.md)
**Phase:** P3

## Description

Define the `Strategy` Protocol and `StrategyContext` dataclass that together form the contract between user-written trading algorithms and the Phantom simulation engine. `Strategy` is a `typing.Protocol` with a single required method `on_bar`. The method receives the current OHLCV bar as a `pd.Series`, the current `Account` state, the list of open `Position` objects, and a `StrategyContext` instance. It returns a list of `OrderRequest` objects to be placed this bar (empty list = no new orders). `StrategyContext` is a dataclass that wraps the engine and provides a `place_order()` convenience method for strategies that prefer to call it directly rather than returning requests.

## File Locations

- `src/phantom/engine/strategy.py` — `Strategy` Protocol, `StrategyContext` dataclass, `OrderRequest` import re-export

## Acceptance Criteria

- [ ] `Strategy` is a `typing.Protocol` with `on_bar(bar, account, positions, context) -> list[OrderRequest]`
- [ ] `StrategyContext` is a `dataclasses.dataclass` with `account_id: str` and an internal `_engine` reference
- [ ] `StrategyContext.place_order(**kwargs)` delegates to `engine.order_manager.place(...)` and returns an `Order`
- [ ] A class with the correct `on_bar` signature passes `isinstance(obj, Strategy)` check via `runtime_checkable`
- [ ] The module has no circular imports with `phantom.engine.simulation_engine`
- [ ] Unit test: a minimal `MyStrategy` class satisfies the Protocol

## Implementation Notes

```python
from typing import Protocol, runtime_checkable
from dataclasses import dataclass
import pandas as pd
from phantom.models.account import Account
from phantom.models.position import Position
from phantom.models.order import OrderRequest

@runtime_checkable
class Strategy(Protocol):
    def on_bar(
        self,
        bar: pd.Series,
        account: Account,
        positions: list[Position],
        context: "StrategyContext",
    ) -> list[OrderRequest]: ...

@dataclass
class StrategyContext:
    account_id: str
    _engine: object  # SimulationEngine, typed as object to avoid circular import

    def place_order(self, **kwargs) -> object:
        return self._engine.order_manager.place(account_id=self.account_id, **kwargs)
```
