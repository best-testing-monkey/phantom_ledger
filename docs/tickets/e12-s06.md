# E12-S06: Per-Pattern-Tag Filtering

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P2
**Depends on:** [E12-S01](e12-s01.md), [E12-S02](e12-s02.md)

## Description

Add `--pattern <tag>` filter option to `phantom report --account <name> --pattern <tag>` that restricts metric computation to positions whose `pattern_tag` field exactly matches the supplied tag (case-sensitive). The filtering happens in the CLI before calling `calculate_metrics()` and `calculate_trade_metrics()` — the `ph.positions.list()` call gains an optional `pattern_tag` kwarg that translates to a `WHERE pattern_tag = ?` SQL clause in `PositionRepo.list()`. The cost aggregation (`aggregate_costs()`) is also filtered to the same subset. The report header panel must display `"Pattern: <tag>"` to make clear the report is filtered. If no positions match the tag, print `"No positions found with pattern_tag='<tag>'"` and exit 0.

## File Locations

- `src/phantom/cli.py` — `report` command updated with `--pattern` option
- `src/phantom/db/repositories/position_repo.py` — `list()` gains `pattern_tag: str | None = None` filter

## Acceptance Criteria

- [ ] `phantom report --account <name> --pattern <tag>` filters positions by exact `pattern_tag` match
- [ ] `PositionRepo.list()` accepts `pattern_tag: str | None = None`; adds `WHERE pattern_tag = ?` when set
- [ ] Both equity metrics and trade metrics computed on the filtered subset only
- [ ] Report output includes `"Pattern: <tag>"` label (in panel title or header row)
- [ ] No matching positions: prints notice and exits 0 (not an error)
- [ ] Without `--pattern`, behaviour is identical to E12-S04 (no regression)

## Implementation Notes

```python
# PositionRepo.list() extension (fragment)
def list(
    self,
    account_name: str | None = None,
    pattern_tag: str | None = None,
    replay_completed_at: str | None = _UNSET,
    **kwargs,
) -> list[Position]:
    clauses = []
    params: list = []
    if account_name:
        clauses.append("account_id = (SELECT id FROM accounts WHERE name = ?)")
        params.append(account_name)
    if pattern_tag is not None:
        clauses.append("pattern_tag = ?")
        params.append(pattern_tag)
    where = ("WHERE " + " AND ".join(clauses)) if clauses else ""
    rows = self._conn.execute(
        f"SELECT * FROM positions {where} ORDER BY entry_datetime ASC",
        params,
    ).fetchall()
    return [self._row_to_model(r) for r in rows]

# CLI fragment
@app.command("report")
def report(
    account: str = typer.Option(..., "--account"),
    pattern: str | None = typer.Option(None, "--pattern"),
):
    ...
    positions = ph.positions.list(account_name=account, pattern_tag=pattern)
```
