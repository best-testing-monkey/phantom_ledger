# E8-S01: MarginEngine.check()

**Epic:** [E8: Margin Engine](e08-margin-engine.md)
**Phase:** P2
**Depends on:** [E7-S15](e07-s15.md), [E5-S01](e05-s01.md)

## Description

Implement the core margin level computation in `MarginEngine.check()`. The method accepts an `Account` and a `BrokerProfile` and returns a `MarginStatus` dataclass. Margin level is defined as `equity / used_margin * 100` (expressed as a percentage). `equity` is `account.cash + sum(open_position_market_values)` — the market value of open positions must be passed in or computed from a positions list provided to `check()`. If `used_margin == 0` the account has no leveraged exposure and `margin_level` is `float("inf")`, with status `"ok"`. The status is one of three values: `"ok"` (level above margin call threshold), `"margin_call"` (at or below `margin_call_level`), or `"stop_out"` (at or below `stop_out_level`). Thresholds come from `broker_profile.margin.margin_call_level` and `broker_profile.margin.stop_out_level` (stored as percentages, e.g. 100.0 and 50.0). `MarginStatus` is a frozen Pydantic model.

```python
# src/phantom/models/margin_status.py
from typing import Literal
from pydantic import BaseModel

class MarginStatus(BaseModel, frozen=True):
    level: float                              # margin_level percentage
    status: Literal["ok", "margin_call", "stop_out"]
    margin_call_level: float                  # from broker profile (e.g. 100.0)
    stop_out_level: float                     # from broker profile (e.g. 50.0)

# src/phantom/engine/margin_engine.py
import logging
from phantom.models.account import Account
from phantom.models.broker import BrokerProfile
from phantom.models.margin_status import MarginStatus

logger = logging.getLogger(__name__)

class MarginEngine:
    def check(
        self,
        account: Account,
        broker_profile: BrokerProfile,
        open_position_market_value: float,
    ) -> MarginStatus:
        """Compute margin level and return status."""
        margin_call_level = broker_profile.margin.margin_call_level
        stop_out_level = broker_profile.margin.stop_out_level
        if account.used_margin == 0:
            return MarginStatus(
                level=float("inf"), status="ok",
                margin_call_level=margin_call_level, stop_out_level=stop_out_level,
            )
        equity = account.cash + open_position_market_value
        level = equity / account.used_margin * 100
        if level <= stop_out_level:
            status = "stop_out"
        elif level <= margin_call_level:
            status = "margin_call"
        else:
            status = "ok"
        return MarginStatus(level=level, status=status,
                            margin_call_level=margin_call_level, stop_out_level=stop_out_level)
```
