# E8-S04: Margin Integration Test

**Epic:** [E8: Margin Engine](e08-margin-engine.md)
**Phase:** P2
**Depends on:** [E8-S03](e08-s03.md)

## Description

Write an integration test that exercises the full stop-out cascade end-to-end using the public API and an in-memory SQLite database. The test creates an account with a CFD broker profile (low margin percentage so positions are highly leveraged), opens three CFD positions on different symbols, then simulates a price drop large enough to push margin level below the stop-out threshold. The test verifies: positions are closed in the correct order (largest unrealized loss first), `account.used_margin` is correctly decremented after each close, and the final account state has a margin level above `stop_out_level` (or zero remaining open positions). The test must not mock the database. External HTTP (yfinance/market data) must be mocked with `unittest.mock.patch`.

## File Locations

- `tests/integration/test_margin_cascade.py` — integration test module

## Acceptance Criteria

- [ ] Three CFD positions opened with distinct entry prices and quantities such that a uniform price drop produces three different unrealized loss amounts
- [ ] After the price drop is applied, `MarginEngine.check()` returns `status="stop_out"`
- [ ] The cascade closes positions in correct order: largest loss closed first, then second largest, and so on
- [ ] `account.used_margin` after each close equals the sum of `margin_required` for the remaining open positions
- [ ] If margin recovers after closing the first (worst) position, the second position is NOT closed
- [ ] All assertions use exact equality for margin amounts and `pytest.approx()` only for floating-point P&L

```python
# tests/integration/test_margin_cascade.py
import pytest
from phantom import Phantom

class TestMarginCascade:
    def test_stop_out_closes_largest_loss_first(self, phantom_instance):
        # 1. Create CFD account with 1000 EUR, margin_pct=0.10, stop_out_level=50
        # 2. Open 3 positions: A (loss=-300), B (loss=-100), C (loss=-50) at drop price
        # 3. Trigger bar update with drop price
        # 4. Assert positions closed in order: A, then check if recovered
        ph = phantom_instance
        account = ph.accounts.create(
            name="margin_test", account_type="manual",
            broker="TEST_CFD", capital=1000.0, currency="EUR"
        )
        pos_a = ph.positions.open(account_id=account.id, ticker="AAA", ...)
        pos_b = ph.positions.open(account_id=account.id, ticker="BBB", ...)
        pos_c = ph.positions.open(account_id=account.id, ticker="CCC", ...)
        # simulate price drop — run one bar through the engine
        ...
        closed = ph.positions.list(status="closed")
        assert closed[0].ticker == "AAA"  # largest loss closed first
        refreshed_account = ph.accounts.get(account.id)
        assert refreshed_account.used_margin == pytest.approx(
            pos_b.margin_required + pos_c.margin_required
        )
```
