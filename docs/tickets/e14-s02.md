# E14-S02: Alert Dispatcher

**Epic:** [E14: Alerts & Notifications](e14-alerts.md)
**Phase:** P3
**Depends on:** [E14-S01](e14-s01.md)

## Description

Implement `AlertDispatcher`, a simple fanout that holds a list of sender objects and calls each one when `dispatch(event)` is invoked. Senders are registered with `dispatcher.register(sender)`. Each sender must implement the `AlertSender` Protocol: `send(event: AlertEvent) -> None`. If any individual sender raises an exception, the dispatcher logs it at ERROR level and continues delivering to remaining senders — a failing Telegram sender must not block Discord delivery. The dispatcher itself never raises. This fanout design allows multiple notification channels to coexist without coupling.

## File Locations

- `src/phantom/alerts/dispatcher.py` — `AlertSender` Protocol, `AlertDispatcher` class

## Acceptance Criteria

- [ ] `AlertSender` Protocol defines `send(event: AlertEvent) -> None`
- [ ] `AlertDispatcher.register(sender: AlertSender)` appends the sender to an internal list
- [ ] `AlertDispatcher.dispatch(event: AlertEvent)` calls `sender.send(event)` for each registered sender
- [ ] If a sender raises, the error is logged with `logger.error("Alert sender %s failed: %s", sender, e, exc_info=True)` and remaining senders continue
- [ ] `dispatch()` on a dispatcher with zero senders is a no-op (no exception)
- [ ] Unit test: one failing sender does not prevent a second sender from being called

## Implementation Notes

```python
from typing import Protocol
from phantom.alerts.events import AlertEvent

class AlertSender(Protocol):
    def send(self, event: AlertEvent) -> None: ...

class AlertDispatcher:
    def __init__(self) -> None:
        self._senders: list[AlertSender] = []

    def register(self, sender: AlertSender) -> None:
        self._senders.append(sender)

    def dispatch(self, event: AlertEvent) -> None:
        for sender in self._senders:
            try:
                sender.send(event)
            except Exception as e:
                logger.error("Alert sender %s failed: %s", sender, e, exc_info=True)
```
