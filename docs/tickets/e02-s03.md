# E2-S03: DEGIRO Broker Profile JSON

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** MVP

## Description

Write the DEGIRO broker profile JSON file. This is the primary profile used throughout development and testing. It represents a stock-only, no-leverage broker with a flat €1.00 commission, dynamic spread, no overnight cost, and Dutch dividend withholding tax rates.

## File Locations

- `src/phantom/profiles/degiro.json`

## Acceptance Criteria

- [ ] File exists at `src/phantom/profiles/degiro.json`
- [ ] `load_profile("src/phantom/profiles/degiro.json")` returns a valid `BrokerProfile` without error
- [ ] `profile.name == "DEGIRO"`
- [ ] `profile.commission.model_type == "fixed"` and `profile.commission.fixed_fee == 1.0`
- [ ] `profile.spread.model_type == "dynamic"` with `base_spread_pct`, `volatility_multiplier`, and `time_of_day_curve` populated
- [ ] `profile.slippage.model_type == "fixed_pct"`
- [ ] `profile.overnight.rate_source == "manual"` and `profile.overnight.manual_rate == 0.0`
- [ ] `profile.margin.default_margin_pct == 1.0` (no leverage)
- [ ] `profile.dividend.withholding_rates` includes `"US": 0.15` and `"NL": 0.15`
- [ ] `profile.supported_instruments` includes `"stock"` and `"etf"`
- [ ] `profile.fx_base_currency == "EUR"`

## Implementation Notes

Use the exact JSON structure from Section 6 of the architecture document.
