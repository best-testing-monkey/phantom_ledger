# E15-S02: Strategy Loader

**Epic:** [E15: Strategy Automation Hooks](e15-strategy-automation.md)
**Phase:** P3
**Depends on:** [E15-S01](e15-s01.md)

## Description

Implement `load_strategy(path: str) -> Strategy` that dynamically imports a Python file at the given path, inspects all top-level classes defined in it, and returns an instance of the first class that satisfies the `Strategy` Protocol. The file is imported using `importlib` with a generated module name derived from the file stem. If the file does not exist, raise `ProfileError(path, "file not found")`. If the file imports successfully but contains no class implementing `Strategy`, raise `ProfileError(path, "no Strategy class found")`. The loaded class is instantiated with no arguments — strategies that require configuration should read it from environment variables or a config file.

## File Locations

- `src/phantom/engine/strategy.py` — `load_strategy()` function

## Acceptance Criteria

- [ ] `load_strategy(path)` returns an instance whose class satisfies the `Strategy` Protocol
- [ ] Raises `ProfileError(path, "file not found")` if the path does not exist
- [ ] Raises `ProfileError(path, "no Strategy class found")` if no suitable class is in the module
- [ ] Only classes defined in the module (not imported ones) are considered candidates
- [ ] The module is imported using `importlib.util.spec_from_file_location` with a unique module name
- [ ] Unit test: a temp file with a valid Strategy class is loaded correctly; a file with no strategy raises `ProfileError`

## Implementation Notes

```python
import importlib.util
import inspect
from pathlib import Path
from phantom.engine.strategy import Strategy
from phantom.errors import ProfileError

def load_strategy(path: str) -> Strategy:
    p = Path(path)
    if not p.exists():
        raise ProfileError(path, "file not found")
    spec = importlib.util.spec_from_file_location(f"_strategy_{p.stem}", p)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    for name, obj in inspect.getmembers(module, inspect.isclass):
        if obj.__module__ == module.__name__ and isinstance(obj, type) and issubclass_protocol(obj, Strategy):
            return obj()
    raise ProfileError(path, "no Strategy class found")
```
