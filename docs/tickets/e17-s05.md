# E17-S05: OrderAPI

**Depends on:** [E6](e06-order-system.md), [E17-S02](e17-s02.md)

## Description

`OrderAPI` is the public interface for order management on the `Phantom` facade (`ph.orders`). `place()` validates that the account exists and that the symbol is non-empty, then delegates to `OrderManager.place()` which handles fill logic, cost calculation, and position creation. The returned `Order` object includes the computed `CostBreakdown` and the resulting `position_id` if the order was filled. `list(account_id)` returns all orders for the account ordered by `created_at` descending. `cancel(order_id)` raises `NotFoundError` if the order doesn't exist or `ValidationError` if the order is already filled and cannot be cancelled.

## Acceptance Criteria

- [ ] `place(account_id, symbol, side, quantity, order_type, ...)` validates account exists before delegating
- [ ] `place()` raises `ValidationError("symbol", "must not be empty")` for blank symbol
- [ ] `place()` raises `NotFoundError("Account", account_id)` if account does not exist
- [ ] `list(account_id)` returns `list[Order]`, empty if no orders exist
- [ ] `cancel(order_id)` raises `NotFoundError` if order not found; raises `ValidationError` if order status is `"filled"`
- [ ] Integration test: placing a market order for a seeded account returns an `Order` with `status="filled"`

## Implementation Notes

```python
class OrderAPI:
    def __init__(self, conn: sqlite3.Connection, account_repo: AccountRepo, order_manager: OrderManager) -> None:
        self._account_repo = account_repo
        self._manager = order_manager
        self._repo = OrderRepo(conn)

    def place(self, account_id: str, symbol: str, side: str, quantity: float,
              order_type: str = "market", **kwargs) -> Order:
        if not symbol.strip():
            raise ValidationError("symbol", "must not be empty")
        self._account_repo.get(account_id)  # raises NotFoundError on miss
        return self._manager.place(account_id=account_id, symbol=symbol,
                                   side=side, quantity=quantity, order_type=order_type, **kwargs)
```
