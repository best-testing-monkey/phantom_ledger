# E16-S08: Open Orders Panel

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

Pending and limit orders placed via the UI are invisible after submission — there is no page that shows them or allows cancellation. Add an "Open Orders" card to the dashboard (below the positions table) showing all `pending` and `partial` orders for the current account, with a Cancel button for each.

## File Locations

- `src/phantom/web/routes/dashboard.py` — fetch pending orders and include in context
- `src/phantom/web/templates/dashboard.html` — add Open Orders card
- `src/phantom/web/routes/orders.py` — add `POST /orders/{order_id}/cancel` endpoint
- `src/phantom/web/templates/_orders_rows.html` *(new)* — HTMX fragment for the orders table body

## Current State

- `ph.orders.list(account_name=..., status="pending")` exists and works
- `ph.orders.cancel(order_id)` exists: raises `ValidationError` if status is not `"pending"`, returns the updated `Order`
- The dashboard template has no orders section at all

## Acceptance Criteria

- [ ] Dashboard shows an "Open Orders" card after the positions card
- [ ] Card lists: Symbol, Direction, Type, Quantity, Limit Price (or "—"), Created At, and a Cancel button
- [ ] Cancelling an order sends `POST /orders/{order_id}/cancel`, redirects back to `/?account=<name>`
- [ ] If there are no pending orders the card shows "No open orders."
- [ ] The order list auto-refreshes every 30 s via HTMX (same pattern as positions)
- [ ] Cancelling an already-filled order shows an inline error message (the redirect carries `?error=...`)

## Implementation Notes

**`dashboard.py`** — add to context:

```python
pending_orders = ph.orders.list(account_name=account_obj.name, status="pending")
# context dict: "pending_orders": pending_orders
```

**`orders.py`** — new cancel endpoint:

```python
@router.post("/orders/{order_id}/cancel")
async def cancel_order(order_id: str, account: str = Form(...)):
    try:
        ph = get_phantom()
        ph.orders.cancel(order_id)
        return RedirectResponse(url=f"/?account={account}", status_code=303)
    except PhantomError as e:
        return RedirectResponse(url=f"/?account={account}&error={e}", status_code=303)
```

**`_orders_rows.html`** (new fragment):

```html
<tbody id="orders-tbody">
{% for order in pending_orders %}
<tr>
  <td>{{ order.ticker }}</td>
  <td>{{ order.direction }}</td>
  <td>{{ order.order_type }}</td>
  <td>{{ order.quantity }}</td>
  <td>{{ order.limit_price if order.limit_price else "—" }}</td>
  <td>{{ order.created_at[:19] }}</td>
  <td>
    <form method="post" action="/orders/{{ order.id }}/cancel">
      <input type="hidden" name="account" value="{{ account.name }}">
      <button class="secondary" style="padding:0.3rem 0.75rem;font-size:0.85rem;"
              onclick="return confirm('Cancel this order?')">Cancel</button>
    </form>
  </td>
</tr>
{% endfor %}
</tbody>
```

Add the card in `dashboard.html` with:

```html
hx-get="/api/orders-rows?account={{ account.name }}"
hx-trigger="every 30s"
hx-target="#orders-tbody"
hx-swap="innerHTML"
```

Also add `GET /api/orders-rows` to `api.py` mirroring the existing `positions-rows` endpoint.
