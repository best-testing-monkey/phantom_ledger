# E4-S01: HistoricalProvider

**Epic:** [E4: Data Layer](e04-data-layer.md)
**Phase:** MVP

## Description

Implement `HistoricalProvider`, the primary data source for backtesting. It fetches OHLCV from price_cache submodule ( git@github.com:best-testing-monkey/price_cache.git ) keyed by ticker. Subsequent calls for the same ticker serve from cache without hitting the network.

## File Locations

- `src/phantom/data/__init__.py` — package marker
- `src/phantom/data/yahoo.py` — `HistoricalProvider` class
- `src/phantom/data/price_store.py` — Parquet read/write helpers

## Acceptance Criteria

- [ ] `HistoricalProvider(data_dir: str | Path)` stores the data directory path
- [ ] `get_bars(ticker: str, start: datetime, end: datetime) -> pd.DataFrame` returns OHLCV DataFrame
- [ ] On cache miss: calls `yfinance.download(ticker, start=start, end=end)`, saves to `data/prices/{ticker}.parquet`
- [ ] On cache hit (parquet file exists and is fresh): reads from Parquet without calling yfinance
- [ ] Returned DataFrame has a `DatetimeIndex` and columns: `Open`, `High`, `Low`, `Close`, `Volume`
- [ ] Returns empty DataFrame (not error) for invalid tickers or out-of-range dates
- [ ] In tests, yfinance calls are mocked with `unittest.mock.patch`
