# E16-S14: Equity Curve Chart

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

The backend stores equity curve data (`EquityRepo`) and the `ReportAPI` can produce metrics, but no chart is rendered in the web UI. Add a line chart to the dashboard showing the account's equity over time, rendered with Chart.js (loaded from CDN — no npm required).

## File Locations

- `src/phantom/web/routes/api.py` — add `GET /api/equity-data?account=<name>` returning JSON
- `src/phantom/web/templates/dashboard.html` — add chart card with a `<canvas>` element
- `src/phantom/web/templates/base.html` — add Chart.js CDN script tag in `{% block extra_js %}`

## Current State

- `src/phantom/db/repositories/equity_repo.py` has `list(account_id)` returning `list[EquityPoint]` where each point has `.timestamp` (datetime) and `.equity` (float)
- The equity repo is not exposed on `Phantom` directly — access it via `ph.reports.account_metrics(name)["equity"]` which returns a dict, or instantiate it directly: `from phantom.db.repositories.equity_repo import EquityRepo; EquityRepo(conn).list(account_id)`
- The dashboard already has HTMX polling — the chart should NOT poll (equity data changes only on fills/closes, not every 30s)

## Acceptance Criteria

- [ ] `GET /api/equity-data?account=<name>` returns `{"labels": ["2024-01-02", ...], "values": [10000.0, ...]}`
- [ ] Dashboard has an "Equity Curve" card containing a `<canvas id="equity-chart">`
- [ ] Chart.js renders a line chart from the JSON endpoint on page load
- [ ] If there are fewer than 2 data points the card shows "No equity data yet."
- [ ] Chart is responsive (Chart.js `responsive: true`)
- [ ] Chart.js is loaded from `https://cdn.jsdelivr.net/npm/chart.js` via a `<script>` tag in `base.html`

## Implementation Notes

**`api.py`** — new JSON endpoint:

```python
from fastapi.responses import JSONResponse

@router.get("/api/equity-data")
async def equity_data(account: str | None = Query(None)):
    if not account:
        return JSONResponse({"labels": [], "values": []})
    try:
        ph = get_phantom()
        account_obj = ph.accounts.get(account)
        from phantom.db.repositories.equity_repo import EquityRepo
        points = EquityRepo(ph._conn).list(account_obj.id)
        labels = [p.timestamp.strftime("%Y-%m-%d %H:%M") for p in points]
        values = [p.equity for p in points]
        return JSONResponse({"labels": labels, "values": values})
    except PhantomError:
        return JSONResponse({"labels": [], "values": []})
```

Note: `ph._conn` is the internal sqlite3 connection on the `Phantom` facade — using it directly is acceptable in the web layer since the web layer lives inside the same process.

**`dashboard.html`** — add after the positions card:

```html
<div class="card">
  <h2>Equity Curve</h2>
  <canvas id="equity-chart" height="80"></canvas>
</div>

<script>
(async () => {
  const resp = await fetch("/api/equity-data?account={{ account.name }}");
  const data = await resp.json();
  if (data.labels.length < 2) {
    document.getElementById("equity-chart").replaceWith(
      Object.assign(document.createElement("p"), {className: "neutral", textContent: "No equity data yet."})
    );
    return;
  }
  new Chart(document.getElementById("equity-chart"), {
    type: "line",
    data: {
      labels: data.labels,
      datasets: [{label: "Equity", data: data.values, borderColor: "#3498db", tension: 0.1, pointRadius: 2}]
    },
    options: {responsive: true, plugins: {legend: {display: false}}}
  });
})();
</script>
```

**`base.html`** — add at the bottom of `<head>` (inside `{% block extra_js %}{% endblock %}`):

```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```
