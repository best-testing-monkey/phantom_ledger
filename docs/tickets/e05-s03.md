# E5-S03: CLI — account create

**Epic:** [E5: Account System](e05-account-system.md)
**Phase:** MVP
**Depends on:** [E5-S01](e05-s01.md), [E5-S02](e05-s02.md)

## Description

Wire up `phantom account create` with support for all four account types and their type-specific flags. The command calls `ph.accounts.create()` and prints the resulting account.

## File Locations

- `src/phantom/cli.py` — add `account_create` command

## Acceptance Criteria

- [ ] `phantom account create --name insider_buys --type pattern --broker DEGIRO --capital 10000 --currency EUR --pattern insider_cluster` creates a pattern account
- [ ] `phantom account create --name discretionary --type manual --broker DEGIRO --capital 25000` creates a manual account (currency defaults to EUR)
- [ ] `phantom account create --name algo1 --type algorithm --broker DEGIRO --capital 50000 --algorithm-id my_algo --algorithm-version v1` creates an algorithm account
- [ ] `phantom account create --name all --type aggregate --broker DEGIRO --capital 0 --children insider_buys,discretionary` creates an aggregate account
- [ ] Missing required type-specific field (e.g. `--type pattern` without `--pattern`) shows `[red]Error:[/red]` and exits 1
- [ ] On success, prints the created account as a Rich panel
