# E9-S08: Graceful Shutdown

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** P2
**Depends on:** [E9-S06](e09-s06.md)

## Description

Implement graceful shutdown for the simulation loop by registering OS signal handlers for `SIGINT` and `SIGTERM`. When either signal is received, the handler sets a `threading.Event` (`stop_event`) that the loop checks at the top of each iteration. The loop must finish the current tick completely (all orders evaluated, positions updated, equity recorded, DB committed) before checking the event and exiting. After the loop exits, the engine performs a final `conn.commit()`, logs `"simulation stopped cleanly"` at INFO level, and allows the process to exit normally with code 0. The signal handler itself must be installed by `SimulationEngine.run_paper()` before the loop starts and uninstalled (restored to default) after the loop exits, so that the engine can be used in tests without polluting the signal handlers of the test process.

## File Locations

- `src/phantom/engine/simulation_engine.py` — install/uninstall signal handlers inside `run_paper()`

## Acceptance Criteria

- [ ] `SIGINT` sets `stop_event`; the loop exits after completing the current tick
- [ ] `SIGTERM` also sets `stop_event` and triggers the same clean shutdown path
- [ ] DB state is committed before the process exits (no partial bar state left uncommitted)
- [ ] `"simulation stopped cleanly"` is logged at INFO after the loop exits
- [ ] Signal handlers are restored to their previous values after `run_paper()` returns
- [ ] Unit test: send `SIGINT` to the process during a mock loop iteration and assert the loop exits after finishing the current step

## Implementation Notes

```python
import signal
import threading

def run_paper(self, account_id: str, tickers: list[str], interval: float,
              stop_event: threading.Event | None = None) -> None:
    if stop_event is None:
        stop_event = threading.Event()

    def _handle_signal(signum, frame):
        logger.info("Signal %s received, stopping simulation...", signum)
        stop_event.set()

    old_sigint = signal.signal(signal.SIGINT, _handle_signal)
    old_sigterm = signal.signal(signal.SIGTERM, _handle_signal)
    try:
        clock = LiveClock(interval=interval)
        while not stop_event.is_set():
            # ... bar processing ...
            self._conn.commit()
            clock.advance()
        self._conn.commit()
        logger.info("simulation stopped cleanly")
    finally:
        signal.signal(signal.SIGINT, old_sigint)
        signal.signal(signal.SIGTERM, old_sigterm)
```
