# E13-S05: Systemd Service Template

**Epic:** [E13: Paper Trade Scheduler](e13-paper-trade-scheduler.md)
**Phase:** P3

## Description

Provide a Jinja2 template for a systemd user service and a `phantom service install` CLI command that renders the template and writes the resulting `.service` file to `~/.config/systemd/user/phantom-{account}.service`. The template must set `ExecStart` to the full path of the `phantom` executable with the `run --account {account} --mode paper` arguments, set `Restart=on-failure`, and include `WantedBy=default.target`. After writing the file, the command prints instructions for enabling and starting the service with `systemctl --user enable/start phantom-{account}`. No systemd commands are run automatically — the user must do that themselves.

## File Locations

- `src/phantom/templates/phantom.service.jinja2` — systemd unit file template
- `src/phantom/cli.py` — `service install` subcommand

## Acceptance Criteria

- [ ] `phantom service install --account <name>` renders the template and writes to `~/.config/systemd/user/phantom-{account}.service`
- [ ] Template sets `ExecStart` to the resolved path of the `phantom` CLI entry point with correct arguments
- [ ] Template includes `Restart=on-failure`, `RestartSec=30`, and `WantedBy=default.target`
- [ ] After writing, command prints `"Installed: ~/.config/systemd/user/phantom-{account}.service"` and follow-up enable/start instructions
- [ ] `~/.config/systemd/user/` directory is created if it does not exist (mode 0o700)
- [ ] Unit test: rendered template contains the account name and correct `ExecStart` path

## Implementation Notes

```jinja2
[Unit]
Description=Phantom Ledger paper trade — {{ account }}
After=network.target

[Service]
ExecStart={{ phantom_bin }} run --account {{ account }} --mode paper --interval {{ interval }}
Restart=on-failure
RestartSec=30

[Install]
WantedBy=default.target
```

```python
import shutil
from jinja2 import Environment, PackageLoader

def _install_service(account: str, interval: int) -> Path:
    phantom_bin = shutil.which("phantom") or sys.executable + " -m phantom"
    env = Environment(loader=PackageLoader("phantom", "templates"))
    tmpl = env.get_template("phantom.service.jinja2")
    content = tmpl.render(account=account, phantom_bin=phantom_bin, interval=interval)
    dest = Path.home() / ".config/systemd/user" / f"phantom-{account}.service"
    dest.parent.mkdir(parents=True, exist_ok=True, mode=0o700)
    dest.write_text(content)
    return dest
```
