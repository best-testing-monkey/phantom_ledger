# E3-S13: DividendModel — CFD adjustment

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** P2
**Depends on:** [E3-S12](e03-s12.md)

## Description

Extend `DividendModel` to handle CFD dividend adjustments. CFD holders do not receive actual dividends but instead receive (longs) or pay (shorts) a dividend adjustment. For longs, the gross dividend is credited multiplied by `cfd_dividend_adjustment`. For shorts, the gross is charged multiplied by `cfd_short_dividend_charge`.

## File Locations

- `src/phantom/costs/dividend.py` — add `calculate_cfd_adjustment()`

## Acceptance Criteria

- [ ] `calculate_cfd_adjustment(gross: float, direction: str) -> float`
- [ ] Long CFD: returns `gross * cfd_dividend_adjustment` (positive — credit to position)
- [ ] Short CFD: returns `-(gross * cfd_short_dividend_charge)` (negative — debit from position)
- [ ] Unit tests: long CFD credit, short CFD charge, `cfd_dividend_adjustment = 1.0` returns full gross
