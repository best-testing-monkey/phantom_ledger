# E1-S03: Migration Runner

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Implement `run_migrations(conn)` in `src/phantom/db/database.py`. It reads numbered `.sql` files from `src/phantom/db/migrations/` in ascending order, applies each one, and records it in a `_migrations` table. Re-running on an already-migrated database is a no-op (idempotent).

## File Locations

- `src/phantom/db/database.py` — add `run_migrations()` function
- `src/phantom/db/migrations/` — directory for SQL files (created here, populated in E1-S04)

## Acceptance Criteria

- [ ] `run_migrations(conn: sqlite3.Connection) -> list[str]` applies all `.sql` files in `src/phantom/db/migrations/` in ascending numeric filename order
- [ ] Creates a `_migrations` table (`id TEXT PRIMARY KEY, applied_at TEXT`) if it does not exist
- [ ] Skips any migration whose filename is already recorded in `_migrations`
- [ ] Each migration is applied in a single transaction; on failure the transaction rolls back and an exception is raised
- [ ] Returns a list of migration filenames that were applied in this call
- [ ] Calling `run_migrations(conn)` twice on the same connection does not error and returns `[]` on the second call

## Implementation Notes

```python
from pathlib import Path

MIGRATIONS_DIR = Path(__file__).parent / "migrations"

def run_migrations(conn: sqlite3.Connection) -> list[str]:
    conn.execute(
        "CREATE TABLE IF NOT EXISTS _migrations "
        "(id TEXT PRIMARY KEY, applied_at TEXT NOT NULL)"
    )
    conn.commit()
    applied = {row[0] for row in conn.execute("SELECT id FROM _migrations")}
    files = sorted(MIGRATIONS_DIR.glob("*.sql"), key=lambda p: p.name)
    ran = []
    for f in files:
        if f.name not in applied:
            conn.executescript(f.read_text(encoding="utf-8"))
            conn.execute(
                "INSERT INTO _migrations (id, applied_at) VALUES (?, ?)",
                (f.name, to_iso(now_utc())),
            )
            conn.commit()
            ran.append(f.name)
    return ran
```
