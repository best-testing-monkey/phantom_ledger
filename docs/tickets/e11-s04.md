# E11-S04: Note List CLI

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** MVP
**Depends on:** [E11-S01](e11-s01.md)

## Description

Add `phantom note list <position-id>` CLI command that retrieves all notes for a given position and displays them in a Rich table. The table has four columns: Note ID (truncated to first 12 chars for readability), Title, Size (human-readable: bytes/KB/MB), and Created At (ISO 8601 displayed in local time). If no notes exist for the position, print `"No notes found for position <id>."` and exit 0. If the position itself does not exist (`NotFoundError`), print the error and exit 1. The command does not display file content — only the metadata stored in `trade_notes`. Rows are ordered oldest-first (matching `NoteRepo.list()` default ordering by `created_at ASC`).

## File Locations

- `src/phantom/cli.py` — `note list` command on `note_app`

## Acceptance Criteria

- [ ] Command is `phantom note list <position-id>` with positional argument
- [ ] Rich table columns: `Note ID`, `Title`, `Size`, `Created At`
- [ ] `Note ID` column displays first 12 characters of ULID
- [ ] `Size` column uses human-readable formatting: `< 1024 → "N B"`, `< 1048576 → "N.N KB"`, else `"N.N MB"`
- [ ] Empty result: prints `"No notes found for position <id>."` and exits 0
- [ ] `NotFoundError` for position exits with code 1

## Implementation Notes

```python
def _human_bytes(size: int) -> str:
    if size < 1024:
        return f"{size} B"
    elif size < 1024 ** 2:
        return f"{size / 1024:.1f} KB"
    else:
        return f"{size / 1024 ** 2:.1f} MB"

@note_app.command("list")
def note_list(position_id: str = typer.Argument(..., help="Position ULID")):
    """List all notes for a position."""
    try:
        ph = get_phantom()
        ph.positions.get(position_id)  # verify position exists
        notes = ph.notes.list(position_id)
        if not notes:
            console.print(f"No notes found for position {position_id}.")
            return
        table = Table(title=f"Notes for {position_id[:12]}")
        table.add_column("Note ID")
        table.add_column("Title")
        table.add_column("Size", justify="right")
        table.add_column("Created At")
        for note in notes:
            table.add_row(
                note.id[:12],
                note.title,
                _human_bytes(note.content_size),
                note.created_at,
            )
        console.print(table)
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
