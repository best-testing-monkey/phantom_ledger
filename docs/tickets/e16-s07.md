# E16-S07: Account Switcher on Dashboard

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

The dashboard currently hard-codes the first account returned by `ph.accounts.list()`. When multiple accounts exist, there is no way to switch between them. Add a dropdown at the top of the dashboard that lets the user pick any account; selecting a new one reloads the page with `?account=<name>` in the query string.

## File Locations

- `src/phantom/web/routes/dashboard.py` — already handles `account: str | None` query param; no changes needed here
- `src/phantom/web/templates/dashboard.html` — add the switcher widget in the `.header` section

## Current State

`dashboard.py` already reads `?account=<name>` and falls back to the first account. The template shows a static `<h1>Dashboard</h1>` with no switcher. The context already passes `accounts` (all accounts) — wait, actually it doesn't. The route only passes the selected `account_obj`, not the full list.

You will need to:
1. Pass `accounts` (full list) in the context dict in `dashboard.py`
2. Add a `<select>` widget to the template that changes the URL on change

## Acceptance Criteria

- [ ] `dashboard.py` passes `accounts: list[Account]` to the template context
- [ ] Template renders a `<select>` in the `.header` div listing all accounts by name
- [ ] The selected option matches the current account
- [ ] Changing the select navigates to `/?account=<name>` (plain JS `onchange`)
- [ ] With only one account the switcher is still rendered (no special-casing)
- [ ] With zero accounts the switcher is omitted (the `no_accounts` path already shows a message)

## Implementation Notes

In `dashboard.py`, fetch the list before the account resolution:

```python
accounts = ph.accounts.list()
# ... resolve account_obj as before ...
return templates.TemplateResponse(
    ...,
    context={
        "account": account_obj,
        "accounts": accounts,   # <-- add this
        ...
    }
)
```

In `dashboard.html`, inside the `.header` div, after the `<h1>`:

```html
{% if accounts and accounts|length > 1 %}
<form style="display:inline-block; margin-left:1rem;">
  <select name="account" onchange="this.form.submit()">
    {% for a in accounts %}
    <option value="{{ a.name }}" {% if a.id == account.id %}selected{% endif %}>
      {{ a.name }}
    </option>
    {% endfor %}
  </select>
</form>
{% endif %}
```

The form has no `action`, so it submits to `/` with `?account=<name>`.
