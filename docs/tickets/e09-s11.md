# E9-S11: Margin Check Hook in Sim Loop

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** P2
**Depends on:** [E8-S01](e08-s01.md), [E9-S02](e09-s02.md)

## Description

Integrate margin level checking into the simulation loop so that margin calls and stop-outs are automatically detected and handled on each bar. After all position updates (and after overnight/dividend hooks) but before the equity point is recorded, call `MarginEngine.check()` for each account that has at least one open CFD position. If the returned `MarginStatus.status == "margin_call"`, call `MarginEngine.handle_margin_call()` to flag the account and emit the warning alert. If `status == "stop_out"`, call `MarginEngine.handle_stop_out()` to cascade-close positions until margin recovers. After the stop-out cascade, recompute the equity point using the updated positions list. Accounts with no open CFD positions skip the margin check entirely (no overhead for stock-only accounts). The check runs on every bar so that margin deterioration is caught promptly.

## File Locations

- `src/phantom/engine/simulation_engine.py` — add `_check_margin()` call inside the bar loop of both `run_backtest()` and `run_paper()`

## Acceptance Criteria

- [ ] `MarginEngine.check()` is called once per account per bar (only for accounts with open CFD positions)
- [ ] `status == "margin_call"` triggers `handle_margin_call()` but does NOT close any positions
- [ ] `status == "stop_out"` triggers `handle_stop_out()` which closes positions until margin recovers
- [ ] After stop-out cascade, equity point is recomputed with the updated (reduced) open positions list
- [ ] Accounts with no CFD positions skip the margin check with zero overhead
- [ ] Margin check runs after overnight/dividend hooks and before equity recording on each bar

## Implementation Notes

```python
def _check_margin(
    self,
    account: Account,
    open_positions: list[Position],
    broker_profile: BrokerProfile,
    current_bar,
) -> list[Position]:
    """Check margin level and handle call/stop-out. Returns updated open positions list."""
    cfd_positions = [p for p in open_positions if p.instrument_type == "cfd"]
    if not cfd_positions:
        return open_positions  # skip — no leveraged exposure

    market_value = sum(p.quantity * current_bar["Close"] for p in open_positions)
    margin_status = self._margin_engine.check(account, broker_profile, market_value)

    if margin_status.status == "stop_out":
        logger.warning(
            "Stop-out triggered for account %s (margin_level=%.1f%%)",
            account.id, margin_status.level,
        )
        closed = self._margin_engine.handle_stop_out(
            account=account,
            open_positions=open_positions,
            broker_profile=broker_profile,
            current_bar=current_bar,
            position_manager=self._position_manager,
            account_repo=self._account_repo,
        )
        closed_ids = {p.id for p in closed}
        return [p for p in open_positions if p.id not in closed_ids]

    elif margin_status.status == "margin_call":
        self._margin_engine.handle_margin_call(
            account=account,
            margin_status=margin_status,
            account_repo=self._account_repo,
            dispatcher=self._dispatcher,
        )

    return open_positions
```
