## Description

Write the unit test suite for the P2 cost models: overnight financing, FX conversion, and dividends (both stock withholding and CFD adjustment). All are pure functions — no DB, no network.

## File Locations

- `tests/unit/test_overnight.py`
- `tests/unit/test_dividend.py`

## Acceptance Criteria

- [ ] `test_overnight.py`: at least 3 tests — long basic, short basic, triple swap Wednesday
- [ ] `test_overnight.py`: zero rate returns zero cost
- [ ] `test_dividend.py`: stock withholding — US 15%, NL 15%, unknown country 0%
- [ ] `test_dividend.py`: CFD long credit, CFD short charge
- [ ] FX tests added to `test_cost_engine.py`: FX required, FX not required
- [ ] `uv run pytest tests/unit/test_overnight.py tests/unit/test_dividend.py` passes
