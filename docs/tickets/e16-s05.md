# E16-S05: Broker Comparison View

**Epic:** [E16: Web UI](e16-web-ui.md)
**Phase:** P3
**Depends on:** [E16-S01](e16-s01.md), [E12-S09](e12-s09.md)

## Description

Implement the broker comparison page at `/brokers/compare` that shows how much an account's historical trades would have cost under each available broker profile. The route accepts `?account=<name>` as a required query parameter. It calls `ph.report.compare_brokers(account_id, profile_names)` with all loaded broker profile names and renders a table comparing total costs, commission totals, spread totals, and slippage totals per broker. The cheapest broker is highlighted in green. If the account has no closed trades, a message "No closed trades to compare" is shown.

## File Locations

- `src/phantom/web/routes/brokers.py` — `/brokers/compare` route
- `src/phantom/web/templates/broker_comparison.html` — Jinja2 template

## Acceptance Criteria

- [ ] `GET /brokers/compare?account=<name>` renders `broker_comparison.html` with per-broker cost data
- [ ] Table columns: Broker Name, Total Costs, Commission, Spread, Slippage (all as formatted currency)
- [ ] The broker with the lowest total cost is highlighted (e.g. CSS class `"best"` on that row)
- [ ] Missing `account` query parameter returns HTTP 400 with message "account parameter is required"
- [ ] Unknown account name returns HTTP 404
- [ ] Test: GET with a seeded account and two broker profiles returns 200 with both profile names in the body

## Implementation Notes

```python
from fastapi import APIRouter, Request, Query, HTTPException
from phantom.errors import NotFoundError

router = APIRouter()

@router.get("/brokers/compare")
async def broker_comparison(request: Request, account: str | None = Query(None)):
    if account is None:
        raise HTTPException(status_code=400, detail="account parameter is required")
    ph = get_phantom()
    try:
        acct = ph.accounts.get(account)
    except NotFoundError:
        raise HTTPException(status_code=404, detail="Account not found")
    profiles = ph.brokers.list()
    comparison = ph.report.compare_brokers(acct.id, [p.name for p in profiles])
    return templates.TemplateResponse("broker_comparison.html", {
        "request": request, "account": acct, "comparison": comparison,
    })
```
