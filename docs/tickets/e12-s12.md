# E12-S12: Terminal Equity Curve Chart

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** P3
**Depends on:** [E12-S01](e12-s01.md)

## Description

Add `phantom report --account <name> --chart` CLI option that renders the equity curve as an ASCII/Unicode chart directly in the terminal. Use the `plotext` library (`pip install plotext`) which renders charts using only terminal escape codes — no browser or GUI required. The chart displays equity (y-axis) over time (x-axis, date labels). Configure the chart: title `"Equity Curve — <account_name>"`, x-axis label `"Date"`, y-axis label `"Equity"`, canvas width 80 columns, theme `"dark"`. Dates on the x-axis are formatted as `YYYY-MM-DD`. If `plotext` is not installed, fall back gracefully by printing `"Install plotext for terminal charts: uv add plotext"` and exiting 0. If fewer than 2 equity points, print a notice and exit 0. The `render_equity_chart()` function in `src/phantom/reports/formatters.py` wraps all `plotext` calls.

## File Locations

- `src/phantom/reports/formatters.py` — `render_equity_chart(curve: list[EquityPoint], account_name: str) -> None`
- `src/phantom/cli.py` — `report` command updated with `--chart` flag

## Acceptance Criteria

- [ ] `--chart` flag triggers terminal chart rendering via `plotext`
- [ ] `ImportError` for `plotext` caught; graceful fallback message printed; exits 0
- [ ] Chart title: `"Equity Curve — <account_name>"`; x-label: `"Date"`; y-label: `"Equity"`
- [ ] X-axis values are date strings (`YYYY-MM-DD`) extracted from `EquityPoint.timestamp`
- [ ] Y-axis values are `EquityPoint.equity` floats
- [ ] Fewer than 2 points: prints `"Not enough data to render chart."` and exits 0

## Implementation Notes

```python
# src/phantom/reports/formatters.py
from __future__ import annotations
from typing import TYPE_CHECKING
if TYPE_CHECKING:
    from phantom.reports.metrics import EquityPoint

def render_equity_chart(curve: list[EquityPoint], account_name: str) -> None:
    try:
        import plotext as plt
    except ImportError:
        print("Install plotext for terminal charts: uv add plotext")
        return
    if len(curve) < 2:
        print("Not enough data to render chart.")
        return
    dates = [pt.timestamp.strftime("%Y-%m-%d") for pt in curve]
    equities = [pt.equity for pt in curve]
    plt.clear_figure()
    plt.theme("dark")
    plt.plot_size(80, 24)
    plt.title(f"Equity Curve — {account_name}")
    plt.xlabel("Date")
    plt.ylabel("Equity")
    plt.plot(dates, equities)
    plt.show()

# CLI fragment
if chart:
    render_equity_chart(curve, account)
```
