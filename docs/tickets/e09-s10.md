# E9-S10: Dividend Hook in Sim Loop

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** P2
**Depends on:** [E4-S05](e04-s05.md), [E3-S12](e03-s12.md), [E3-S13](e03-s13.md), [E9-S02](e09-s02.md)

## Description

Integrate dividend processing into the simulation loop by checking the dividend calendar on each bar for every open position's ticker. On each bar, after overnight costs are applied but before TP/SL evaluation, call `DataProvider.get_dividend(ticker, bar_date)` for each open position. If the returned `dividend_per_share > 0`, call `CostEngine.dividend_adjustment(position, dividend_per_share, dividend_model)` to compute the net cash adjustment. Apply the adjustment to `account.cash`. Log the event at INFO level. Create a `DividendLog` entry and persist it via `DividendLogRepo`. Dividend data is sourced from the local Parquet cache populated in E4-S05; if the ticker has no dividend data, `get_dividend()` returns `0.0` without raising. This hook runs for both stock and CFD positions (they have different adjustment formulas handled inside `CostEngine.dividend_adjustment`).

## File Locations

- `src/phantom/engine/simulation_engine.py` — add `_apply_dividends()` call inside the bar loop of both `run_backtest()` and `run_paper()`

## Acceptance Criteria

- [ ] `DataProvider.get_dividend(ticker, bar_date)` is called for every open position on every bar
- [ ] When `dividend_per_share > 0`, `account.cash` is adjusted by the net dividend amount
- [ ] A `DividendLog` record is created and persisted for each dividend event applied
- [ ] No `DividendLog` is written and no cash adjustment is made when `dividend_per_share == 0`
- [ ] Long stock and long CFD positions receive positive cash adjustments; short CFD positions are debited
- [ ] `DataError` from `get_dividend()` logs WARNING and skips the dividend for that position (no crash)

## Implementation Notes

```python
def _apply_dividends(
    self,
    account: Account,
    open_positions: list[Position],
    bar_date: date,
) -> None:
    for position in open_positions:
        try:
            dividend_per_share = self._data_provider.get_dividend(position.ticker, bar_date)
        except DataError as exc:
            logger.warning(
                "Dividend fetch failed for %s on %s: %s", position.ticker, bar_date, exc
            )
            continue
        if dividend_per_share == 0.0:
            continue
        adjustment = self._cost_engine.dividend_adjustment(
            position=position,
            dividend_per_share=dividend_per_share,
            dividend_model=self._broker_profile.dividend,
        )
        account.cash += adjustment
        log_entry = DividendLog(
            position_id=position.id,
            account_id=account.id,
            ex_date=bar_date.isoformat(),
            dividend_per_share=dividend_per_share,
            adjustment_amount=adjustment,
            created_at=to_iso(now_utc()),
        )
        self._dividend_log_repo.create(log_entry)
        logger.info(
            "Dividend adjustment %.4f applied to position %s on %s",
            adjustment, position.id, bar_date,
        )
```
