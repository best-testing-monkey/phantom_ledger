# E17-S03: AccountAPI

## Description

`AccountAPI` is the public interface for account management on the `Phantom` facade (`ph.accounts`). It delegates all persistence to `AccountRepo` but adds validation logic that belongs in the API layer: checking for duplicate account names and validating that the referenced broker profile exists. `create()` assigns a ULID, sets `created_at` to `now_utc()`, and persists the account. `get()` accepts either an account ID (ULID) or account name — it tries ID first then falls back to name lookup, raising `NotFoundError` if neither matches. `delete()` raises `NotFoundError` if the ID does not exist.

## Acceptance Criteria

- [ ] `create(name, broker_profile, account_type, initial_cash)` returns the created `Account`
- [ ] `create()` raises `ValidationError("name", "already exists")` if name is already taken
- [ ] `list()` returns all accounts as `list[Account]` (empty list if none)
- [ ] `get(id_or_name)` tries ID lookup then name lookup; raises `NotFoundError("Account", id_or_name)` on miss
- [ ] `delete(id)` raises `NotFoundError` if account does not exist
- [ ] Integration test: create two accounts with the same name raises `ValidationError`

## Implementation Notes

```python
class AccountAPI:
    def __init__(self, conn: sqlite3.Connection) -> None:
        self._repo = AccountRepo(conn)

    def create(self, name: str, broker_profile: str, account_type: str, initial_cash: float) -> Account:
        existing = self._repo.list()
        if any(a.name == name for a in existing):
            raise ValidationError("name", "already exists")
        account = Account(
            id=new_id(), name=name, broker_profile_id=broker_profile,
            account_type=account_type, cash=initial_cash, created_at=now_utc(),
        )
        return self._repo.create(account)

    def get(self, id_or_name: str) -> Account:
        try:
            return self._repo.get(id_or_name)
        except NotFoundError:
            return self._repo.get_by_name(id_or_name)  # raises NotFoundError if miss
```
