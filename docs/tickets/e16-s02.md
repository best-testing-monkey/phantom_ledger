# E16-S02: Dashboard Page

**Epic:** [E16: Web UI](e16-web-ui.md)
**Phase:** P3
**Depends on:** [E16-S01](e16-s01.md)

## Description

Implement the main dashboard page at `/` that displays an account overview for all accounts or a selected account. The page shows: account name, cash balance, total equity, and unrealized P&L in a summary card at the top. Below that, a table of all open positions with columns: symbol, side, quantity, entry price, current price, unrealized P&L, and unrealized P&L %. At the bottom, a table of the 10 most recently closed trades with columns: symbol, side, realized P&L, close reason, and close date. The route accepts an optional `?account=<name>` query parameter to filter to a specific account. If omitted, the first account is shown.

## File Locations

- `src/phantom/web/routes/dashboard.py` — `/` route
- `src/phantom/web/templates/dashboard.html` — Jinja2 template

## Acceptance Criteria

- [ ] `GET /` renders `dashboard.html` with account summary, open positions, and recent closed trades
- [ ] `?account=<name>` query parameter filters to that account; defaults to first account if omitted
- [ ] Open positions table includes: symbol, side, quantity, entry_price, current_price, unrealized_pnl, unrealized_pnl_pct
- [ ] Recent closed trades table shows last 10 trades ordered by close time descending
- [ ] If no accounts exist, renders a "No accounts found" message with a link to create one
- [ ] Test: GET `/` with a seeded account returns 200 and renders the account name in the response body

## Implementation Notes

```python
from fastapi import APIRouter, Request, Query
from phantom.web.app import templates
from phantom.api.phantom import get_phantom

router = APIRouter()

@router.get("/")
async def dashboard(request: Request, account: str | None = Query(None)):
    ph = get_phantom()
    accounts = ph.accounts.list()
    if not accounts:
        return templates.TemplateResponse("dashboard.html", {"request": request, "no_accounts": True})
    selected = next((a for a in accounts if a.name == account), accounts[0])
    positions = ph.positions.list(selected.id)
    recent_trades = ph.positions.list_closed(selected.id, limit=10)
    return templates.TemplateResponse("dashboard.html", {
        "request": request, "account": selected,
        "positions": positions, "recent_trades": recent_trades,
    })
```
