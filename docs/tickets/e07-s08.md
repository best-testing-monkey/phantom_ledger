# E7-S08: Position Modify CLI

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP
**Depends on:** [E7-S01](e07-s01.md), [E7-S02](e07-s02.md)

## Description

Add the `phantom position modify <id>` CLI command that lets a user update the take-profit and/or stop-loss on an open position without closing it. The command accepts `--tp` and `--sl` as optional floating-point options; at least one must be supplied. Before calling the API it validates the position exists and is currently open, then delegates to `ph.positions.modify()`. On success it prints a Rich confirmation panel showing the updated values. On any `PhantomError` it prints a red error message and exits with code 1. The CLI must never contain business logic — all validation (e.g. that TP is above entry for longs) lives in the API layer.

## File Locations

- `src/phantom/cli.py` — add `position modify` sub-command to the `position_app` Typer group

## Acceptance Criteria

- [ ] `phantom position modify <id> --tp 210.0` updates only take-profit; stop-loss is unchanged
- [ ] `phantom position modify <id> --sl 175.0` updates only stop-loss; take-profit is unchanged
- [ ] `phantom position modify <id> --tp 210.0 --sl 175.0` updates both in a single call
- [ ] Running without `--tp` or `--sl` prints a validation error and exits code 1 without touching the DB
- [ ] `NotFoundError` (non-existent ID) prints `[red]Error:[/red]` and exits code 1
- [ ] Confirmation output uses a Rich panel and shows the position ID plus new TP/SL values

## Implementation Notes

```python
@position_app.command("modify")
def position_modify(
    position_id: str = typer.Argument(..., help="Position ID to update"),
    tp: float | None = typer.Option(None, "--tp", help="New take-profit price"),
    sl: float | None = typer.Option(None, "--sl", help="New stop-loss price"),
):
    """Update take-profit and/or stop-loss on an open position."""
    if tp is None and sl is None:
        console.print("[red]Error:[/red] Provide at least --tp or --sl.")
        raise typer.Exit(code=1)
    try:
        ph = get_phantom()
        position = ph.positions.modify(position_id, take_profit=tp, stop_loss=sl)
        console.print(
            Panel(f"Position [bold]{position.id}[/bold] updated.\n"
                  f"TP: {position.take_profit}  SL: {position.stop_loss}",
                  title="Position Modified")
        )
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
