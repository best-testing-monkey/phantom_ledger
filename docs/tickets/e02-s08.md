# E2-S08: CLI — broker validate

**Epic:** [E2: Broker Profile System](e02-broker-profiles.md)
**Phase:** P2

## Description

Add `phantom broker validate <file>` CLI command. It validates a broker JSON file against the `BrokerProfile` schema and reports any errors — without persisting anything to the database.

## File Locations

- `src/phantom/cli.py` — add `broker_validate` command

## Acceptance Criteria

- [ ] `phantom broker validate src/phantom/profiles/degiro.json` prints success message and exits 0
- [ ] `phantom broker validate /path/to/bad.json` prints the `ProfileError` message and exits 1
- [ ] Command calls `ph.brokers.validate(path)` (no persistence side-effect)
- [ ] On success, prints a summary of the validated profile (name, instruments, commission type)
