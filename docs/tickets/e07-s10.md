# E7-S10: Trailing Stop Tracking

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** P2
**Depends on:** [E7-S01](e07-s01.md), [E7-S04](e07-s04.md)

## Description

Extend `PositionManager.update()` to track the trailing stop peak and trigger a close when the retracement threshold is breached. On each bar, update `position.peak_price`: for a long position the peak is the highest `bar.High` seen since entry; for a short position it is the lowest `bar.Low` since entry. After updating the peak, compute the retracement distance from the peak to the current bar's close. If that distance exceeds `position.trailing_stop_distance`, immediately close the position at the current bar's close price with `close_reason = "trailing_stop"`. The `trailing_stop_distance` is stored on the position model (set when the order was placed). If `trailing_stop_distance` is `None` the logic is skipped entirely for that position. Peak price must be persisted to the DB on every update so it survives a restart.

## File Locations

- `src/phantom/engine/position_manager.py` — extend `update()` with trailing stop logic
- `src/phantom/models/position.py` — ensure `peak_price: float | None` and `trailing_stop_distance: float | None` fields exist

## Acceptance Criteria

- [ ] `peak_price` is updated every bar: `max(peak_price, bar.High)` for long, `min(peak_price, bar.Low)` for short
- [ ] Trailing stop triggers when `abs(bar.Close - peak_price) >= trailing_stop_distance` for long, `abs(peak_price - bar.Close) >= trailing_stop_distance` for short
- [ ] Close is recorded with `close_reason = "trailing_stop"` and `exit_price = bar.Close`
- [ ] Positions with `trailing_stop_distance = None` are unaffected by this logic
- [ ] `peak_price` is persisted to the DB after each update (not only on close)
- [ ] Unit test covers: long peak advancement, short peak advancement, trigger at exact threshold, no trigger below threshold

## Implementation Notes

```python
def _update_trailing_stop(self, position: Position, bar: Bar) -> bool:
    """Returns True if position should be closed. Updates peak_price in place."""
    if position.trailing_stop_distance is None:
        return False
    if position.direction == "long":
        new_peak = max(position.peak_price or position.entry_price, bar.high)
        position.peak_price = new_peak
        return (new_peak - bar.close) >= position.trailing_stop_distance
    else:  # short
        new_peak = min(position.peak_price or position.entry_price, bar.low)
        position.peak_price = new_peak
        return (bar.close - new_peak) >= position.trailing_stop_distance
```
