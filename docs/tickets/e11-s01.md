# E11-S01: NoteManager and trade_notes Repository

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** MVP

## Description

Implement `NoteManager` — the entry point for all note CRUD operations — and the corresponding `NoteRepo` database repository. Notes are Markdown files stored on the filesystem at `{data_dir}/notes/{account_id}/{position_id}/{note_id}.md`. The `trade_notes` table holds lightweight metadata: id (ULID), position_id, account_id, title, file_path (relative to `data_dir`), content_size (integer bytes), created_at, and updated_at. `NoteManager` is instantiated with `data_dir: Path`, `conn: sqlite3.Connection`. On `create()`, it generates a new ULID, creates the directory tree (`parents=True, exist_ok=True`), writes the content to the file, then inserts the metadata row via `NoteRepo.create()`. The `Note` Pydantic model must mirror the table schema. The migration SQL for `trade_notes` must be added as a numbered migration file.

## File Locations

## Acceptance Criteria

- [ ] `Note` model has fields: `id: str`, `position_id: str`, `account_id: str`, `title: str`, `file_path: str`, `content_size: int`, `created_at: str`, `updated_at: str`
- [ ] `trade_notes` table created by migration with matching columns and `FOREIGN KEY (position_id) REFERENCES positions(id)`
- [ ] `NoteManager.create(position_id, account_id, title, content)` writes file then inserts DB row; returns `Note`
- [ ] `NoteRepo.get(note_id)` raises `NotFoundError("Note", note_id)` if not found
- [ ] `NoteRepo.list(position_id)` returns all notes for a position ordered by `created_at ASC`; returns `[]` if none
- [ ] File path stored as relative string; absolute path reconstructed by prepending `data_dir`

## Implementation Notes

```python
# src/phantom/models/note.py
from pydantic import BaseModel, Field
from phantom.utils.ids import new_id

class Note(BaseModel):
    id: str = Field(default_factory=new_id)
    position_id: str
    account_id: str
    title: str
    file_path: str
    content_size: int = 0
    created_at: str
    updated_at: str

# src/phantom/notes/manager.py
class NoteManager:
    def __init__(self, data_dir: Path, conn: sqlite3.Connection) -> None:
        self._data_dir = data_dir
        self._repo = NoteRepo(conn)

    def create(self, position_id: str, account_id: str, title: str, content: str) -> Note:
        note_id = new_id()
        rel_path = f"notes/{account_id}/{position_id}/{note_id}.md"
        abs_path = self._data_dir / rel_path
        abs_path.parent.mkdir(parents=True, exist_ok=True)
        abs_path.write_text(content, encoding="utf-8")
        now = to_iso(now_utc())
        note = Note(
            id=note_id, position_id=position_id, account_id=account_id,
            title=title, file_path=rel_path,
            content_size=len(content.encode("utf-8")),
            created_at=now, updated_at=now,
        )
        return self._repo.create(note)
```
