# E9-S07: Run CLI Command

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** P2
**Depends on:** [E9-S06](e09-s06.md)

## Description

Add the `phantom run` top-level CLI command that starts the paper trading loop for a named account. The command validates that the account exists and that a broker profile is loaded before starting the simulation. It then calls `ph.runner.paper(account_name, mode="paper", interval=interval)` which internally spins up `SimulationEngine.run_paper()` in a background thread or blocking call. The command blocks until SIGINT (Ctrl+C) is received, at which point it sets the stop event and waits for the current tick to finish before exiting with code 0. It prints a startup banner (Rich panel) showing account name, broker, and tick interval. No business logic lives in the CLI — all validation and startup logic is in the public API or engine layer.

## File Locations

- `src/phantom/cli.py` — add `run` command to the root Typer app (not inside a sub-group)

## Acceptance Criteria

- [ ] `phantom run --account myaccount --mode paper --interval 300` starts the paper trading loop
- [ ] Missing `--account` prints usage error and exits 1
- [ ] `NotFoundError` for a non-existent account name prints `[red]Error:[/red]` and exits 1
- [ ] Startup banner is printed with account name, broker, and interval before the loop starts
- [ ] SIGINT (Ctrl+C) is handled gracefully: loop stops, `"Shutting down..."` is printed, exit code 0
- [ ] `--interval` defaults to `300` (5 minutes) if not supplied

## Implementation Notes

```python
@app.command("run")
def run_simulation(
    account: str = typer.Option(..., "--account", help="Account name to trade"),
    mode: str = typer.Option("paper", "--mode", help="Simulation mode: paper"),
    interval: int = typer.Option(300, "--interval", help="Tick interval in seconds"),
):
    """Start the paper trading loop for an account."""
    try:
        ph = get_phantom()
        acct = ph.accounts.get_by_name(account)
        console.print(Panel(
            f"[bold]Account:[/bold] {acct.name}\n"
            f"[bold]Broker:[/bold] {acct.broker}\n"
            f"[bold]Interval:[/bold] {interval}s",
            title="Paper Trading Started",
        ))
        ph.runner.paper(account_id=acct.id, tickers=ph.positions.tracked_tickers(acct.id),
                        interval=interval)
    except KeyboardInterrupt:
        console.print("\n[yellow]Shutting down...[/yellow]")
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
