# E11-S03: Note Creation via $EDITOR

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** MVP
**Depends on:** [E11-S01](e11-s01.md)

## Description

When `phantom note add <pos-id> --title <title>` is invoked without `--file`, open the user's `$EDITOR` (falling back to `vi` if unset) with a temporary `.md` file. The temp file starts with a brief comment header (`# <title>\n\n`) so the user has context. After the editor exits, read the temp file content. If the content is empty or identical to the initial header (user saved without typing anything), print `"Aborted: note was empty."` and exit 0 without creating a note. Otherwise pass the content to `NoteManager.create()`. Use Python's `tempfile.NamedTemporaryFile(suffix=".md", delete=False)` and clean up the temp file in a `finally` block. The editor is launched via `subprocess.run([editor, tmp_path])` where `editor = os.environ.get("EDITOR", "vi")`.

## File Locations

- `src/phantom/cli.py` — `note add` command, editor-launch branch
- `src/phantom/notes/manager.py` — `create()` called with captured content

## Acceptance Criteria

- [ ] `$EDITOR` env var used; falls back to `vi` if not set
- [ ] Temp file pre-populated with `f"# {title}\n\n"` before editor opens
- [ ] If content after editor exit equals the initial header or is blank: print `"Aborted: note was empty."` and exit 0
- [ ] Non-empty content passed to `NoteManager.create()`; success panel printed
- [ ] Temp file deleted in `finally` block regardless of success or error
- [ ] Editor launched via `subprocess.run` (blocking until editor closes)

## Implementation Notes

```python
import os
import subprocess
import tempfile

EDITOR_HEADER = "# {title}\n\n"

def _open_editor(title: str) -> str | None:
    """Open $EDITOR, return content or None if aborted."""
    editor = os.environ.get("EDITOR", "vi")
    header = EDITOR_HEADER.format(title=title)
    tmp = tempfile.NamedTemporaryFile(suffix=".md", mode="w", delete=False, encoding="utf-8")
    try:
        tmp.write(header)
        tmp.flush()
        tmp.close()
        subprocess.run([editor, tmp.name], check=False)
        content = Path(tmp.name).read_text(encoding="utf-8")
        if not content.strip() or content.strip() == header.strip():
            return None
        return content
    finally:
        Path(tmp.name).unlink(missing_ok=True)
```
