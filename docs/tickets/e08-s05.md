# E8-S05: Margin Display in CLI

**Epic:** [E8: Margin Engine](e08-margin-engine.md)
**Phase:** P2
**Depends on:** [E8-S01](e08-s01.md), [E7-S09](e07-s09.md)

## Description

Extend the `phantom account show` command to display margin metrics for CFD accounts and extend `phantom position list` to include a `Margin Req.` column for CFD accounts. For `account show`, add a margin section to the Rich panel that shows: current margin level (as a percentage, colour-coded — green above margin_call_level, yellow between call and stop_out, red at or below stop_out), used margin, and free margin (`equity - used_margin`). For `phantom position list`, when the account contains at least one CFD position, add a `Margin Req.` column showing `position.margin_required` formatted to 2 decimal places. Stock-only accounts should not display margin columns or sections. Both commands call only public API methods — no direct DB queries in CLI code. The `MarginEngine.check()` is invoked inside the API layer, not the CLI.

## File Locations

- `src/phantom/cli.py` — extend `account show` and `position list` commands

## Acceptance Criteria

- [ ] `phantom account show` for a CFD account displays: Margin Level (%), Used Margin, Free Margin in a dedicated panel section
- [ ] Margin level colour: green when above `margin_call_level`, yellow between thresholds, red at or below `stop_out_level`
- [ ] `phantom position list` adds a `Margin Req.` column when any position has `instrument_type="cfd"`
- [ ] Stock-only accounts show no margin section in `account show` and no margin column in `position list`
- [ ] Margin level is displayed as `"∞"` (infinity symbol) when `used_margin == 0`
- [ ] All output uses `console.print()` with Rich renderables; no `print()` calls

## Implementation Notes

```python
def _margin_level_colour(level: float, call_level: float, stop_out_level: float) -> str:
    if level == float("inf"):
        return "green"
    if level <= stop_out_level:
        return "red"
    if level <= call_level:
        return "yellow"
    return "green"

# In account_show():
margin_status = ph.accounts.margin_status(account.id)  # API returns MarginStatus
if margin_status is not None:
    level_display = "∞" if margin_status.level == float("inf") else f"{margin_status.level:.1f}%"

    )
    console.print(Panel(

        f"[bold]Used Margin:[/bold] {account.used_margin:.2f}\n"
        f"[bold]Free Margin:[/bold] {account.equity - account.used_margin:.2f}",
        title="Margin",
    ))
```
