# E16-S19: Order Confirmation Page

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

After placing an order the user is silently redirected to the dashboard with no feedback. Add a confirmation page that shows what was placed (or filled) before returning to the dashboard.

## File Locations

- `src/phantom/web/routes/orders.py` — change redirect to render confirmation template
- `src/phantom/web/templates/order_confirmation.html` *(new)*

## Current State

`POST /orders/new` on success does `return RedirectResponse(url="/", status_code=303)`. The placed order is stored in `placed_order` (local variable) but discarded.

`Order` model fields relevant here: `id`, `ticker`, `direction`, `order_type`, `quantity`, `limit_price`, `status` (`"pending"` for limit orders, `"filled"` for market orders), `fill_price`, `filled_at`.

## Acceptance Criteria

- [ ] On success, render `order_confirmation.html` (HTTP 200, not a redirect) showing order details
- [ ] Page shows: Symbol, Direction, Order Type, Quantity, Status, Fill Price (if filled), Limit Price (if limit order)
- [ ] If status is `"filled"`, show a green banner: "Order filled at <price>"
- [ ] If status is `"pending"`, show a blue banner: "Order placed — waiting to fill"
- [ ] Page has two buttons: "Back to Dashboard" (→ `/`) and "Place Another Order" (→ `/orders/new`)
- [ ] The account name is shown in the page header
- [ ] Template extends `base.html`

## Implementation Notes

**`orders.py`** — replace the redirect on success:

```python
# existing:
# return RedirectResponse(url="/", status_code=303)

# replace with:
accounts = ph.accounts.list()
account_obj = next((a for a in accounts if a.id == account_id), None)
return templates.TemplateResponse(
    request=request,
    name="order_confirmation.html",
    context={
        "order": placed_order,
        "account": account_obj,
    },
)
```

**`order_confirmation.html`**:

```html
{% extends "base.html" %}
{% block title %}Order Confirmation — Phantom Ledger{% endblock %}
{% block content %}
<div class="header"><h1>Order Confirmation</h1></div>

{% if order.status == "filled" %}
<div class="success">Order filled at {{ "%.4f"|format(order.fill_price) }}</div>
{% else %}
<div style="background:#e8f4fd;border:1px solid #3498db;color:#2980b9;padding:1rem;border-radius:4px;margin-bottom:1rem;">
  Order placed — waiting to fill
</div>
{% endif %}

<div class="card">
  <table>
    <tr><th>Symbol</th><td>{{ order.ticker }}</td></tr>
    <tr><th>Direction</th><td>{{ order.direction }}</td></tr>
    <tr><th>Type</th><td>{{ order.order_type }}</td></tr>
    <tr><th>Quantity</th><td>{{ order.quantity }}</td></tr>
    <tr><th>Status</th><td>{{ order.status }}</td></tr>

  </table>

<a href="/" class="button">← Dashboard</a>
<a href="/orders/new" class="button secondary" style="margin-left:1rem;">Place Another</a>

```
