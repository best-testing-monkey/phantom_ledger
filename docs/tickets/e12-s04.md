# E12-S04: Report CLI — Equity and Cost Panels

**Epic:** [E12: Reporting & Analytics](e12-reporting.md)
**Phase:** MVP
**Depends on:** [E12-S01](e12-s01.md), [E12-S02](e12-s02.md), [E12-S03](e12-s03.md)

## Description

Add `phantom report --account <name>` CLI command that fetches all positions for the account, builds the equity curve from `close_datetime` / `realized_pnl` data, and displays two Rich `Panel`s side by side or stacked. Panel 1 "Performance" is a Rich `Table` with rows: Total Return, CAGR, Max Drawdown, Max Drawdown Duration, Win Rate, Profit Factor, Expectancy. Panel 2 "Cost Breakdown" is a Rich `Table` with rows: Commission, Spread, Slippage, Overnight, FX, Dividends, Total. The equity curve is constructed by accumulating `realized_pnl` chronologically across closed positions — `EquityPoint(timestamp=pos.close_datetime, equity=running_equity)`. Starting equity is the account's `initial_capital`. If fewer than 2 closed positions exist, skip equity metrics and print a notice. If no closed positions, skip trade metrics and print a separate notice.

## File Locations

- `src/phantom/cli.py` — `report` command (top-level, not a sub-app)

## Acceptance Criteria

- [ ] Command `phantom report --account <name>` requires `--account` option
- [ ] Equity curve constructed from closed positions sorted by `close_datetime` ascending
- [ ] Panel 1 shows all `EquityMetrics` fields plus `win_rate_pct`, `profit_factor`, `expectancy` from `TradeMetrics`
- [ ] Panel 2 shows all `CostSummary` fields with human-readable labels (not field names)
- [ ] Graceful degradation: `< 2 closed positions` prints notice and skips equity metrics; `0 closed` skips trade metrics
- [ ] `NotFoundError` for account exits with code 1

## Implementation Notes

```python
@app.command("report")
def report(account: str = typer.Option(..., "--account", help="Account name")):
    """Display performance and cost report for an account."""
    try:
        ph = get_phantom()
        acc = ph.accounts.get_by_name(account)
        positions = ph.positions.list(account_name=account)
        closed = [p for p in positions if p.status == "closed"]

        # Build equity curve
        equity = acc.initial_capital
        curve: list[EquityPoint] = []
        for pos in sorted(closed, key=lambda p: p.close_datetime):
            equity += pos.realized_pnl or 0.0
            curve.append(EquityPoint(timestamp=pos.close_datetime, equity=equity))

        # Compute and render metrics
        if len(curve) >= 2:
            em = calculate_metrics(curve)
        else:
            em = None
            console.print("[yellow]Notice:[/yellow] Fewer than 2 closed positions — equity metrics skipped.")

        if closed:
            tm = calculate_trade_metrics(positions)
        else:
            tm = None
            console.print("[yellow]Notice:[/yellow] No closed positions — trade metrics skipped.")

        cs = aggregate_costs(positions)
        # render two Rich Panels with Tables
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
