# E11-S08: Note Search

**Epic:** [E11: Trade Notes](e11-trade-notes.md)
**Phase:** P2
**Depends on:** [E11-S01](e11-s01.md)

## Description

Add `phantom note search <account-name> <keyword>` CLI command that full-text searches across all note files belonging to an account. The implementation uses Python's `Path.rglob("*.md")` to walk `{data_dir}/notes/{account_id}/` recursively, opens each file, and searches for the keyword (case-insensitive substring match, line by line). For each matching line, print the relative file path and the matching line with the keyword highlighted using Rich markup `[bold yellow]`. If no files match, print `"No notes found matching '<keyword>'."`. The account must be resolved to an `account_id` via `ph.accounts.get_by_name(account_name)`. The search is pure filesystem (no SQLite FTS) — this is intentional since note files may be large Markdown documents. Search is always case-insensitive.

## File Locations

- `src/phantom/notes/manager.py` — `NoteManager.search(account_id, keyword) -> list[SearchResult]`
- `src/phantom/cli.py` — `note search` command on `note_app`

## Acceptance Criteria

- [ ] Walks `{data_dir}/notes/{account_id}/` with `Path.rglob("*.md")`
- [ ] Line-by-line case-insensitive match using `keyword.lower() in line.lower()`
- [ ] Returns list of `SearchResult(file_path: str, line_number: int, line: str)` dataclass instances
- [ ] CLI prints each match as `"<relative_path>:<line_number>: <line>"` with keyword highlighted in bold yellow
- [ ] No matches: prints `"No notes found matching '<keyword>'."` and exits 0
- [ ] `NotFoundError` for account name propagates and exits with code 1

## Implementation Notes

```python
from dataclasses import dataclass

@dataclass
class SearchResult:
    file_path: str       # relative to data_dir
    line_number: int
    line: str

class NoteManager:
    def search(self, account_id: str, keyword: str) -> list[SearchResult]:
        root = self._data_dir / "notes" / account_id
        if not root.exists():
            return []
        results: list[SearchResult] = []
        kw_lower = keyword.lower()
        for md_file in sorted(root.rglob("*.md")):
            rel = str(md_file.relative_to(self._data_dir))
            for lineno, line in enumerate(md_file.read_text(encoding="utf-8").splitlines(), 1):
                if kw_lower in line.lower():
                    results.append(SearchResult(file_path=rel, line_number=lineno, line=line))
        return results
```

```python
@note_app.command("search")
def note_search(
    account_name: str = typer.Argument(...),
    keyword: str = typer.Argument(...),
):
    try:
        ph = get_phantom()
        account = ph.accounts.get_by_name(account_name)
        results = ph.notes.search(account.id, keyword)
        if not results:
            console.print(f"No notes found matching '{keyword}'.")
            return
        for r in results:
            highlighted = r.line.replace(keyword, f"[bold yellow]{keyword}[/bold yellow]")
            console.print(f"{r.file_path}:{r.line_number}: {highlighted}")
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
