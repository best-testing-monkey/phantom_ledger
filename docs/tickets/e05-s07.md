# E5-S07: Validation — CFD/Short Instrument Check

**Epic:** [E5: Account System](e05-account-system.md)
**Phase:** P2
**Depends on:** [E5-S01](e05-s01.md), [E2-S01](e02-s01.md)

## Description

When placing an order for a CFD or a short position, validate that the account's broker profile supports `"cfd"` in its `supported_instruments` list. If not, reject the order with a `ValidationError`.

## File Locations

- `src/phantom/api/orders.py` — add validation in `OrderAPI.place()`

## Acceptance Criteria

- [ ] `OrderAPI.place()` raises `ValidationError("Broker DEGIRO does not support instrument type: cfd")` when placing a CFD order on a stock-only broker profile
- [ ] Short positions on stock-only brokers also raise `ValidationError` (because shorting stocks requires margin/CFD functionality)
- [ ] Validation fires before any DB write
- [ ] Long stock orders on stock-only brokers pass validation
