# E15-S05: Strategy Backtest CLI

**Epic:** [E15: Strategy Automation Hooks](e15-strategy-automation.md)
**Phase:** P3
**Depends on:** [E15-S02](e15-s02.md), [E15-S03](e15-s03.md), [E9-S02](e09-s02.md)

## Description

Add a `phantom run --mode backtest` variant to the CLI that loads a strategy file, sets it on the engine, fetches historical price data for the requested date range, and runs the full backtest loop. After completion, prints a Rich table of final metrics (total return, Sharpe ratio, max drawdown, number of trades, total costs). The command validates that `--strategy`, `--start`, and `--end` are all provided when `--mode backtest` is used; missing args print a helpful error and exit 1. Dates are accepted as `YYYY-MM-DD` strings and parsed with `parse_datetime()`.

## File Locations

- `src/phantom/cli.py` — extended `run` command handling `--mode backtest`

## Acceptance Criteria

- [ ] `phantom run --account <name> --mode backtest --strategy path.py --start 2024-01-01 --end 2025-01-01` runs to completion
- [ ] Missing `--strategy`, `--start`, or `--end` with `--mode backtest` prints an error and exits 1
- [ ] Strategy is loaded via `load_strategy(strategy_path)` and assigned to `engine.strategy`
- [ ] Historical data is fetched for the account's configured symbols over the date range via `ph.data.fetch_prices()`
- [ ] After completion, a Rich table shows: Total Return %, Sharpe Ratio, Max Drawdown %, Trades, Total Costs
- [ ] Integration test: running backtest with a no-op strategy (returns `[]`) completes without error

## Implementation Notes

```python
elif mode == "backtest":
    if not strategy or not start or not end:
        console.print("[red]Error:[/red] --strategy, --start, --end are required for backtest mode")
        raise typer.Exit(code=1)
    strat = load_strategy(strategy)
    result = ph.runner.backtest(account, start=start, end=end, strategy=strat)
    table = Table(title="Backtest Results")
    table.add_column("Metric")
    table.add_column("Value", justify="right")
    table.add_row("Total Return", f"{result.total_return_pct:.2f}%")
    table.add_row("Sharpe Ratio", f"{result.sharpe:.3f}")
    table.add_row("Max Drawdown", f"{result.max_drawdown_pct:.2f}%")
    table.add_row("Trades", str(result.trade_count))
    table.add_row("Total Costs", f"{result.total_costs:.2f}")
    console.print(table)
```
