# E3-S02: SpreadModel — fixed and dynamic types

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** MVP
**Depends on:** [E2-S01](e02-s01.md)

## Description

Implement `SpreadModel.calculate()` for `"fixed"` and `"dynamic"` model types. The spread cost represents the bid-ask spread paid on entry (half-spread on each side). The dynamic model scales the base spread by volatility (ATR-relative) and time-of-day.

## File Locations

- `src/phantom/costs/spread.py` — `SpreadModel.calculate()`

## Acceptance Criteria

- [ ] `SpreadModel.calculate(price: float, quantity: float, atr: float | None = None, hour_utc: int | None = None) -> float`
- [ ] `"fixed"`: returns `fixed_spread_pct * price * quantity`
- [ ] `"dynamic"`: returns `base_spread_pct * time_multiplier * (1 + volatility_multiplier * atr / price) * price * quantity` where `time_multiplier` is looked up from `time_of_day_curve` by the nearest lower hour key
- [ ] Dynamic with `atr=None`: uses base spread only (volatility component = 0)
- [ ] Dynamic with `hour_utc=None`: uses time multiplier of 1.0
- [ ] `time_of_day_curve` keys are string hours (e.g. `"9"`, `"14"`); interpolate or use floor lookup
- [ ] Unit tests: fixed basic, dynamic basic with ATR, dynamic with no ATR, dynamic at different hours
