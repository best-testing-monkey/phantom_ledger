# E5-S05: Aggregate Account Computation

**Epic:** [E5: Account System](e05-account-system.md)
**Phase:** P2
**Depends on:** [E5-S01](e05-s01.md)

## Description

Implement aggregate account logic. An aggregate account has no positions of its own — its equity is the sum of its child accounts' equity curves. Reporting metrics are computed over the combined equity series.

## File Locations

- `src/phantom/api/accounts.py` — `AccountAPI.get_aggregate_equity()`
- `src/phantom/reports/equity_curve.py` — `combine_equity_curves()`

## Acceptance Criteria

- [ ] `combine_equity_curves(curves: list[pd.Series]) -> pd.Series` aligns curves on a common DatetimeIndex (outer join, forward-fill NaN) and sums them
- [ ] `AccountAPI.get_aggregate_equity(account_name) -> pd.Series` loads all child account equity curves from the DB and combines them
- [ ] Combined equity curve is used by `ReportAPI.account_metrics()` for aggregate accounts
- [ ] Raises `ValidationError` if called on a non-aggregate account
