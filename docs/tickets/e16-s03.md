# E16-S03: Position Detail Page

**Epic:** [E16: Web UI](e16-web-ui.md)
**Phase:** P3
**Depends on:** [E16-S01](e16-s01.md)

## Description

Implement the position detail page at `/positions/{id}` that shows the full lifecycle of a single position. The page renders entry and exit prices, entry and exit timestamps, holding duration (formatted as human-readable e.g. "3d 4h"), the full cost breakdown table (commission, spread, slippage, overnight, FX, dividend costs as separate rows), unrealized or realized P&L depending on whether the position is open or closed, and all trade notes attached to the position. Notes are shown with title, creation timestamp, and content (truncated at 500 chars with a "Read more" link). If the position ID does not exist, return HTTP 404.

## File Locations

- `src/phantom/web/routes/positions.py` — `/positions/{id}` route
- `src/phantom/web/templates/position_detail.html` — Jinja2 template

## Acceptance Criteria

- [ ] `GET /positions/{id}` renders `position_detail.html` with full position data
- [ ] Cost breakdown table shows each cost component as a separate row with label and amount
- [ ] Holding duration is calculated as `close_time - open_time` (or `now - open_time` for open positions) and formatted as `Xd Yh Zm`
- [ ] All notes for the position are rendered in reverse chronological order
- [ ] `NotFoundError` from `ph.positions.get(id)` is converted to HTTP 404 response
- [ ] Test: GET `/positions/{id}` for a known position returns 200 and includes the symbol in the body

## Implementation Notes

```python
from fastapi import APIRouter, Request, HTTPException
from phantom.errors import NotFoundError

router = APIRouter()

@router.get("/positions/{position_id}")
async def position_detail(request: Request, position_id: str):
    ph = get_phantom()
    try:
        position = ph.positions.get(position_id)
    except NotFoundError:
        raise HTTPException(status_code=404, detail="Position not found")
    notes = ph.notes.list(position_id)
    return templates.TemplateResponse("position_detail.html", {
        "request": request,
        "position": position,
        "notes": notes,
    })
```
