# E7-S15: Margin Tracking Per Position

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** P2
**Depends on:** [E8-S01](e08-s01.md), [E7-S01](e07-s01.md), [E7-S02](e07-s02.md)

## Description

Implement per-position margin requirement computation and account-level `used_margin` tracking. When a position is opened, compute `margin_required = notional_value / leverage` where `notional_value = quantity * entry_price` and `leverage` comes from `MarginModel.default_margin_pct` (treated as `1 / leverage_ratio` — a margin percentage of 0.05 means 20x leverage, so `margin_required = notional * 0.05`). Store `margin_required` on the position. Add `margin_required` to `account.used_margin` on open and subtract it on close. Only CFD positions consume margin; stock positions set `margin_required = 0.0` and do not affect `used_margin`. The `MarginModel` is retrieved from the broker profile associated with the account. After computing `margin_required`, check that `account.free_margin >= margin_required` (where `free_margin = equity - used_margin`); raise `MarginError` if insufficient. Persist both position and account atomically.

## File Locations

- `src/phantom/engine/position_manager.py` — call `_compute_margin()` in `open()` and `_release_margin()` in `close()`
- `src/phantom/costs/margin.py` — `compute_margin_required(quantity, price, margin_pct) -> float` pure function
- `src/phantom/models/position.py` — ensure `margin_required: float = 0.0` field exists
- `src/phantom/models/account.py` — ensure `used_margin: float = 0.0` field exists

## Acceptance Criteria

- [ ] Opening a CFD position sets `position.margin_required = notional * margin_pct` and increases `account.used_margin` by the same amount
- [ ] Closing a CFD position decreases `account.used_margin` by `position.margin_required`
- [ ] Stock positions have `margin_required = 0.0` and do not modify `account.used_margin`
- [ ] `MarginError` is raised if `account.free_margin < margin_required` at open time
- [ ] `account.used_margin` and `position.margin_required` are persisted atomically with the position record
- [ ] `compute_margin_required()` in `costs/margin.py` is a pure function with unit tests covering standard and zero margin cases

## Implementation Notes

```python
# src/phantom/costs/margin.py
def compute_margin_required(quantity: float, price: float, margin_pct: float) -> float:
    """
    Compute the margin required to open a CFD position.

    Args:
        quantity: Number of units.
        price: Entry price per unit.
        margin_pct: Margin percentage from broker profile (e.g. 0.05 = 5% = 20x leverage).

    Returns:
        Required margin amount in account base currency.
    """
    return quantity * price * margin_pct

# In PositionManager.open():
if position.instrument_type == "cfd":
    margin_required = compute_margin_required(
        quantity=position.quantity,
        price=position.entry_price,
        margin_pct=margin_model.default_margin_pct,
    )
    free_margin = account.equity - account.used_margin
    if free_margin < margin_required:
        raise MarginError(
            f"Insufficient free margin: need {margin_required:.2f}, have {free_margin:.2f}"
        )
    position.margin_required = margin_required
    account.used_margin += margin_required
```
