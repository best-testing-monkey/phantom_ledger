# E3-S04: CostEngine

**Epic:** [E3: Cost Engine](e03-cost-engine.md)
**Phase:** MVP
**Depends on:** [E3-S01](e03-s01.md), [E3-S02](e03-s02.md), [E3-S03](e03-s03.md)

## Description

Implement `CostEngine` as the single entry point that composes all cost sub-models from a `BrokerProfile`. It exposes `entry_costs()` and `exit_costs()` that return a frozen `CostBreakdown` dataclass. At MVP, only commission, spread, slippage, and FX gating are implemented — overnight and dividends come in P2.

## File Locations

- `src/phantom/costs/engine.py` — `CostEngine` class
- `src/phantom/costs/__init__.py` — export `CostEngine`

## Acceptance Criteria

- [ ] `CostEngine(profile: BrokerProfile)` in `src/phantom/costs/engine.py`
- [ ] `entry_costs(price, quantity, ticker, instrument_type, atr, hour_utc, fx_required) -> CostBreakdown`
- [ ] `exit_costs(price, quantity, ticker, instrument_type, atr, hour_utc, fx_required) -> CostBreakdown`
- [ ] `CostBreakdown` is a frozen dataclass with float fields: `commission`, `spread`, `slippage`, `fx`, `total`
- [ ] `total == commission + spread + slippage + fx` (within float tolerance)
- [ ] `fx == 0.0` when `fx_required=False`
- [ ] `fx == price * quantity * profile.fx_conversion_pct` when `fx_required=True`
- [ ] `from phantom.costs import CostEngine` works
