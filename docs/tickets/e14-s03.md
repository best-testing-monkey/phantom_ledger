# E14-S03: Telegram Webhook Sender

**Epic:** [E14: Alerts & Notifications](e14-alerts.md)
**Phase:** P3
**Depends on:** [E14-S01](e14-s01.md)

## Description

Implement `TelegramSender`, an `AlertSender` that delivers alert messages to a Telegram chat via the Bot API. The sender is configured with `bot_token` and `chat_id`. On `send(event)`, it POSTs to `https://api.telegram.org/bot{token}/sendMessage` with a JSON body containing `chat_id` and the formatted `text`. The message text should include the event type, account ID, position ID (if set), and the human-readable message. Use `httpx` (sync client) for the HTTP call. If the API returns a non-2xx status code, raise `DataError("telegram", response.text)`. The bot token must never be logged.

## File Locations

- `src/phantom/alerts/telegram.py` — `TelegramSender` class

## Acceptance Criteria

- [ ] `TelegramSender(bot_token: str, chat_id: str)` stores config; token is stored but never logged
- [ ] `send(event)` POSTs to the correct Telegram Bot API endpoint with `chat_id` and `text` fields
- [ ] Message text format: `"[{event_type}] Account {account_id}: {message}"` (position_id appended if set)
- [ ] Non-2xx HTTP response raises `DataError("telegram", response.text)`
- [ ] `httpx` is used for the HTTP call (sync, not async)
- [ ] Unit test: mock `httpx.post` to return 200 and verify correct URL and payload; mock 400 and verify `DataError` raised

## Implementation Notes

```python
import httpx
from phantom.alerts.events import AlertEvent
from phantom.errors import DataError

class TelegramSender:
    _API_URL = "https://api.telegram.org/bot{token}/sendMessage"

    def __init__(self, bot_token: str, chat_id: str) -> None:
        self._token = bot_token
        self._chat_id = chat_id

    def send(self, event: AlertEvent) -> None:
        text = f"[{event.event_type}] Account {event.account_id}: {event.message}"
        if event.position_id:
            text += f" (position {event.position_id})"
        url = self._API_URL.format(token=self._token)
        resp = httpx.post(url, json={"chat_id": self._chat_id, "text": text})
        if not resp.is_success:
            raise DataError("telegram", resp.text)
```
