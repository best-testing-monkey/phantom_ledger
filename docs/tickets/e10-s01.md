# E10-S01: ReplayEngine.replay_position() Core Loop

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** MVP
**Depends on:** [E9-S02](e09-s02.md), [E4-S01](e04-s01.md)

## Description

Implement `ReplayEngine.replay_position()` — the core method that reconstructs what would have happened to a position if it had been traded historically. Given a `Position` with a historical `entry_datetime`, the engine loads OHLCV bars from the DataProvider spanning `entry_datetime` to `max_close_datetime` (or `now_utc()` if not set). It then steps through each bar in chronological order, applying the full position lifecycle on every bar: check take-profit (high/low breach for long/short), check stop-loss, update unrealized P&L, and accumulate costs via `CostEngine`. The method returns an updated `Position` reflecting what the bar-by-bar simulation produced. It does not write to the DB — that is the responsibility of E10-S02 (outcome handling).

The engine is instantiated with a `DataProvider` and a `CostEngine`. It has no global state; multiple instances can coexist. The bar loop must call `CostEngine.apply_bar_costs()` (overnight, FX, dividend hooks are handled separately in E10-S06) and update `unrealized_pnl` on each bar. Log at DEBUG level for each bar processed.

## File Locations

- `src/phantom/engine/replay_engine.py` — `ReplayEngine` class with `replay_position()` method

## Acceptance Criteria

- [ ] `ReplayEngine` accepts `data_provider: DataProvider` and `cost_engine: CostEngine` in its constructor
- [ ] `replay_position()` loads bars via `DataProvider.get_bars(ticker, start, end)` where `start = position.entry_datetime` and `end = position.max_close_datetime or now_utc()`
- [ ] Each bar checks TP (if set): for long, `bar.high >= take_profit`; for short, `bar.low <= take_profit`
- [ ] Each bar checks SL (if set): for long, `bar.low <= stop_loss`; for short, `bar.high >= stop_loss`
- [ ] `unrealized_pnl` is updated on every bar using `(current_price - entry_price) * quantity * direction_sign`
- [ ] DEBUG log emitted per bar: ticker, bar timestamp, close price, unrealized P&L

## Implementation Notes

```python
import logging
from phantom.engine.replay_engine import ReplayEngine
from phantom.data.provider import DataProvider
from phantom.costs.engine import CostEngine
from phantom.models.position import Position
from phantom.utils.datetime import now_utc

logger = logging.getLogger(__name__)

class ReplayEngine:
    def __init__(self, data_provider: DataProvider, cost_engine: CostEngine) -> None:
        self._data = data_provider
        self._costs = cost_engine

    def replay_position(self, position: Position) -> Position:
        end = position.max_close_datetime or now_utc()
        bars = self._data.get_bars(position.ticker, position.entry_datetime, end)
        pos = position.model_copy()
        for bar in bars.itertuples():
            direction_sign = 1 if pos.direction == "long" else -1
            pos.unrealized_pnl = (bar.Close - pos.entry_price) * pos.quantity * direction_sign
            # TP/SL checks — exit conditions handled by replay_position returning
            # partial result; outcome applied by E10-S02
            logger.debug(
                "Replay bar %s %s close=%.4f upnl=%.2f",
                pos.ticker, bar.Index, bar.Close, pos.unrealized_pnl or 0.0,
            )
            if _tp_hit(pos, bar) or _sl_hit(pos, bar):
                break
        return pos
```
