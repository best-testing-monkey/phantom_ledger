# E10-S08: Bulk Replay Performance — Shared Price Data Cache

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** P2

## Description

When replaying multiple positions on the same ticker over overlapping date ranges, it is wasteful to load price data from the DataProvider (and potentially from disk or network) once per position. This story introduces an in-memory price data cache keyed by `(ticker, start_date, end_date)` within a single `replay_all()` call. The cache is a plain `dict` on the `ReplayEngine` instance, populated lazily: on the first call for a given `(ticker, start, end)` key, load via `DataProvider.get_bars()` and store; on subsequent calls for the same key, return the cached `DataFrame` directly. Cache keys use date-normalized timestamps (strip intra-day time component) to maximize sharing across positions with slightly different `entry_datetime` times on the same date. The cache lives only for the duration of a single `replay_all()` call — it is cleared at the start of each new bulk replay to avoid stale data. Log at DEBUG when a cache hit occurs: `"Cache hit for %s [%s, %s]"`.

## File Locations

- `src/phantom/engine/replay_engine.py` — `_price_cache: dict` attribute, `_get_bars_cached()` private method

## Acceptance Criteria

- [ ] `_price_cache` initialized as empty dict at start of each `replay_all()` call (not at class instantiation)
- [ ] Cache key is `(ticker, start_date, end_date)` where dates are `date` objects (not datetimes)
- [ ] `_get_bars_cached()` returns cached DataFrame on hit; calls `DataProvider.get_bars()` and stores result on miss
- [ ] DEBUG log on cache hit: `"Cache hit for %s [%s, %s]"` with ticker and date range
- [ ] `DataProvider.get_bars()` called at most once per unique `(ticker, start_date, end_date)` key in a single bulk replay
- [ ] Cache is isolated per `replay_all()` call — a second call to `replay_all()` starts with an empty cache

## Implementation Notes

```python
from datetime import date
import pandas as pd

class ReplayEngine:
    def __init__(self, data_provider: DataProvider, cost_engine: CostEngine) -> None:
        self._data = data_provider
        self._costs = cost_engine
        self._price_cache: dict[tuple[str, date, date], pd.DataFrame] = {}

    def replay_all(self, positions: list[Position]) -> list[Position]:
        self._price_cache = {}  # reset per bulk call
        return [self.replay_position(pos) for pos in positions]

    def _get_bars_cached(
        self, ticker: str, start: datetime, end: datetime
    ) -> pd.DataFrame:
        key = (ticker, start.date(), end.date())
        if key in self._price_cache:
            logger.debug("Cache hit for %s [%s, %s]", ticker, key[1], key[2])
            return self._price_cache[key]
        bars = self._data.get_bars(ticker, start, end)
        self._price_cache[key] = bars
        return bars
```
