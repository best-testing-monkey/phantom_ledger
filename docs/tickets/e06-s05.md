# E6-S05: Order Fill — Create Position

**Epic:** [E6: Order System](e06-order-system.md)
**Phase:** MVP
**Depends on:** [E6-S04](e06-s04.md), [E3-S04](e03-s04.md), [E7-S01](e07-s01.md)

## Description

Implement the fill handler that fires when `OrderManager.evaluate()` returns a filled order. It computes entry costs via `CostEngine`, deducts from account cash, creates the `Position` record, and links the order to the position. All three writes (order update, account update, position create) are atomic within one DB transaction.

## File Locations

- `src/phantom/engine/order_manager.py` — add `handle_fill()` method or inline in simulation loop

## Acceptance Criteria

- [ ] On fill: `CostEngine.entry_costs(fill_price, quantity, ticker, instrument_type, atr, hour_utc, fx_required)` is called
- [ ] `account.cash -= (fill_price * quantity) + entry_costs.total`
- [ ] New `Position` is created with `entry_price=fill_price`, `entry_datetime=filled_at`, `commission_entry=entry_costs.commission`, etc.
- [ ] `order.position_id` is set to the new position's ID; order status updated to `"filled"`
- [ ] All three DB writes (order, account, position) are committed in a single transaction
- [ ] Raises `InsufficientFundsError` if cash would go negative after costs (re-check at fill time)
