# E9-S03: Equity Curve Recording

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** MVP
**Depends on:** [E9-S01](e09-s01.md), [E5-S01](e05-s01.md)

## Description

Implement equity curve recording so that at the end of every bar the simulation captures a snapshot of account equity. Equity is defined as `account.cash + sum(position.quantity * bar.Close for each open position)`. Create an `EquityPoint` Pydantic model with fields: `id` (ULID), `account_id`, `timestamp` (ISO 8601 UTC), `equity` (float). Create an `EquityRepo` with `create()` and `list(account_id)` methods. After position updates on each bar, the simulation calls `EquityRecorder.record()`, which computes the current equity value, creates an `EquityPoint`, and persists it via `EquityRepo`. The `equity_curve` table accumulates one row per bar per account. This table is the source of truth for the equity chart, drawdown calculation, and performance metrics in E12.

## Acceptance Criteria

- [ ] `equity_curve` table has columns: `id` (TEXT PK), `account_id` (TEXT FK), `timestamp` (TEXT ISO 8601), `equity` (REAL)
- [ ] `EquityRepo.create()` inserts a row and commits; returns the `EquityPoint`
- [ ] `EquityRepo.list(account_id)` returns all points for the account ordered by `timestamp` ascending
- [ ] Equity is computed as `cash + sum(qty * bar_close)` at the end of each bar (after position updates)
- [ ] One `EquityPoint` is persisted per bar per account — no duplicates for the same `account_id` + `timestamp`
- [ ] Unit test: given fixed cash and one position, computed equity matches `cash + qty * close` exactly

## Implementation Notes

```python
# src/phantom/models/equity_point.py
from pydantic import BaseModel, Field
from phantom.utils.ids import new_id

class EquityPoint(BaseModel):
    id: str = Field(default_factory=new_id)
    account_id: str
    timestamp: str   # ISO 8601 UTC
    equity: float

# src/phantom/db/repositories/equity_repo.py
class EquityRepo:
    def __init__(self, conn: sqlite3.Connection):
        self._conn = conn

    def create(self, point: EquityPoint) -> EquityPoint:
        self._conn.execute(
            "INSERT INTO equity_curve (id, account_id, timestamp, equity) VALUES (?, ?, ?, ?)",
            (point.id, point.account_id, point.timestamp, point.equity),
        )
        self._conn.commit()
        return point

    def list(self, account_id: str) -> list[EquityPoint]:
        rows = self._conn.execute(
            "SELECT * FROM equity_curve WHERE account_id = ? ORDER BY timestamp ASC",
            (account_id,),
        ).fetchall()
        return [EquityPoint(**dict(row)) for row in rows]

# In simulation loop (per bar):
market_value = sum(p.quantity * bar["Close"] for p in open_positions)
equity = account.cash + market_value
point = EquityPoint(account_id=account_id, timestamp=to_iso(clock.now()), equity=equity)
equity_repo.create(point)
```
