# E16-S17: Trade Notes from UI

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

Trade notes can be added via `phantom note add` CLI but cannot be created or edited from the web UI. The position detail page already lists existing notes (truncated). Add a form to create new notes and allow deletion.

## File Locations

- `src/phantom/web/routes/positions.py` — add `POST /positions/{position_id}/notes` and `POST /positions/{position_id}/notes/{note_id}/delete`
- `src/phantom/web/templates/position_detail.html` — add note creation form and delete buttons

## Current State

- `ph.notes.add(position_id, content, title=None)` exists — creates a note in the filesystem and DB
- `ph.notes.list(position_id=position_id)` exists — returns `list[Note]`
- `Note` model has: `id`, `title`, `content`, `position_id`, `created_at`
- The position detail page already renders notes but truncates at 500 chars. There is no add form or delete button.
- Check `src/phantom/api/notes.py` for the exact `add()` signature before implementing.

## Acceptance Criteria

- [ ] Below the notes list, a "Add Note" form has a `<textarea>` for content and optional title `<input>`
- [ ] `POST /positions/{position_id}/notes` creates the note and redirects back to `/positions/{position_id}`
- [ ] Empty content shows a form validation error ("Note content cannot be empty")
- [ ] Each existing note has a Delete button: `POST /positions/{position_id}/notes/{note_id}/delete`
- [ ] Delete redirects back to `/positions/{position_id}` on success
- [ ] Full note content (not truncated) is shown on the position detail page — the 500-char truncation in the route is removed
- [ ] Notes are listed newest-first
