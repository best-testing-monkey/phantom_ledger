# E16-S20: Closed Trades Pagination on Dashboard

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

The dashboard shows the 10 most recent closed trades, hard-coded. There is no way to see older trades without the CLI. Add Previous/Next pagination to the closed trades table, and increase the default page size to 25.

## File Locations

- `src/phantom/web/routes/dashboard.py` — add `page` query param, slice closed trades
- `src/phantom/web/templates/dashboard.html` — add pagination controls below the closed trades table

## Current State

`dashboard.py` line ~38:

```python
recent_trades = sorted(closed_trades, key=lambda p: p.exit_datetime, reverse=True)[:10]
```

The template receives `recent_trades` as a flat list with no pagination metadata.

## Acceptance Criteria

- [ ] `GET /?account=<name>&page=2` shows trades 26–50 (page 2)
- [ ] Default page is 1; page size is 25
- [ ] "Previous" link appears when `page > 1`; "Next" link appears when more trades exist beyond the current page
- [ ] Pagination links preserve the `?account=<name>` parameter
- [ ] Total trade count is shown: "Showing 26–50 of 73 closed trades"
- [ ] If all trades fit on one page, no pagination controls are shown
- [ ] Page 0 or negative page numbers are clamped to page 1

## Implementation Notes

**`dashboard.py`** — update the route signature and slicing:

```python
async def dashboard(request: Request, account: str | None = None, page: int = 1):
    PAGE_SIZE = 25
    page = max(1, page)
    ...
    all_closed = sorted(closed_trades, key=lambda p: p.exit_datetime, reverse=True)
    total_closed = len(all_closed)
    start = (page - 1) * PAGE_SIZE
    recent_trades = all_closed[start : start + PAGE_SIZE]

    # context additions:
    "recent_trades": recent_trades,
    "page": page,
    "total_closed": total_closed,
    "page_size": PAGE_SIZE,
    "has_prev": page > 1,
    "has_next": start + PAGE_SIZE < total_closed,
    "trade_start": start + 1,
    "trade_end": min(start + PAGE_SIZE, total_closed),
```

**`dashboard.html`** — below the closed trades `<table>`:

```html
{% if total_closed > page_size %}
<div style="display:flex;justify-content:space-between;align-items:center;margin-top:1rem;">
  <span class="neutral">Showing {{ trade_start }}–{{ trade_end }} of {{ total_closed }} closed trades</span>
  <div>
    {% if has_prev %}
    <a href="/?account={{ account.name }}&page={{ page - 1 }}">← Previous</a>
    {% endif %}
    {% if has_next %}
    <a href="/?account={{ account.name }}&page={{ page + 1 }}" style="margin-left:1rem;">Next →</a>
    {% endif %}
  </div>
</div>
{% endif %}
```

---

> **Implementation Standards:** Slicing must happen in the route, not in the template. The template receives only the current page's data plus pagination metadata. Never pass the full list to the template.
