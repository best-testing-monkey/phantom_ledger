# E1-S08: pytest Fixtures

**Epic:** [E1: Project Scaffolding](e01-scaffolding.md)
**Phase:** MVP

## Description

Populate `tests/conftest.py` with the four shared fixtures that all tests depend on. These fixtures are the canonical test infrastructure for the entire project — every integration test uses `phantom_instance`, every repo unit test uses `db_conn`, and cost model tests use `degiro_profile` and `sample_price_data`.

## File Locations

- `tests/conftest.py` — all four fixtures

## Acceptance Criteria

- [ ] `db_conn` fixture: `:memory:` SQLite connection with `row_factory=sqlite3.Row`, `PRAGMA foreign_keys = ON`, `PRAGMA journal_mode = WAL`, and `run_migrations` applied; yields connection and closes on teardown
- [ ] `phantom_instance` fixture: `Phantom(data_dir=str(tmp_path), in_memory=True)` using pytest's `tmp_path`
- [ ] `degiro_profile` fixture: returns a `BrokerProfile` with exactly the values shown in A.9 of `_standards.md` (`name="DEGIRO_TEST"`, `fixed_fee=1.0`, `fixed_spread_pct=0.0005`, `fixed_pct=0.0003`, etc.)
- [ ] `sample_price_data` fixture: 20 business-day pandas DataFrame from `pd.bdate_range("2025-01-02", periods=20)` using `np.random.default_rng(42)`, with columns `Open`, `High`, `Low`, `Close`, `Adj Close`, `Volume`
- [ ] All four fixtures are importable in test files via normal pytest dependency injection
- [ ] `uv run pytest tests/` passes with all fixtures resolving correctly
