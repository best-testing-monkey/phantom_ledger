# E16-S09: Close Position Action

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

There is no way to close an open position from the web UI. Add a Close button to each open position row on the dashboard and to the position detail page. Closing requires an `exit_price` (the price at which to simulate the close); the user must supply it.

## File Locations

- `src/phantom/web/routes/positions.py` — add `POST /positions/{position_id}/close` endpoint
- `src/phantom/web/templates/_positions_rows.html` — add Close button to each row
- `src/phantom/web/templates/position_detail.html` — add Close form
- `src/phantom/web/templates/_close_modal.html` *(new)* — inline form for exit price input

## Current State

- `ph.positions.close(position_id, close_reason="manual", exit_price: float)` exists
  - Raises `ValidationError` if `exit_price is None`
  - Deducts exit costs, credits cash, marks position `"closed"`
- The position detail page (`/positions/{position_id}`) has no close form
- `_positions_rows.html` shows each open position as a table row linked to the detail page

## Acceptance Criteria

- [ ] Each open position row on the dashboard has a "Close" button
- [ ] Clicking it reveals an inline form asking for Exit Price (HTML `<details>` or small form below the row — no JS modal required)
- [ ] Submitting calls `POST /positions/{position_id}/close` with `exit_price` and `account` fields
- [ ] On success, redirect to `/?account=<name>`
- [ ] The position detail page also has a Close section with an exit price field
- [ ] Closing with a blank price shows a form validation error (use `required` attribute + server-side check)
- [ ] Already-closed positions show no Close button

## Implementation Notes

**`positions.py`** — new endpoint:

```python
@router.post("/positions/{position_id}/close")
async def close_position(
    request: Request,
    position_id: str,
    exit_price: float = Form(...),
    account: str = Form(...),
):
    try:
        ph = get_phantom()
        ph.positions.close(position_id, close_reason="manual", exit_price=exit_price)
        return RedirectResponse(url=f"/?account={account}", status_code=303)
    except PhantomError as e:
        # Re-render position detail with error
        position = ph.positions.get(position_id)
        account_obj = ph.accounts.get(position.account_id)
        notes = ph.notes.list(position_id=position_id) if hasattr(ph, 'notes') else []
        return templates.TemplateResponse(
            request=request,
            name="position_detail.html",
            context={"position": position, "account": account_obj, "notes": notes, "error": str(e)},
        )
```

**In `_positions_rows.html`**, after the existing `<td>` for the position link, add:

```html
<td>
  {% if position.status == "open" %}
  <details>
    <summary style="cursor:pointer;color:#3498db;">Close</summary>
    <form method="post" action="/positions/{{ position.id }}/close" style="margin-top:0.5rem;">
      <input type="hidden" name="account" value="{{ account.name }}">
      <input type="number" name="exit_price" step="0.0001" placeholder="Exit price" required
             style="width:120px;padding:0.3rem;margin-right:0.5rem;">
      <button type="submit" style="padding:0.3rem 0.75rem;font-size:0.85rem;">Confirm</button>
    </form>
  </details>
  {% endif %}
</td>
```

Note: `_positions_rows.html` currently does not have access to `account` — the HTMX fragment endpoint `/api/positions-rows` must also pass `account` to the template context (it currently passes only `positions`).

---

> **Implementation Standards:** Redirect after POST. Use `required` on the price input — never close with price=0.
