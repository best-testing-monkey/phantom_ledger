# E10-S02: Replay Outcome Handling

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** MVP
**Depends on:** [E10-S01](e10-s01.md)

## Description

After `ReplayEngine.replay_position()` steps through all bars, this story is responsible for writing the determined outcome back to the database. If an exit condition (TP or SL) was triggered on any bar, the position is closed at the historical bar price and timestamp with the matching `close_reason` (`"tp"` or `"sl"`). `realized_pnl` is computed as `(close_price - entry_price) * quantity * direction_sign` minus accumulated costs. The `close_price` for a TP fill is the exact `take_profit` value (not bar high, to avoid unrealistic fills); for an SL fill it is the exact `stop_loss` value. If no exit condition fired before the last bar is exhausted, the position is left `status = "open"` with accumulated costs stored on the model and `replay_completed_at` set to `now_utc()` as an ISO 8601 string. Either path must persist the final position state via `PositionRepo.update()`. Log at INFO level on any close.

## File Locations

- `src/phantom/engine/replay_engine.py` — `_apply_outcome()` private helper called at end of `replay_position()`

## Acceptance Criteria

- [ ] TP hit: `position.status = "closed"`, `close_reason = "tp"`, `close_price = position.take_profit`, `close_datetime` = bar timestamp as UTC datetime
- [ ] SL hit: `position.status = "closed"`, `close_reason = "sl"`, `close_price = position.stop_loss`, `close_datetime` = bar timestamp as UTC datetime
- [ ] `realized_pnl = (close_price - entry_price) * quantity * direction_sign - total_accumulated_cost`
- [ ] No exit by end of bars: `status` remains `"open"`, `replay_completed_at = to_iso(now_utc())`
- [ ] `PositionRepo.update(pos)` called exactly once regardless of path; commit occurs inside repo
- [ ] INFO log on close: `"Replay closed %s via %s at %.4f pnl=%.2f"` with ticker, close_reason, close_price, realized_pnl

## Implementation Notes

```python
def _apply_outcome(
    self,
    pos: Position,
    exit_price: float | None,
    exit_dt: datetime | None,
    close_reason: str | None,
    total_cost: float,
) -> Position:
    if exit_price is not None:
        direction_sign = 1 if pos.direction == "long" else -1
        pos.status = "closed"
        pos.close_reason = close_reason
        pos.close_price = exit_price
        pos.close_datetime = exit_dt
        pos.realized_pnl = (
            (exit_price - pos.entry_price) * pos.quantity * direction_sign
            - total_cost
        )
        logger.info(
            "Replay closed %s via %s at %.4f pnl=%.2f",
            pos.ticker, close_reason, exit_price, pos.realized_pnl,
        )
    pos.replay_completed_at = to_iso(now_utc())
    self._repo.update(pos)
    return pos
```
