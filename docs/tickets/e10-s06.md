# E10-S06: Replay with Overnight and Dividend Hooks

**Epic:** [E10: Historical Position Replay](e10-replay.md)
**Phase:** P2
**Depends on:** [E9-S09](e09-s09.md), [E9-S10](e09-s10.md)

## Description

Extend `ReplayEngine.replay_position()` to apply overnight financing charges and dividend adjustments exactly as the live simulation does. On each bar transition, the engine must detect day boundaries: if the current bar's date differs from the previous bar's date, an overnight period has elapsed and `OvernightCostModel.calculate()` must be called with the position notional and the applicable overnight rate for that night (fetched from the stored rate or DataProvider). Dividend adjustments are triggered when the bar date matches or crosses an ex-dividend date for the ticker, retrieved from `DataProvider.get_dividends(ticker, start, end)`. For long equity positions, credit the dividend amount `(dividend_per_share * quantity)`; for short equity or CFD positions, apply the appropriate deduction per the `BrokerProfile.dividend` config. Accumulate all overnight charges and dividend adjustments into `total_accumulated_cost` for P&L calculation. Log at DEBUG for each overnight charge and at INFO for each dividend event.

## File Locations

- `src/phantom/engine/replay_engine.py` — `_apply_overnight()` and `_apply_dividend()` private helpers, called from bar loop

## Acceptance Criteria

- [ ] Day boundary detection: compare `bar.date` with `prev_bar.date`; trigger overnight charge on each new calendar day
- [ ] `OvernightCostModel.calculate()` called once per overnight period with correct notional and rate
- [ ] `DataProvider.get_dividends(ticker, start, end)` called once per replay (not per bar) to fetch ex-dates
- [ ] Dividend credit applied to long positions on ex-date bar; deduction applied to short positions per broker config
- [ ] Both charges accumulated into `position.total_cost` and ultimately reflected in `realized_pnl`
- [ ] DEBUG log per overnight charge: `"Overnight charge %s %.4f"` with date and amount; INFO log per dividend event

## Implementation Notes

```python
def _apply_overnight(self, pos: Position, bar_date: date, notional: float) -> float:
    """Return overnight charge for one night."""
    charge = self._costs.overnight.calculate(
        notional=notional,
        nights=1,
        direction=pos.direction,
    )
    logger.debug("Overnight charge %s %.4f", bar_date, charge)
    return charge

def _apply_dividend(
    self, pos: Position, bar_date: date, ex_dates: dict[date, float]
) -> float:
    """Return dividend adjustment (positive = credit, negative = charge)."""
    if bar_date not in ex_dates:
        return 0.0
    div_per_share = ex_dates[bar_date]
    if pos.direction == "long":
        amount = div_per_share * pos.quantity
    else:
        amount = -div_per_share * pos.quantity * self._costs.dividend_charge_factor
    logger.info("Dividend event %s amount=%.4f", bar_date, amount)
    return amount
```
