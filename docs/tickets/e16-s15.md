# E16-S15: Position Cost Breakdown Panel

**Epic:** E16 — Web UI  
**Phase:** P3 (Web UI improvements)

## Description

The simulation engine calculates commission, spread, slippage, overnight, and FX costs per position and stores them as fields on the `Position` model. These are invisible in the web UI. Add a cost breakdown section to the position detail page.

## File Locations

- `src/phantom/web/templates/position_detail.html` — add cost breakdown card
- No route or backend changes needed

## Current State

The `Position` model (`src/phantom/models/position.py`) already has these fields:

```
commission_entry: float = 0.0
commission_exit: float = 0.0
spread_cost: float = 0.0
slippage_cost: float = 0.0
overnight_costs: float = 0.0
overnight_accrued: float = 0.0
fx_conversion_cost: float = 0.0
```

These are already passed to the template via `context["position"]`.

The position detail template currently shows: entry/exit price, quantity, status, P&L, duration, and notes. There is no cost section.

## Acceptance Criteria

- [ ] A "Cost Breakdown" card appears on the position detail page
- [ ] Rows: Commission (entry), Commission (exit), Spread, Slippage, Overnight (settled), Overnight (accruing), FX Conversion, **Total Costs**
- [ ] Total is sum of all cost fields
- [ ] Values are formatted to 2 decimal places with the account's base currency symbol
- [ ] If all cost fields are 0.0, show "No costs recorded." instead of a table (simplifies display for paper trades that haven't run through the engine)
- [ ] Open positions show "overnight_accrued" as a separate row labelled "Overnight (accruing)" to distinguish from settled overnight costs

## Implementation Notes

This is a template-only change. In `position_detail.html`, add a new `.card` section:

```html
{% set total_costs = position.commission_entry + position.commission_exit
   + position.spread_cost + position.slippage_cost
   + position.overnight_costs + position.fx_conversion_cost %}

{% if total_costs == 0 and position.overnight_accrued == 0 %}
<div class="card">
  <h2>Cost Breakdown</h2>
  <p class="neutral">No costs recorded.</p>
</div>
{% else %}
<div class="card">
  <h2>Cost Breakdown</h2>
  <table>
    <tr><td>Commission (entry)</td><td class="negative">{{ "%.2f"|format(position.commission_entry) }}</td></tr>
    <tr><td>Commission (exit)</td><td class="negative">{{ "%.2f"|format(position.commission_exit) }}</td></tr>
    <tr><td>Spread</td><td class="negative">{{ "%.2f"|format(position.spread_cost) }}</td></tr>
    <tr><td>Slippage</td><td class="negative">{{ "%.2f"|format(position.slippage_cost) }}</td></tr>
    <tr><td>Overnight (settled)</td><td class="negative">{{ "%.2f"|format(position.overnight_costs) }}</td></tr>
    {% if position.status == "open" %}
    <tr><td>Overnight (accruing)</td><td class="negative">{{ "%.2f"|format(position.overnight_accrued) }}</td></tr>
    {% endif %}
    <tr><td>FX Conversion</td><td class="negative">{{ "%.2f"|format(position.fx_conversion_cost) }}</td></tr>
    <tr style="font-weight:600;border-top:2px solid #bdc3c7;">
      <td>Total Costs</td>
      <td class="negative">{{ "%.2f"|format(total_costs + position.overnight_accrued) }}</td>
    </tr>
  </table>
</div>
{% endif %}
```

---

> **Implementation Standards:** Template-only change — do not add a new route or modify the route handler. Use `"%.2f"|format(value)` for consistent decimal display.
