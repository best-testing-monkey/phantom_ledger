# E7-S07: CLI — position close

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP
**Depends on:** [E7-S04](e07-s04.md)

## Description

Wire up `phantom position close <id> --reason manual` CLI command. It closes the position at the current market price (from the data layer) with `close_reason = "manual"`.

## File Locations

- `src/phantom/cli.py` — add `position_close` command

## Acceptance Criteria

- [ ] `phantom position close <position-id>` prompts for confirmation and closes at current price
- [ ] `phantom position close <position-id> --yes` skips confirmation prompt
- [ ] `--reason` flag accepts `"manual"` (default), or any valid `CloseReason` value
- [ ] On success, prints realized P&L and cost breakdown using Rich
- [ ] `phantom position close <nonexistent-id>` exits 1 with friendly error
- [ ] Closing an already-closed position exits 1 with friendly error
