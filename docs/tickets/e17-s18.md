# E17-S18: Standalone CostEngine Export

**Epic:** [E17: Library API Surface](e17-library-api.md)
**Phase:** P2
**Depends on:** [E3](e03-cost-engine.md), [E17-S11](e17-s11.md)

## Description

Ensure `CostEngine` can be instantiated directly with a `BrokerProfile` and used without a `Phantom` instance — no DB connection, no migrations, no account needed. This allows users to do quick cost calculations or build their own tooling on top of the cost model without setting up the full system. `CostEngine.__init__` must accept a `BrokerProfile` as its sole argument. The `calculate(fill_price, quantity, side, symbol, currency, account_currency, holding_days)` method returns a `CostBreakdown`. Verify that the existing `CostEngine` implementation already supports this and add it to the public `__init__.py` exports if not already present.

## File Locations

- `src/phantom/costs/engine.py` — verify `CostEngine.__init__(profile: BrokerProfile)` signature
- `src/phantom/__init__.py` — ensure `CostEngine` is in `__all__`

## Acceptance Criteria

- [ ] `from phantom import CostEngine` works without importing any internal module
- [ ] `ce = CostEngine(profile)` where `profile` is a `BrokerProfile` instance constructs without error
- [ ] `ce.calculate(fill_price=150.0, quantity=10, side="buy", symbol="AAPL", ...)` returns a `CostBreakdown`
- [ ] `CostBreakdown` is `frozen=True` and has fields for each cost component plus a `total` property
- [ ] `CostEngine` does not import from `phantom.db`, `phantom.api`, or `phantom.engine`
- [ ] Unit test: `CostEngine(profile).calculate(...)` returns correct commission for a known profile fixture

## Implementation Notes

```python
# Standalone usage (no Phantom instance needed):
from phantom import CostEngine, BrokerProfile

profile = BrokerProfile.model_validate_json(Path("ibkr.json").read_text())
ce = CostEngine(profile)
breakdown = ce.calculate(
    fill_price=150.0,
    quantity=100,
    side="buy",
    symbol="AAPL",
    currency="USD",
    account_currency="USD",
    holding_days=0,
)
print(f"Total cost: {breakdown.total:.2f}")
print(f"Commission: {breakdown.commission:.2f}")
```
