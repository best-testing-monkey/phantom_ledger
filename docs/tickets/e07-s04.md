# E7-S04: TP/SL Exit Logic

**Epic:** [E7: Position System](e07-position-system.md)
**Phase:** MVP
**Depends on:** [E7-S03](e07-s03.md), [E3-S04](e03-s04.md)

## Description

Implement the TP and SL exit logic. When a price bar hits the take-profit or stop-loss level, the position is closed at the trigger price. Exit costs are computed and subtracted from realized P&L.

## File Locations

- `src/phantom/engine/position_manager.py` — add `close()` method

## Acceptance Criteria

- [ ] `close(position, exit_price, close_reason, bar_timestamp) -> Position` computes exit costs, sets `realized_pnl`, and returns closed position
- [ ] Long TP: triggers when `bar["High"] >= take_profit`; `exit_price = take_profit`; `close_reason = "tp"`
- [ ] Long SL: triggers when `bar["Low"] <= stop_loss`; `exit_price = stop_loss`; `close_reason = "sl"`
- [ ] Short TP: triggers when `bar["Low"] <= take_profit`; `exit_price = take_profit`; `close_reason = "tp"`
- [ ] Short SL: triggers when `bar["High"] >= stop_price`; `exit_price = stop_loss`; `close_reason = "sl"`
- [ ] `realized_pnl = (exit_price - entry_price) * quantity` (for long; negated for short) `- commission_entry - commission_exit - spread_cost - slippage_cost`
- [ ] Position `status` set to `"closed"`, `exit_datetime` set to bar timestamp
- [ ] `commission_exit` and other cost fields updated on the position
