## Description

Audit `src/phantom/cli.py` and remove any remaining business logic — SQL queries, direct repo access, manager calls, calculation code, or data transformation. Every CLI command must follow exactly this pattern: call `get_phantom()`, call exactly one method on a `ph.*` sub-API, format the result with Rich tables or panels, catch `PhantomError` and print `[red]Error:[/red] {e}` then exit 1. The CLI is a presentation layer only. Any logic currently in the CLI that is not covered by an API method is a sign that an API method is missing — implement it before removing the logic.

## File Locations

- `src/phantom/cli.py` — refactored to thin wrapper pattern throughout

## Acceptance Criteria

- [ ] No `sqlite3`, `PositionRepo`, `OrderRepo`, `AccountRepo`, or any `phantom.db.*` import in `cli.py`
- [ ] No `phantom.engine.*` import in `cli.py` (except `PaperTradeScheduler` for the `run` command)
- [ ] Every command catches `PhantomError` and exits with code 1
- [ ] Every destructive command (delete, close, cancel) calls `typer.confirm()` unless `--yes` flag is provided
- [ ] `get_phantom()` is a module-level cached helper that creates one `Phantom` instance per process
- [ ] Integration test: every `phantom` subcommand can be invoked via `typer.testing.CliRunner` without importing internal modules

## Implementation Notes

```python
_phantom_instance: Phantom | None = None

def get_phantom() -> Phantom:
    global _phantom_instance
    if _phantom_instance is None:
        data_dir = os.environ.get("PHANTOM_DATA", "./data")
        _phantom_instance = Phantom(data_dir=data_dir)
    return _phantom_instance

# Example of correct thin-wrapper pattern:
@app.command()
def account_create(name: str, broker: str, cash: float = 10_000.0) -> None:
    try:
        ph = get_phantom()
        account = ph.accounts.create(name=name, broker_profile=broker, initial_cash=cash)
        console.print(f"[green]Created account:[/green] {account.name} ({account.id})")
    except PhantomError as e:
        console.print(f"[red]Error:[/red] {e}")
        raise typer.Exit(code=1)
```
