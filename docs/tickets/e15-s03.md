# E15-S03: Strategy Execution in Simulation Loop

**Epic:** [E15: Strategy Automation Hooks](e15-strategy-automation.md)
**Phase:** P3
**Depends on:** [E15-S01](e15-s01.md), [E9-S02](e09-s02.md)

## Description

Wire strategy execution into the per-bar simulation loop. After all position updates (TP/SL checks, overnight costs, margin updates) for a given bar have been applied, if a `Strategy` is attached to the engine, call `strategy.on_bar(bar, account, open_positions, context)`. Collect the returned `list[OrderRequest]` and place each one via `OrderManager.place()`. Errors from individual order placements (e.g. `InsufficientFundsError`) should be caught, logged at WARNING level, and skipped — the loop must continue. The strategy is optional; if `None`, the step is a no-op. Assign the strategy via `engine.strategy = loaded_strategy` before starting the loop.

## File Locations

- `src/phantom/engine/simulation_engine.py` — `strategy` attribute and strategy execution step in `_process_bar()`

## Acceptance Criteria

- [ ] `SimulationEngine.strategy: Strategy | None` attribute defaults to `None`
- [ ] `_process_bar()` calls `strategy.on_bar(bar, account, open_positions, context)` after position updates when strategy is not `None`
- [ ] Each `OrderRequest` returned is passed to `self._order_manager.place()`
- [ ] `InsufficientFundsError` and `ValidationError` from placement are caught and logged at WARNING, not re-raised
- [ ] When `strategy` is `None`, no exception is raised and performance is unaffected
- [ ] Integration test: a strategy that returns one order per bar produces the expected number of orders after N bars

## Implementation Notes

```python
if self.strategy is not None:
    context = StrategyContext(account_id=account.id, _engine=self)
    requests = self.strategy.on_bar(bar, account, open_positions, context)
    for req in requests:
        try:
            self._order_manager.place(**req.model_dump())
        except (InsufficientFundsError, ValidationError) as e:
            logger.warning("Strategy order rejected: %s", e)
```
