# E9-S02: SimulationEngine.run_backtest()

**Epic:** [E9: Simulation Engine](e09-simulation-engine.md)
**Phase:** MVP
**Depends on:** [E6-S01](e06-s01.md), [E7-S01](e07-s01.md), [E9-S01](e09-s01.md), [E9-S03](e09-s03.md)

## Description

Implement `SimulationEngine.run_backtest()`, the main loop that drives a historical simulation. The method accepts an account ID, a ticker (or list of tickers), a date range, and an optional `BrokerProfile`. It constructs a `BacktestClock` from the historical data's `DatetimeIndex`, then iterates bar-by-bar. On each bar: (1) call `OrderManager.evaluate(bar)` to check pending orders and fill any that trigger on this bar; (2) call `PositionManager.update(position, bar)` for every open position associated with the account; (3) call `EquityRecorder.record(account, open_positions, bar)` to persist the equity point. The loop continues until `clock.is_done()` returns `True`. All state changes within a single bar are committed atomically — either all succeed or none are persisted. The method returns a `BacktestResult` dataclass with the account's final state and a reference to the equity curve.

## File Locations

- `src/phantom/engine/simulation_engine.py` — `SimulationEngine` class with `run_backtest()` method
- `src/phantom/models/backtest_result.py` — `BacktestResult` dataclass

## Acceptance Criteria

- [ ] `run_backtest()` iterates every bar in the historical data from start to end date
- [ ] `OrderManager.evaluate(bar)` is called before `PositionManager.update()` on every bar
- [ ] `PositionManager.update()` is called for each open position after order evaluation
- [ ] Equity is recorded after position updates on every bar (not just on fills)
- [ ] All changes within a bar are wrapped in a single DB transaction (commit once per bar)
- [ ] `BacktestResult` contains at minimum: `account`, `equity_curve` (list of `EquityPoint`), `filled_orders`, `closed_positions`

## Implementation Notes

```python
# src/phantom/engine/simulation_engine.py
class SimulationEngine:
    def run_backtest(
        self,
        account_id: str,
        tickers: list[str],
        start: str | datetime,
        end: str | datetime,
    ) -> BacktestResult:
        data = self._data_provider.load(tickers, start, end)
        clock = BacktestClock(data.index)
        filled_orders = []
        closed_positions = []
        while not clock.is_done():
            bar = data.loc[clock.now()]
            # 1. Fill pending orders
            new_fills = self._order_manager.evaluate(bar, account_id)
            filled_orders.extend(new_fills)
            # 2. Update open positions
            open_positions = self._position_repo.list(account_id=account_id, status="open")
            for position in open_positions:
                result = self._position_manager.update(position, bar)
                if result.closed:
                    closed_positions.append(result.position)
            # 3. Record equity point
            self._equity_recorder.record(account_id, open_positions, bar)
            # 4. Commit bar
            self._conn.commit()
            clock.advance()
        account = self._account_repo.get(account_id)
        equity_curve = self._equity_repo.list(account_id=account_id)
        return BacktestResult(account=account, equity_curve=equity_curve,
                              filled_orders=filled_orders, closed_positions=closed_positions)
```
